# 伊瑟拉（精灵）默认美术资源设计

## 当前玩法口径

- 角色 ID：`1003`。
- 默认装备：`弓箭`，双手，占用两个手位。
- 默认攻击：5 格远程直线。
- 当前没有角色专属技能动作需求；只制作待机、移动、攻击、受击、死亡。
- 不包含狐狸、坐骑、技能法阵或大型粒子效果。

## 角色形象

以失忆精灵王族猎手为定位：银白及肩发、精灵长耳、三叶形小王冠、象牙白与低饱和鼠尾草绿猎装、深绿内衬、棕色长靴、旧金装饰和深木长弓。保留轻盈的森林弓手轮廓，但服装必须适合徒步和战斗。

## 立绘

- 当前候选：`Resources/Images/Characters/Portraits/isera_portrait_v3.png`。
- 画布：`1024×1536`，透明背景。
- 与重剑手使用相同的纵向 2:3 口径和全身留白；人物约占画布高度 78%。
- 默认持弓，不加入技能光效和环境背景。
- 表情与姿态强调失忆后的稚嫩感：视线略微游移，眉眼带轻微茫然，肩部内收，空闲手靠近胸口，持弓动作略显生疏；保持年轻成人比例。

## 战斗精灵

- 最终资源：`Resources/Images/Characters/Pixel/isera_pixel_action_sheet_v3.png`。
- 当前 `isera_pixel_action_sheet.png` 基于旧版立绘生成，只作为尺寸草稿，不能作为确认后的局内资源接入。
- 画布：`2032×774`，透明背景，七格横向动作表。
- 帧序与重剑手一致：
  1. 待机 A
  2. 待机 B
  3. 移动接触步
  4. 移动经过步
  5. 拉弓蓄力
  6. 松弦释放
  7. 受击 / 当前死亡停留帧
- 图集已按七个独立透明连通块重新排版。运行时与重剑手同样使用 `0.32` 缩放：精灵待机显示约 `48×106 px`，重剑手约 `51×107 px`。
- 脚底基线与重剑手一致；弓和箭必须完整显示，不能按等宽格子再次裁切素材。

### 生成验收

- 人物必须与 `isera_portrait_v3.png` 一致：少女脸、略显茫然的眼神、白花叶冠、轻薄绿白裙、软靴与纤细枝弓。
- 七个动作不得跨格；每格左右至少保留 28 个透明源像素。
- 待机帧运行时高度目标为 `107±4 px`，宽度可以因长弓达到约 `60–75 px`。
- 待机、移动和受击中弓必须跟随双手；攻击帧必须完整表现搭箭、拉弦和松弦。
- 不生成狐狸、技能、法阵、光蝶或额外攻击特效。

## 动画参数

| 动画 | 帧 | 速度 | 循环 |
|---|---|---:|---|
| 待机 | 0, 1 | 1.5 fps | 是 |
| 移动 | 2, 3 | 8 fps | 是 |
| 攻击 | 4, 5, 0 | 9 fps | 否 |
| 受击 | 3, 0 | 8 fps | 否 |
| 死亡 | 6 | 停留 | 否 |

攻击只播放人物图集本身，不旋转整个角色节点。移动、受击和死亡沿用重剑手现有播放规则。

受击使用仍保持站立的第 3 帧配合短距离后撤和受击闪色；死亡才使用第 6 帧跪倒姿势，两者不可复用同一动作。
