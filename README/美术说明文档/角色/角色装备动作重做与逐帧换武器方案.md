# 角色装备动作重做与逐帧换武器方案

> 2026-10-07。方案阶段；此文不代表已经完成新动画或武器替换。

## 现状与结论

- 原始人物形象保存在 `Resources/Images/Characters/OriginalReferences/`。现有 `FrameV2` 的双手剑、长枪、弓、法典是完整带装备图，武器、手和衣服遮挡已经画在同一层；不能把另一张武器 PNG 盖上去就完成换装。
- `PixelHeroActor` 对部分单手装备使用固定位置的独立 Sprite2D；这个位置没有覆盖所有动作逐帧握点。双手装备则直接切换完整动作图集。单张 `equipment_sword/shield/two_hand_sword/bow/tome.png` 只有一种画法，不含刺击透视、剑刃转向、弓弦张合、翻书等动作视角。
- 当前 `SpriteFrames` 多数只有 2 待机、2 移动、2 攻击、1 受击或跪倒。除原重剑手双手剑外，死亡使用跪倒终态。因此“换武器时待机、移动、攻击、死亡均完整重做”尚未实现。
- **可行做法**：按角色和持握动作族重做人物身体与四种状态，再为同一动作族里的每件武器制作逐帧美术图层，通过离线合成输出最终 PNG 与 `.tres`。游戏只按装备 ID 读取并播放资源；骨骼、逐帧武器坐标、角度与手部遮挡不在运行时计算。

## 资源结构

一套可复用的动作以 `角色 × 持握动作族` 为单位，而非一张通用身体图：

| 动作族 | 身体姿势 | 可替换的装备范围 | 必须另做的情况 |
|---|---|---|---|
| 单手武器 | 单手握柄、另一手自然摆动 | 握点与重量接近的剑、刀 | 长度或重量明显不同，导致步态/攻击动作改变 |
| 单盾、剑盾、双持 | 分别制作左手举盾、剑盾配合、双手持武器 | 同尺寸盾面或同族单手武器 | 盾面遮挡躯干范围变化、双手武器交叉关系变化 |
| 双手剑 | 两手握距固定、蓄力与挥砍 | 同握距、同重心范围的双手剑外观 | 长枪刺击、重锤挥击等不同发力方式 |
| 长枪 | 两手分握、直线刺击 | 握距相同的枪、矛外观 | 明显改变握距、枪长或攻击方向 |
| 弓 | 持弓、搭箭、拉弦、释放 | 同尺寸弓与对应箭 | 弓形、拉距或箭位置变化过大 |
| 法典/法器 | 托书、抬手、施法 | 尺寸接近的书形法典 | 法杖、法球需自己的持握与施法动作族 |

每个动作族为**待机、移动、攻击、死亡**独立制作连续帧。现有受击也要同步补做，避免切换装备后在受击时跳回另一种武器。死亡要有倒下过程、落地终态与武器落点，不再用受击跪姿代替。

每帧保存：身体后层、装备后层、装备前层、手/袖口前层、可选特效层；脚底/躯干锚点、左右握点、装备枢轴和命中或释放事件。弓弦、箭、书页以及需要透视变化的刀刃须有专门的逐帧图，不能只旋转一张静态 PNG。

## 制作与接入步骤

1. **定原型**：以原始人物形象锁定脸、发型、服装、体型和颜色。对每个角色与动作族先画带一件标准装备的四种完整动画，受击作为第五项补齐；检查动作开始、循环、命中、结束和倒地。重剑手与精灵分别验收，不直接共用身体帧。
2. **逐帧拆件**：从合格完整帧中移除武器并补画被挡住的手、袖、身体；独立提取武器、前手遮挡与后层。与原标准装备重组，逐帧对照完整帧。先让标准装备重组成功，才允许同族换装。
3. **制作武器变体**：以数据库装备 ID 标识具体外观。每件武器提供与动作族一致的帧序和必要视角；沿用同一身体与手部姿势时，只替换武器图层。若新武器改变握距、重心或遮挡，回到第 1 步制作新的动作族或身体变体。
4. **离线合成**：工具读取逐帧图层、握点和遮挡数据，生成 `角色/装备ID/状态` 的完整 PNG 帧图与 SpriteFrames。逐帧检查手指压在握柄前、武器另一段位于身体后、没有旧武器残影。运行时代码仅将当前装备 ID 映射到资源路径并播放状态动画。
5. **接入测试模式与战场**：动画素材测试增加“具体装备 ID/外观”选择、四状态全帧步进、原尺寸/2 倍、深浅背景切换，以及标准装备与替换装备并排对照。战场复用同一成品资源，不能仅在测试模式显示正确。

## 分批验收

第一批以**重剑手双手剑**做重组样板：先用原标准剑精确重组待机、移动、攻击、死亡，再更换第二把同握距双手剑。第二批做精灵弓与另一把同类弓；第三批完成长枪、法典；第四批补单手、盾、剑盾、双持。每批合格后再扩展下一类。

每套交付至少检查：所有帧画布完整；站立帧脚底基线一致、躯干不漂移；双手握点连续，武器长度和透视一致；前后手遮挡正确；待机与移动循环无跳帧；攻击有清楚的准备、命中、收势；死亡有落地终态。自动审计锚点和文件完整性，随后在图形版“动画素材测试”逐状态截 1 倍/2 倍图并人工放大检查，再跑战场装备切换烟测。任何一帧有错位或残影，就退回该帧资源修正，不用代码位移掩盖。

现有装备 PNG 可以充当**武器外观参考**，但需补齐动作视角与逐帧遮挡。现有完整带装备图可用于形象和动作参考，不能直接作为可替换武器的身体层。原始人物资源保持原样作为对照基准。

## 2026-10-07 首批制作进度

重剑手已接入四种动作族：**单手武器、长枪、弓、法典**。单手武器仅制作一套短剑标准动作，后续同族外观更换使用逐帧武器美术替换流程，不为长刀再复制一整套身体动作。每套 `FrameV3/swordmaster_<类别>.png/.tres` 包含 2 帧待机、2 帧移动、2 帧攻击、1 帧受击和 4 帧独立死亡过程。原始生成图保存在 `FrameV3/Sources/`，对应离线打包脚本保存在 `Tools/Art/`。

这四套当前仍是**武器已画入人物的完整帧**，尚未完成身体、武器、前手遮挡逐帧拆分，因此“用任意同族装备 PNG 直接换装”仍未实现。重剑手双手剑保留原有动作与独立倒地图；盾、剑盾、双剑目前仍使用旧预览路径。下一步应优先拿单手短剑验证上文的拆件和离线重组，再增加具体武器外观。
