# 角色局内骨骼动画改造方案

## 一、改造结论

停止继续扩充“整张角色图集 + C# 手工坐标修正”的实现。局内角色改为 **Godot 原生刚性分层骨骼**：身体部件使用独立透明 PNG，挂到 `Skeleton2D / Bone2D`；武器使用独立场景，通过左右手插槽绑定；动作由 `AnimationPlayer + AnimationTree` 驱动。

为保持当前像素/低分辨率质感，不对身体做大面积网格拉伸。大部分部件只做刚性旋转和平移；肘、膝、披风、裙摆在极端动作中允许切换备用部件贴图。该方案属于“骨骼 + 姿势换图”的混合动画。

现有 PNG 图集保留为外观参考和回退资源，在骨骼版本通过验收前不删除。

## 当前实施状态（2026-09-28）

重剑手第一阶段骨骼原型已经建立。首次组装未通过外观验收后，已完成第二轮拆件与握点整改，并重新启用为动画素材测试界面的默认重剑手：

- `Scenes/Characters/SwordmasterRig.tscn`：重剑手独立骨骼场景。
- `Scripts/Presentation/CharacterRig2D.cs`：15 根 `Bone2D`、左右手装备插槽、8 类装备映射以及待机、移动、攻击、受击、死亡动画。
- `Resources/Images/Characters/Rigs/Swordmaster/PartsV2/`：以既有重剑手动作表为身份、服装与比例参考重新生成并裁切的 16 张透明拆件；旧 `Parts/` 只保留作失败版本对照。
- `AnimationPlayer` 已能驱动骨骼；`AnimationTree` 节点已作为后续正式状态机接口保留，当前阶段尚未启用混合树。
- 空手、单手剑、盾、剑盾、双持使用通用人形骨骼；所有双手近战武器共用 `idle_twohand / attack_twohand`；弓和法典分别使用独立持握待机及攻击动画。
- 装备为手部 Socket 子节点，移动、攻击、受击和死亡过程中随手骨骼运动，不再通过角色整图坐标追踪。
- 待机只做胸、头和手臂约 1 度的周期差分，角色根、骨盆和脚底不平移。
- 重剑手死亡由整套骨骼侧倒并停留，不再切换旧倒地整图，因此不会出现旧序列帧残留剑尖。
- 全部武器贴图使用图片内实际握点作为 Sprite 原点：单手剑绕剑柄、双手剑绕主握把、盾绕中心握把旋转，不再绕整张图片中心旋转。
- 第二轮显示根缩放为 `0.78`，局内高度已恢复到原像素角色量级；剑盾使用独立 `idle_guard`，盾位于身体前方。

首次原型存在头身比例改变、肩肘断裂、手臂长度不一致、装备握点不自然等问题，已废弃。第二轮已通过自动资源、待机推进、根节点零漂移、手部随动作移动及图形截图烟测；仍需继续接受实际游戏观感验收。

本阶段继续保留 `PixelHeroActor` 作为测试界面的外层兼容适配器：重剑手默认走第二轮骨骼场景，精灵暂走原序列帧。正式战场角色表现层与精灵骨骼化属于后续阶段。

## 二、目标

1. 待机、移动、攻击、受击、死亡切换时角色脚底和身体中心不跳动。
2. 单手、盾、双持和双手武器严格跟随手部。
3. 所有双手近战武器共用一套双手动作；弓箭、法典各自使用独立动作组。
4. 重剑手与精灵复用骨骼命名、状态机和装备接口，只替换人物部件与少量角色专属动作。
5. 动画素材测试场景和正式六边形战场使用同一个角色表现组件。

## 三、技术选型

### 3.1 当前阶段

- Godot 4.6.2 原生 `Skeleton2D`、`Bone2D`。
- `Sprite2D` 刚性部件，不使用全身 `Polygon2D` 网格蒙皮。
- `AnimationPlayer` 保存动画轨道。
- `AnimationTree` / 状态机处理动作切换。
- C# 组件负责角色、装备和动画命令，不再直接操作每帧像素坐标。

### 3.2 后续兼容

骨骼名、插槽名和装备配置保持数据化。若后续购买 Spine，可将同一套分层 PNG 和动作命名迁移至 Spine；当前阶段不引入商业插件依赖。

## 四、素材生产规格

### 4.1 原始文件

- 分层 PSD/PSB 为美术母版。
- 推荐画布：`256×384` 或其整数倍；角色主体高度约 330 像素。
- Godot 中按约 `0.32` 缩放，使局内站立高度约 106–108 像素。
- 所有被遮挡关节必须补画完整，不能只切割当前可见区域。
- 导出为 RGBA PNG，关闭纹理过滤和 mipmap。

### 4.2 人物部件

```text
root
├─ pelvis
├─ torso
├─ chest
├─ neck
├─ head
│  ├─ hair_back
│  ├─ face
│  ├─ hair_front
│  └─ head_accessory
├─ arm_l_upper / arm_l_lower / hand_l
├─ arm_r_upper / arm_r_lower / hand_r
├─ leg_l_upper / leg_l_lower / foot_l
├─ leg_r_upper / leg_r_lower / foot_r
├─ cape_back / cape_front
├─ skirt_back / skirt_front_l / skirt_front_r
└─ character_accessory
```

重剑手约需 20–24 个身体部件；精灵增加薄纱、发带和分片裙摆，约需 24–30 个部件。

### 4.3 部件元数据

每个部件记录：

- 原 PSD 画布坐标；
- 裁切边界；
- 旋转枢轴；
- 父骨骼；
- 默认 `z_index`；
- 是否允许替换贴图；
- 像素对齐规则。

建议保存为 `character_parts.json`，由 Godot 编辑器工具生成 `.tscn`。

## 五、骨骼与插槽

### 5.1 标准人形骨骼

```text
root
└─ pelvis
   ├─ spine
   │  └─ chest
   │     ├─ neck → head
   │     ├─ clavicle_l → arm_l_upper → arm_l_lower → hand_l
   │     └─ clavicle_r → arm_r_upper → arm_r_lower → hand_r
   ├─ leg_l_upper → leg_l_lower → foot_l
   └─ leg_r_upper → leg_r_lower → foot_r
```

### 5.2 装备插槽

```text
socket_hand_l
socket_hand_r
socket_back
socket_waist
socket_weapon_primary_grip
socket_weapon_secondary_grip
socket_bow_string
socket_projectile_origin
socket_effect_origin
```

武器场景提供主握点和副握点。右手绑定主握点；双手武器再用副握点约束左手。弓箭和法典不复用双手近战姿势。

## 六、武器动作组

| 动作组 | 使用装备 | 规则 |
|---|---|---|
| `Unarmed` | 空手 | 双手自然下垂 |
| `OneHand` | 单手剑、长刀 | 主手攻击，副手自然或持盾 |
| `Shield` | 单盾、剑盾 | 盾始终绑定副手；受击时进入格挡方向 |
| `DualWield` | 双剑 | 两个主握点分别绑定左右手 |
| `TwoHandMelee` | 双手剑、战斧、长枪、双手锤 | 共用双手握持、移动和攻击动作 |
| `Bow` | 弓、弓箭 | 独立待机、持弓移动、拉弦、释放、受击 |
| `Tome` | 魔典、法典 | 独立托书待机、持书移动、抬书施法、释放、受击 |

`WeaponVisualProfile` 至少包含：

```text
DefinitionId
ScenePath
ActionSet
HandsRequired
PrimaryGrip
SecondaryGrip
ProjectileOrigin
EffectScenePath
```

## 七、基础动画

### 7.1 待机

- 1.2–1.8 秒循环。
- `root`、`pelvis` 和脚底禁止平移。
- 胸腔上下不超过 1 个显示像素。
- 头发、披风和薄纱只做 1–2 度旋转。
- 武器插槽随手部移动，不单独漂移。

### 7.2 移动

- 单格移动约 0.32 秒。
- 动画只控制腿、手臂、披风和身体起伏；格间坐标由战场表现层控制。
- 角色根节点采用“起点 → 抬高约 12 px 的中点 → 终点”的两段插值。
- 动画结束后脚底必须准确落在目标格中心。

### 7.3 攻击

- 单手、双持、双手近战分别读取动作组。
- 双手近战左手必须同时满足副握点约束。
- 弓箭包含抬弓、搭箭、拉弦、释放、回稳；箭矢从 `projectile_origin` 生成。
- 法典包含托书、抬书、手势、释放、回稳；符文从 `effect_origin` 生成。
- 伤害触发使用动画事件轨道，不依赖固定延迟猜测。

### 7.4 受击

- 0.20–0.28 秒。
- 角色保持站立，胸部与头部后仰，根节点短距离后退后回位。
- 手持装备随手部运动。
- 不复用死亡姿势。

### 7.5 死亡

- 0.65–0.9 秒，结束后停留。
- 重剑手：失去握力 → 单膝落地 → 侧倒；武器落在身体旁。
- 精灵：失去握弓姿势 → 双膝/单膝落地 → 侧坐或伏倒。
- 死亡状态不可自动返回待机。

## 八、Godot 场景结构

```text
CharacterRig2D (Node2D, CharacterRig2D.cs)
├─ VisualRoot (Node2D)
│  ├─ Skeleton2D
│  │  └─ root (Bone2D)
│  │     └─ ...标准骨骼...
│  ├─ EquipmentBack (Node2D)
│  ├─ EquipmentFront (Node2D)
│  └─ Effects (Node2D)
├─ AnimationPlayer
├─ AnimationTree
├─ Shadow (Sprite2D)
└─ DebugOverlay (Node2D)
```

`CharacterRig2D.cs` 对外只暴露：

```csharp
SetCharacterProfile(profileId)
Equip(left, right)
PlayIdle()
PlayMove(from, to)
PlayAttack(direction)
PlayHurt(direction)
PlayDeath()
```

调用方不直接修改骨骼、贴图位置或装备节点。

## 十二、测试与验收

新增 `--character-rig-smoke` 图形烟测，至少覆盖：

1. 所有角色和武器资源可加载。
2. 待机循环 10 次后 `root`、双脚位置零漂移。
3. 动画切换前后脚底误差不超过 0.5 显示像素。
4. 单手武器主握点误差不超过 1 显示像素。
5. 双手武器两个握点误差均不超过 1 显示像素。
6. 弓弦、箭矢生成点与双手位置正确。
7. 法典与符文生成点正确。
8. 受击可以回到待机，死亡不可回到待机。
9. 装备切换不改变人物骨骼比例和脚底位置。
10. 重剑手与精灵在同一六边形格中的显示高度接近。

烟测截图统一写入 `Tests/character-rig-*.png`，并保留骨骼、插槽和包围盒调试开关。

## 十三、完成标准

- 动画素材测试与正式战场使用同一骨骼角色场景。
- C# 中不再保存逐帧人物中心修正表和武器绝对坐标。
- 所有装备通过插槽和视觉配置加载。
- 双手武器无脱手、穿手或切换跳位。
- 待机无角色整体漂移。
- 动作切换无脚底跳动。
- 构建、单元测试、骨骼图形烟测和战场烟测全部通过。
