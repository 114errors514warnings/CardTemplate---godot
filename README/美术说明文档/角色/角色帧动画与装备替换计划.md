# 角色帧动画与装备替换计划

> 2026-10-05。停止角色骨骼化路线，使用帧动画表现动作与换装。本文件替代此前的骨骼重做、拆件和连接方案。

## 可行性与复用范围

帧动画可以表现待机、移动、攻击、受击、死亡和不同装备。生产成本按“角色 × 持握方式 × 动作”计算；同持握方式的外观装备可复用身体帧，改变持握、动作或服装轮廓的装备需要对应帧。

| 装备/状态 | 可复用内容 | 需要单独制作的内容 |
|---|---|---|
| 同类单手剑、同类盾 | 同一角色、同一动作的身体帧与握点 | 武器/盾的外观与必要的透视帧 |
| 剑盾、双剑 | 对应双手占用方式的身体帧 | 左右装备层、前后手遮挡 |
| 双手剑、斧、锤、枪 | 仅在握距、重心、动作相同且验收通过时复用 | 长枪刺击、重锤挥击等动作族不能直接套用双手剑 |
| 弓 | 持弓、搭箭、拉弦、释放的专属身体帧 | 弓身姿态、弓弦、箭矢与释放特效 |
| 法器/法典 | 对应施法动作族 | 手型、书页/法器姿态与施法特效 |
| 盔甲、长袍、头饰 | 小型挂件可作叠加层 | 改变躯干/裙摆/头部轮廓时重画对应身体帧，不能只盖一张图 |

## 统一制作流程

1. **先生成带指定装备的完整动作。** 每次明确角色、装备类型、视角、动作、帧序和命中/释放时刻。先验收人体动作、双手握点、装备重心与完整轮廓，得到 `equipped_reference`。
2. **从该动作去除装备。** 使用同一套已验收画面作为编辑目标，保留人物位置、姿势、衣服、画布和脚底。补全原来被装备挡住的手、袖口、躯干和衣摆，得到 `body_clean`。不允许用透明洞替代补画。
3. **准备独立装备帧。** 从完整动作确定每帧的装备轮廓与透视。同角度可复用一张装备图；出入画面方向、缩短透视、弓弦变形等需要装备帧，不能只旋转一张 PNG。
4. **建立逐帧挂点和遮挡。** 每帧记录左右握点、装备枢轴、角度/缩放、背面装备层、前手遮挡层、脚底和命中事件。合成顺序为“后部身体 → 后部装备 → 前部身体/手 → 前部装备 → 特效”，按实际姿态调整。
5. **重组对照。** 将 `body_clean + equipment + front_hand` 合成，与带装备参考逐帧对比。人物非编辑区域应保持一致；检查去除是否留下鬼影、重组是否盖住手指、握柄是否滑动。修改身体姿态会影响全部装备时，回到第 1 步。
6. **导出播放资源。** PNG 帧、`SpriteFrames .tres`、挂点/事件数据保存为美术资源。游戏读取角色、装备动作族和动作名称进行播放。身体与装备必须共享同一帧索引和时钟，禁止各播各的造成不同步。

## 画布和验收规范

- 本轮标准画布为单帧 `256×256`，脚底锚点 `(128,228)`，两名角色站立可见高度约 `128 px`；大剑蓄力与挥击允许更大的武器包围盒，但不得越出单帧。
- 每帧以脚底和躯干共同校准水平位置。最新 `packing_report.json` 记录每帧独立修正量；`AuditFrameAnchors.py` 在身体制作稿上验证站立帧脚底均为 `y=228`、脚底中心与躯干中心各距 `x=128` 不超过 6 像素。受击/跪倒帧另按动作终态检查，不套站立中心阈值。
- 图集不再假设生成器能严格对齐七宫格。离线导出根据透明连通部件分离姿势，保留颜色/alpha，并用固定缩放与脚底锚点排版；不在运行时拼接肢体。
- 原尺寸、2 倍和深浅背景检查脸、手、轮廓、脚底和装备。每个动作检查起始、命中/释放、结束，以及循环接缝。技术 PASS 只证明资源与播放链路，不能代替美术验收。
- 每次导出帧图后，依次运行 `python Tools/Art/AuditFrameAnchors.py`、构建与测试、图形版动画素材测试 `--frame-art-smoke`；查看其逐帧固定位置截图与 2 倍攻击截图，再运行 `--animation-material-smoke` 检查实际动作播放。新的移动预览走相邻六边形 `(72,-42)`，并截图、断言落点；截图中的途中位移不能当作图集本身的偏移。
- 同一角色装备切换时头身比例与脚底不跳；两人站立高度差目标 ≤5 显示像素。待机脚底保持固定，移动不得出现身体帧与装备帧错相。
- 生成图中的透明像素可能带有非零 RGB；必须按 alpha 合成后检查。不可只看忽略 alpha 的预览，也不可通过删除不透明的身体像素来清除杂色。

- `Tools/Art/ExportFrameSheets.gd` 是离线打包工具；`packing_report.json` 保存源图哈希、各姿势源区域、脚底锚点和缩放，便于复查。

- 默认双手剑和精灵弓使用改进帧；其他已存在的剑、盾、双剑、弓、法器入口继续使用原有帧与贴图。原型完整资源保留供回归与形象参考。

当前每人有七个关键姿势：2 待机、2 移动、2 攻击、1 受击/跪倒。重剑手继续使用独立倒地图。精灵跪倒不是完整死亡倒地序列；这项与更多动作过渡帧列入下一轮，不能将现有七姿势描述成完整平滑动画。

## 后续执行顺序

1. 先完成重剑手双手剑、精灵弓的 `body_clean + equipment + front_hand` 重组样板，保存逐帧握点和透视装备帧，通过对照后替换当前完整装备帧。
2. 补齐精灵真正的倒地序列，以及两人的攻击准备/收势、移动循环过渡帧；保持角色形象与脚底基线。
3. 按单手、剑盾、双剑、双手近战、弓、法器逐动作族制作；同族外观装备通过挂点数据替换，跨族切换整套身体动作资源。
4. 最后覆盖改变衣服轮廓的装备组合，按实际可见组合制作，不承诺所有装备共用一套人物帧。

## 验证入口

主菜单 → 动画素材测试：切换重剑手/精灵、完整装备帧/去装备人物帧、原尺寸/2 倍，并播放移动、攻击、受击、死亡。`--animation-material-smoke` 验证帧资源与既有装备入口；图形模式导出截图供检查。角色骨骼场景、图集、导出脚本及骨骼烟测入口已撤除。

## 2026-10-07 双手装备动作扩展

当前装备表里的双手武器按动作族接入：双手剑用挥剑动作，长枪用前刺动作，弓与弓箭用拉弦释放动作，魔典与法典用持书施法动作。重剑手和精灵各有这四类完整带装备帧；精灵当前不提供单手剑、盾、双剑的专属动作，测试模式中这些入口禁用。数据库里的普通弓与弓箭共用弓动作，魔典与法典共用法典动作；目前装备表没有双手斧、锤和独立法杖，尚无对应资源。

- 新增 `FrameV2/swordmaster_spear_equipped`、`swordmaster_bow_equipped`、`swordmaster_tome_equipped` 与 `isera_spear_equipped`、`isera_tome_equipped`、`isera_greatsword_equipped` 六套 PNG 和 SpriteFrames。精灵弓、重剑手双手剑继续使用现有改进帧。重剑手弓与法典来自原型完整动作图的统一规格打包，长枪及精灵三套新动作的生成原图保存在 `FrameV2/Sources/`。
- 资源是七个完整关键姿势，不在游戏代码中控制骨骼。离线工具 `Tools/Art/ExpandEquipmentFrames.gd` 逐帧分离和对齐；游戏按装备类别选择 `.tres` 播放。长枪使用 `384×256`、精灵双手剑使用 `320×256` 的透明单帧宽度，以容纳武器完整伸展；角色仍在单帧中心。其他新增单帧为 `256×256`。
- 所有新增帧可见脚底均为 `y=228`，躯干水平中心偏差不超过 6 像素。`Tools/Art/AuditFrameAnchors.py` 对这两项逐帧断言。制作时对长枪攻击的躯干中心做了逐帧修正，避免出枪时人物整体平移。
- 已在图形版“动画素材测试”检查四类装备、两名角色、待机与攻击准备/命中帧的 1 倍及 2 倍截图；截图保存在 `Tests/equipment-<角色>-<装备>-<帧>-<倍数>.png`。`--frame-art-smoke`、`--animation-material-smoke`、`--battlefield-smoke` 均通过。图形烟测增加资源加载断言，避免资源缺失却仍报 PASS。

当前七帧里的第七帧用于受击或跪倒；除重剑手原双手剑的独立倒地图外，其他装备的“死亡”仍是跪倒终态，未达到独立倒地动画的完成标准。新动作是完整带装备帧，尚未拆成 `body_clean + equipment + front_hand` 可重组组合；后续变更同持握类武器外观前，需按上方统一制作流程逐帧制作并验证。
