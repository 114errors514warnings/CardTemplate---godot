# 战斗规则（BattleRule）

> 关卡级"战斗规则"机制：规则做成**枚举**，作为**关卡级变量**挂在单关卡 CSV 上，可跨关卡复用。
> 当前只实现了一个钩子（意图选择）与一条规则（`BanditEscalation`），后续规则按需再加钩子。

## 一、关卡级变量

| 项 | 内容 |
|---|---|
| 位置 | 单关卡 CSV 第 13 列 `BattleRule`（表头/字段约束见[配表规范](../数据系统/数据配置/配表规范.md)） |
| 取值 | `BattleRuleKind` 枚举名；多个用 `\|` 分隔；留空/缺列 = 无额外规则 |
| 约束 | 同一关卡内所有行必须一致；未知规则名报错 |
| 复用 | 规则**不绑地图、不绑关卡 ID**：任何关卡填上枚举名即可生效；不填则完全沿用原有行为 |

生效链路：

```
关卡 CSV 第 13 列 BattleRule
  → BattleLevelCatalog.Parse              解析成 BattleRuleKind 列表（校验全行一致）
  → BattleLevelConfig.Rules               关卡级变量
  → BattleLevelCatalog.ApplyMonstersTo    透传
  → BattleMapDefinition.Rules             战斗定义上的规则标识
  → BattlefieldSession 构造               BattleRuleRegistry.Create 建规则实例
  → PrepareEnemyIntentions()             规则钩子参与意图选择（无规则 = 均匀随机）
```

## 二、钩子与规则

- 接口 `IBattleRule` 当前只有 **`TrySelectIntention(IntentSelectionContext)`**（返回 `true` = 已决定用哪一列意图）。
- 上下文包含：`Round`（第几个玩家回合）、`IntentBatch`（第几个怪物回合的意图批次，从 1 起）、`EnemyId`、`Monster`、`Candidates`（非空意图列）、`HitPlayerCount`（累计命中玩家次数，含被格挡）、`Random`、`SelectedIndex`。
- 已实现规则 `BanditEscalation`（劫匪升级节奏）：低攻起步 → 门槛批次必定高攻 → 之后等概率；命中达阈值后按概率切逃跑，进入后**锁定**，并从下一批次起**传染**给同类意图的敌人。阈值与意图列位置集中在该类的常量里。
- 只接手"低攻/高攻/逃跑三列意图齐全"的怪物；其它怪物不会被该规则接管。

## 三、跑步（Flee）行为

- `EnemyIntent.csv` 的 `Behavior=Flee` 行表示该意图**不索敌、不攻击**：按 `MoveBudget` 朝最近地图边界（半径 = 地图 `Radius` 的最外圈格点）逐步移动。
- 站在边界格时立即离场；移动到位后离场。
- 离场走 `BattlefieldPresence.Departed`（不是 `Defeated`）：不再被索敌、不再参与意图准备；**结算不会把它算作被击杀**（被窃金币不返还）。
- 头顶预览按行为分类：`Attack` 显示伤害数字，非攻击行为显示 `逃跑`。

## 四、验证入口

- 单测 `Tests/BattleRuleTests.cs`：枚举解析、关卡列一致性与报错、规则不介入的分支、门槛批次、命中阈值与锁定、传染从下一批次生效。
- 无界面自检 `BattlefieldSceneSmoke.VerifyBattleRules()`：关卡列 → 规则挂载 → 批次 1/2 低攻、批次 3 高攻、逃跑意图离场（`Departed`）→ 输出 `BATTLEFIELD_BATTLE_RULE_PASS`。
