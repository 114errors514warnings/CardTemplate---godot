# AI API 跑测使用说明

## 启动

正常进入六边形战斗场景后，调用：

```http
GET http://127.0.0.1:17880/api/game/
```

成功响应 `ok=true` 即可开始。

## 玩家操作示例

选择角色：

```json
{"type":"battle.select_unit","unitId":1}
```

移动：

```json
{
  "type":"battle.move",
  "path":[{"q":-1,"r":0}]
}
```

出牌：

```json
{
  "type":"battle.play_card",
  "cardId":11001001,
  "hasTarget":true,
  "q":1,
  "r":0
}
```

拾取与装备：

```json
{"type":"battle.pick_item","instanceId":"fixed-1","slot":0}
{"type":"battle.equip","instanceId":"fixed-2","hand":"left"}
```

## 推荐跑测流程

1. `battle.state` 保存初始快照。
2. 常规轮询使用摘要 `battle.state`；仅在排查时以 `detail:"full"` 请求完整快照。
3. 使用 `battle.legal_move`、`battle.preview_move` 或 `battle.legal_card` 按需查询，不枚举整图路径和全部卡牌目标。
3. 只调用其中允许的玩家操作。
4. 每次操作后调用 `battle.state`，比较 HP、资源、手牌、装备、道具和坐标变化。
5. `battle.end_turn` 后轮询 `battle.wait_idle`。
6. 空闲后调用 `battle.events` 检查怪物移动、攻击、状态和胜负事件。
7. 在初始、装备、道具、怪物回合和胜负等关键节点调用 `battle.capture`。
8. 要测试下一批随机手牌或意图时，正常退出并重新进入战斗；不通过 API 修改牌堆或怪物。

## 已实测覆盖（2026-09-15）

- 状态、合法操作、事件、空闲状态、截图；
- 角色切换与移动；
- 治疗药剂拾取和使用；
- 行军短剑、长刀、长枪、魔典、弓的正常拾取、装备与卸装；
- 目标型石头道具投掷；
- 多个自然抽到的技能、攻击和状态牌；
- 多次结束回合、怪物行动完成与回到玩家回合。
