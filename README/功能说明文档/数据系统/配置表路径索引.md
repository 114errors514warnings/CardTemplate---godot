# 配置表路径索引

本表记录当前实际加载的配置路径。新增核心配置时，应同时登记 `DataBase/FilePathRegistry.csv` 与本索引。

| 类型 | 路径键 | 实际路径 | 加载入口 | 说明 |
|---|---|---|---|---|
| 武器 | `Data.Equipment.Weapon` | `DataBase/Equipment/Weapon.csv` | `BattleWeaponCatalog` | 武器攻击方式、距离、防御与修正值；`AttackMode` 必须使用 `WeaponAttackMode` 枚举名。 |
| 战场验证地图 | `Data.Battlefield.Foundation` | `DataBase/Battlefield/FoundationMap.json` | `BattleMapDefinition` | 六边形格、出生、固定物件与随机生成参数。 |
| 通用卡牌 | `Data.Card.Common` | `DataBase/Card/通用/通用Card.csv` | `LoadingSystem` | 卡牌目录同时支持递归扫描。 |
| 角色 | `Data.Unit.Character` | `DataBase/Unit/Character.csv` | `LoadingSystem` | 人物基础属性。 |
| 游戏变量 | `Data.Game.Variables` | `DataBase/GameVariables.csv` | `GameVariables` | 每回合默认能量、默认抽牌张数、按角色配置的移动次数。 |
| 怪物 | `Data.Unit.Monster` | `DataBase/Unit/Monster.csv` | `LoadingSystem` | 旧版怪物定义；战场专用意图表待建立。 |
| 状态 | `Data.State.Common` | `DataBase/State/通用State.csv` | `LoadingSystem` | 状态与衰减定义。 |
| 正式关卡索引 | （待登记）| `DataBase/Level/LevelIndex.csv` | `BattleLevelCatalog` | `LevelId` → `ConfigPath` 映射；单关卡在 `Level/Config/<LevelId>.csv`。旧 `DataBase/Stage` 已废弃。 |
| 正式地图索引 | （待登记）| `DataBase/BattleMap/MapIndex.csv` | `BattleMapDefinition` | `MapId` → 地图 JSON；单地图在 `BattleMap/Maps/<MapId>.json`。 |
| 掉落表索引 | （待登记）| `DataBase/Reward/DropTableIndex.csv` | `LoadingSystem` | `DropTableId` → 奖励 CSV；单表在 `Reward/Config/<DropTableId>.csv`。 |
| 战场意图 | `Data.Battlefield.EnemyIntent` | `DataBase/Battlefield/EnemyIntent.csv` | `BattleEnemyIntentCatalog` | 怪物意图的空间攻击方式、移动与索敌。 |
| 掉落表 | `Data.Map.DropTable` | `DataBase/Map/DropTable.csv` | `LoadingSystem` | 战利品掉落配置。 |

完整路径注册表见 [FilePathRegistry.csv](../DataBase/FilePathRegistry.csv)。
