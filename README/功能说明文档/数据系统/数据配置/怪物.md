# 怪物配置

## 配置路径与职责

| 文件 | 职责 |
|---|---|
| `DataBase/Unit/Monster.csv` | 模板属性与每个意图的实际效果 |
| `DataBase/Battlefield/EnemyIntent.csv` | 意图的空间攻击方式、移动、索敌和预览规则 |
| `DataBase/Stage/<层>/<节点类型>.csv` | 将怪物 ID 编组成具体遭遇 |

## Monster.csv

```csv
id,Name,MAX_HP,Ini_Attack,Ini_Defend,Intention1,...,Intention10
```

- 前五列是模板 ID、名称、生命、基础攻击、基础防御。
- 每个 `IntentionN` 可包含多个效果，以 `|` 分隔；单个效果参数以 `;` 分隔。
- 第一个数为 `EffectType`：`1=Damage`、`2=Shield`、`3=AddState`。
- `Damage` 使用怪物攻击力加额外参数；`Shield` 使用怪物防御力加额外参数。

加载链：`LoadingSystem.LoadMonstersByKey()` → `LoadMonsterCsv.LoadMonstersFromCSV()` → `LoadingSystem.MonsterDictionary` → `BattlefieldSession` 按遭遇 `MonsterIds` 实例化 `MonsterInstance`。

**怪物的初始生命与初始状态不在本表配置**，而在单关卡 CSV 的 `InitialValue` 列（如 `State=1:2|HP=12`、`State=Steal:1`），
开局实例化怪物时由 `UnitInitialStateConfig` 写入；完整语法、容错与示例见[对象初始值](对象初始值.md)。

意图列可以写 `0`（`EffectType.None`）：该意图没有任何效果，用于"非攻击意图"占位（例如逃跑）；
配合 `EnemyIntent.csv` 的 `Behavior=Flee` 行，怪物会转而朝最近边界移动并在抵达后离场，规则见[战斗规则](../../战斗系统/战斗规则.md)。

## EnemyIntent.csv

```csv
MonsterId,IntentionIndex,PreviewCertainty,AttackMode,AttackRange,MoveBudget,ActionBudget,ActionOrder,TargetPolicy,AreaRadius,PreviewDirection
```

| 字段 | 说明 |
|---|---|
| `MonsterId` / `IntentionIndex` | 对应 `Monster.csv` 的怪物与第几个意图；索引从 0 开始 |
| `PreviewCertainty` | `UnknownNumbers`、`KnownDamageUnknownRange`、`KnownDamageKnownRange` |
| `AttackMode` | `AdjacentSingle`、`MeleeLine`、`RangedLine`、`ThrowSingle`、`Fan`、`Thrust` 等 |
| `AttackRange` | 攻击距离或直线最大长度 |
| `MoveBudget` | 本次怪物行动可走的格数 |
| `ActionBudget` | 行动数预览预算；0 表示沿用效果/意图表现 |
| `ActionOrder` | `MoveThenAttack` 或 `AttackThenMove` |
| `TargetPolicy` | `Nearest`、`ThrowAreaDense`、`ThrustNearestCollinear`、`AllyRange` 等 |
| `AreaRadius` | 投掷范围半径；非范围攻击填 0 |
| `PreviewDirection` | 已知范围预览的轴向方向，如 `1;0`；没有则留空 |

`BattleEnemyIntentCatalog` 读取此表，`EnemyIntentPlanner` 根据空间规则规划移动与攻击，`BattlefieldSession` 执行 `Monster.csv` 里的实际效果。
