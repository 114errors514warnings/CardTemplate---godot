# 怪物配置

## 配置路径与职责

| 文件 | 职责 |
|---|---|
| `DataBase/Unit/Monster.csv` | 模板属性与每个意图的实际效果 |
| `DataBase/Battlefield/EnemyIntent.csv` | 意图的空间攻击方式、移动、索敌和预览规则 |
| `DataBase/Stage/<层>/<节点类型>.csv`（旧体系，2026-09-30 已归档到 `_archive/DataBase-Stage-2026-09-30/`） | 将怪物 ID 编组成具体遭遇 |

## Monster.csv

```csv
id,Name,MAX_HP,Ini_Attack,Ini_Defend,Intention1,...,Intention10[,IsMinion]
```

- 前五列是模板 ID、名称、生命、基础攻击、基础防御。
- 每个 `IntentionN` 可包含多个效果，以 `|` 分隔；单个效果参数以 `;` 分隔。
- 第一个数为 `EffectType`：`1=Damage`、`2=Shield`、`3=AddState`。
- `Damage` 使用怪物攻击力加额外参数；`Shield` 使用怪物防御力加额外参数。
- **额外参数（两元素 vs 三元素）**：
  - `1;<修正值>` / `2;<修正值>`：修正值直接加在攻击力 / 防御力上（`1;-1` = 攻击力 − 1、`2;1` = 防御力 + 1）。
  - `1;<MonsterDamageTargetMode>;<修正值>`：**至少两个额外参数时**，首参才被解释为伤害目标模式（`1` = 每次 `Damage` 各自随机选目标、`2` = 同意图内多次 `Damage` 共用同一随机目标），修正值取第三位；例：`1;2;0` = 共用目标 + 0 修正。
  - `3;<EffectTargetType>;<StateType>;<层数>`：状态段（`1;6;2` = 对自身加 2 层 `AddAttack`；`2;1;2` = 给本次意图最近一次命中的目标加 2 层 `Vulnerable`）。
  - **目标类型取值**：`0 = Auto`（**随机一名角色**；六边形战场按本意图的索敌目标结算）、`1 = Self`、`2 = SelectedTarget`（本意图最近一次命中的目标）、`3 = AllEnemies`（全体角色）、`4 = AllUnits`。
  - ⚠️ **纯状态意图（意图里没有伤害段）不能用 `2`**：`SelectedTarget` 依赖「本意图最近命中的目标」，没有伤害段就解析不出目标 → 状态会被静默跳过。纯弱化请写 `0`（随机一名角色）或 `3`（全体角色）。
  - ✅ **`0` 的收口（2026-10-01）**：旧卡牌战斗路径（`MonsterIntentionService`）此前把 `0` 落到 `default`（= **自身**），使 `3101` / `3107` / `3112` 的「对角色施加易伤 / 虚弱」实际加在怪物自己身上（玩家反而吃到 ×1.5 增伤）；现与 `BattleUnitRegistry.ResolveEffectTargets` 的 `Auto` 口径统一为**随机一名角色**。回归断言：`--battlefield-smoke` 的 `BATTLEFIELD_MONSTER_STATE_TARGET_PASS`。
- ✅ **旧池 `3003` / `3007` 的写法收尾（2026-09-28）**：这两行原先写作两元素 `1;2|1;2|1;2`（`3007` 为 `1;2|1;2`），按上面的规则会被读成「伤害修正值 +2」，与[怪物属性与强度](../../../玩法说明文档/怪物设计/怪物属性与强度.md) 的设计意图（「固定命中同一随机目标的三连击 / 二连击」）不符 → 已改写为**显式三元素** `1;2;0|1;2;0|1;2;0`（`3007`：`1;2;0|1;2;0`），即「同意图共用同一随机目标 + 0 修正」。**写法规范**：只要还想表达目标模式就写三元素、别省末位 0；两元素 `1;<修正值>` 只用于真·伤害修正（3113 横扫 `1;2`、3115 低攻 `1;-1` 等）。连带把缺失的 `3007` 两行补进 `EnemyIntent.csv`（取值 = 原隐式回退规格 `AdjacentSingle / 射程 1 / 移动 2 / MoveThenAttack / Nearest`，**行为不变**，只是不再依赖回退）。
- ✅ **已修复（2026-09-28）**：六边形战场改走统一取参 `EnemyIntentDamageArgs`（两元素 `1;<修正值>` = 攻击力 + 修正、三元素起第 2 位才是目标模式），**执行与意图预览同一口径**；3115 低攻 4 / 高攻 6、3114 借势格挡 13 / 横扫 15、3106 / 3107 / 3111 的修正值均生效。落地记录见[9 月施工文档 §34](../../../施工文档/2026/2026.09/9月施工文档.md)，取参单测见 `Tests/EnemyIntentDamageArgsTests.cs`；意图价值口径见[单位数值平衡标准 §2.3](../../../玩法说明文档/系统规则/数值平衡/单位数值平衡标准.md)。

- **`IsMinion`（是否为爪牙）—— 可选的末列**：`1` / `true` / `yes` / `是` / `爪牙` = 爪牙，`0` / 空 = 普通敌人（完整取值见 `MonsterCsvSchema`）。**列位置无关**（表头按 `IsMinion` / `是否爪牙` 定位），但必须**追加在 `Intention1..10` 之后**（意图列按固定偏移解析）；旧表没有这一列时**全部按非爪牙**（向后兼容）。
  - 语义：爪牙**不属于默认通关必杀目标**、**不计入非生存关卡的战利品价值比例**，但参与普通行动 / 受击 / 状态 / 伤害结算（[六边形战场玩法 §7.5](../../../玩法说明文档/系统规则/战斗系统/六边形战场玩法.md)）。
  - 数据流：`Monster.csv` → `Monster.IsMinion` → `MonsterInstance`（战场实例继承）→ `RunBattleScene.ComputeDefeatValueRatio` 的 `EnemyValueSample(..., IsMinion)`（爪牙既不在分子也不在分母）。列结构 / 取值解析在 `Scripts/System/Modules/Loading/MonsterCsvSchema.cs`（纯逻辑，单测 `Tests/MonsterCsvSchemaTests.cs`）。
  - 现状：**所有怪物都是 `0`**（爪牙内容未设计）；歼灭关的「非爪牙全退场即胜」（玩法 §7.1）**尚未拆分**，爪牙目前仍会挡住胜利判定。落地记录见[9 月施工文档 §35](../../../施工文档/2026/2026.09/9月施工文档.md)。

加载链：`LoadingSystem.LoadMonstersByKey()` → `LoadMonsterCsv.LoadMonstersFromCSV()`（逐行解析走 `ParseMonstersFromLines`，表头用于定位 `IsMinion` 列）→ `LoadingSystem.MonsterDictionary` → `BattlefieldSession` 按遭遇 `MonsterIds` 实例化 `MonsterInstance`。

**怪物的初始生命与初始状态不在本表配置**，而在单关卡 CSV 的 `InitialValue` 列（如 `State=1:2|HP=12`、`State=Steal:1`），
开局实例化怪物时由 `UnitInitialStateConfig` 写入；完整语法、容错与示例见[对象初始值](对象初始值.md)。

意图列可以写 `0`（`EffectType.None`）：该意图没有任何效果，用于"非攻击意图"占位（例如逃跑）；
配合 `EnemyIntent.csv` 的 `Behavior=Flee` 行，怪物会转而朝最近边界移动并在抵达后离场，规则见[战斗规则](../../战斗系统/战斗规则.md)。

## EnemyIntent.csv

```csv
MonsterId,IntentionIndex,PreviewCertainty,AttackMode,AttackRange,MoveBudget,ActionBudget,ActionOrder,TargetPolicy,AreaRadius,PreviewDirection
```

| 字段 | 说明 |
|---|---|
| `MonsterId` / `IntentionIndex` | 对应 `Monster.csv` 的怪物与第几个意图；索引从 0 开始 |
| `PreviewCertainty` | `UnknownNumbers`、`KnownDamageUnknownRange`、`KnownDamageKnownRange` |
| `AttackMode` | `AdjacentSingle`、`MeleeLine`、`RangedLine`、`ThrowSingle`、`Fan`、`Thrust` 等 |
| `AttackRange` | 攻击距离或直线最大长度 |
| `MoveBudget` | 本次怪物行动可走的格数 |
| `ActionBudget` | 行动数预览预算；0 表示沿用效果/意图表现 |
| `ActionOrder` | `MoveThenAttack` 或 `AttackThenMove` |
| `TargetPolicy` | `Nearest`、`ThrowAreaDense`、`ThrustNearestCollinear`、`AllyRange` 等 |
| `AreaRadius` | 投掷范围半径；非范围攻击填 0 |
| `PreviewDirection` | 已知范围预览的轴向方向，如 `1;0`；没有则留空 |

`BattleEnemyIntentCatalog` 读取此表，`EnemyIntentPlanner` 根据空间规则规划移动与攻击，`BattlefieldSession` 执行 `Monster.csv` 里的实际效果。
