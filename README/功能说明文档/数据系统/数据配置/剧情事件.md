# 剧情事件 JSON 配置

事件采用“一事件一 JSON”。

```text
DataBase/Story/EventIndex.csv
DataBase/Story/Events/<EventId>.json
```

`EventIndex.csv` 固定表头：

```csv
EventId,ConfigPath
```

JSON 顶层字段：`schemaVersion`、`eventId`、`title`、`summary`、`battleMapId`、`canSkip`、`background`、`actors`、`timeline`、`choices`。

- `summary` 是跳过剧情版显示的完整梗概。
- `battleMapId` 是事件剧情 UI 下方加载的六边形背景地图；必须存在于 `DataBase/BattleMap/MapIndex.csv`。未填写时使用 `M-EVENT-EMPTY` 空地图。
- `background.backgroundId` 对应 `Resources/Images/UI/Story/Backgrounds/<backgroundId>.png`；所有图片资源的目录规范见[工程规范](../../工程规范/README.md)。
- `actors` 配置 `actorId`、`displayName`、`portraitId`、`defaultSide`、`variants`。
- `timeline` 按 `order` 排列；当前加载 `Dialogue`、`Narration` 节点，字段为 `actorId`、`side`、`portraitVariant`、`bubbleStyle`、`text`、`autoDelay`。
- `choices` 配置 `choiceId`、`order`、`text`、`effectPreview`、`effects`、`next`。`effectPreview` 会显示在选项文本后的括号中。
- `effects` 当前已执行 `HpDelta/SelectedPlayer` 与 `GoldDelta/Run`；其他效果类型必须在执行器接入后才能用于正式事件。

当前测试事件见 `DataBase/Story/Events/EVT-F1-001.json`，剧情测试按钮直接读取该文件。JSON 读取入口为 `Scripts/Story/StoryEventCatalog.cs`，UI 入口为 `Scripts/Story/EventStoryOverlay.cs`。随机事件节点由 `DataBase/WorldMap/EventPool.csv` 选择 `EventId`；当前 `ConditionId` 仅为保留列，必须留空，具体条件枚举与过滤逻辑在有事件需求时再接入。

已登记事件的 `NodeType` 对应关系：

| EventId | NodeType | 事件 | 说明 |
|---|---|---|---|
| EVT-F1-001 | NormalEvent / DangerousEvent / Merchant | 夜路抉择 | 测试事件 |
| EVT-F1-011 | NormalEvent | 余响的符碑 | 普通事件 |
| EVT-F1-012 | NormalEvent | 断裂的吊桥 | 普通事件 |
| EVT-F1-013 | NormalEvent | 倾覆货车旁的储粮窖 | 普通事件 |
| EVT-F1-016 | DangerousEvent | 流寇的过路费 | 危险事件（等价纯减益形态，不进入战斗）|

- 事件节点不可放弃：`choices` 至少 2 项，且不提供「离开 / 放弃节点」选项；同一事件内所有选项的净价值必须落在同一区间。
- `effectPreview` 会被 `StoryEventCatalog.Validate` 强制校验为非空，因此正式事件的选项结果一律对玩家公开。
- 事件货币价格表与选项配平规则见 [事件系统](../../../玩法说明文档/系统规则/事件系统/事件系统.md)。
