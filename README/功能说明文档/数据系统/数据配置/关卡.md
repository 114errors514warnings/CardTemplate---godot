# 关卡与遭遇配置

## 现有路径

| 配置 | 路径 | 用途 |
|---|---|---|
| 第一层普通敌袭 | `DataBase/Stage/第一层/普通敌袭.csv` | 按普通敌袭场次数选 Low / Mid / High 编组 |
| 第一层高危敌袭 | `DataBase/Stage/第一层/高危敌袭.csv` | 高危战斗节点的编组 |
| 其他层与节点 | `DataBase/Stage/<层>/<节点类型>.csv` | Boss、精英、事件、村庄等节点的配置位置 |
| 掉落表 | `DataBase/Map/DropTable.csv` | 遭遇的 `DropTableId` 对应奖励 |

所有 Stage CSV 当前列为：

```csv
Name,Difficulty,MonsterIds,DropTableId,Weight,Note
```

| 列 | 格式 | 说明 |
|---|---|---|
| `Name` | 文本 | 遭遇名称与结算标题 |
| `Difficulty` | `Low` / `Mid` / `High` / `Any` | 普通敌袭按档位过滤；其他节点通常使用 `Any` |
| `MonsterIds` | `ID|ID|ID` | 本场生成的怪物模板 ID，允许重复 |
| `DropTableId` | 整数 | 掉落表 ID |
| `Weight` | 正整数 | 同档位多条配置的加权随机权重 |
| `Note` | 文本 | 设计说明，不参与运行时规则 |

## 加载与选择

1. `LoadingSystem.EnsureAllDataLoaded()` 调用 `LoadStageEncounters()`。
2. `LoadStageEncounterCsv.LoadRowsFromCSV()` 解析每个 Stage CSV 为 `StageEncounterRow`。
3. 地图点击节点时，`MapScene.TryResolveEncounter()` 调用 `LoadingSystem.TryPickStageEncounter()`。
4. 普通敌袭由 `StageEncounterPicker.ResolveNormalCombatDifficultyByEncounterCount()` 决定档位：第 1–3 场为 Low、第 4–5 场为 Mid、第 6 场起为 High。
5. 选中行写入 `RunSession.PendingEncounter` 及存档；正式 `RunBattleScene` 使用其中的 `MonsterIds` 创建六边形战斗。

因此，一场战斗只生成被选中行中的怪物，不会把同一 CSV 的其他行或其他难度档位一并生成。例如首场出现 3101×3，是 Low 行“符文残响”被选中后的正常结果。
