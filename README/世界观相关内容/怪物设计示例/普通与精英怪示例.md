# 普通与精英怪示例

> 各层普通怪 / 精英怪的方向性示例（**不是**正式数值来源：数值见 [怪物总表](../../玩法说明文档/怪物设计/怪物总表.md)，遭遇见 [关卡设计](../../玩法说明文档/关卡设计/README.md)）。
> 怪物类别的定义见 [怪物类别](怪物类别.md)；区域生态与原型模板见 [符文之地设计指引](符文之地设计指引/README.md)。

## 第一层

- 前半段发生在符文之地外围的村舍、城镇与野外，普通怪以受灾居民、魔化野兽、流寇及低阶原生体为主；不应过早大量投放机构内部的奥术守卫或高阶法师。
- 接近机构本体后，逐步引入小／中型魔力原生体、狂暴法师学徒、狂暴法师、伏魔护卫、符文兽与活化铠甲。
- **精英怪**：符文兽、兼用近战与法术的奥术守卫、可在被击败后复活的活化铠甲。
- 具体区域生态、敌人原型和关卡组合见 `符文之地设计指引/`。

### 第一层 Boss 形象（设计红线的来源）

| Boss | 形象关键点 | 由此产生的设计限制 |
|---|---|---|
| [卡珊德拉](第一层-卡珊德拉.md) | 悬浮的大法师、周身环绕不断浮现又破灭的**幻象水晶** | 外围与机构外缘的普通怪不要再用「悬浮法师 + 幻象 / 预言 / 水晶」这套形象 |
| [汲能者](第一层-汲能者.md) | **虹彩能量漩涡**、纯粹能量生命、无意识但会吞噬魔力持续生长 | 不要再用「纯能量漩涡 / 虹彩 / 无限成长的魔力原生体」作为普通怪（**史莱姆等有质体的黏液系可以继续复用**）|
| [磐石巨像](第一层-磐石巨像.md) | 黑曜石 + 魔法宝石构成的**巨型**类人构装体、破石翼、胸口奥术引擎、守护大门 | 不要再用「巨型石质 / 宝石构装体」；普通构装怪限定为**人形单兵体型**（如活化铠甲）|

### 第一层高等档普通敌袭的三条新轴（2026-10-01 落地）

| 新怪 | 形象 / 来源 | 补的轴 | 与 Boss 的区分要点 |
|---|---|---|---|
| [伏魔护卫](第一层-伏魔护卫.md) | 人类制式护卫，符纹长矛 | 近战**直线**封锁（距离 3）+ 进攻型前排 | 人形活体，无宝石 / 无石翼 / 不悬浮 |
| [失控哨戒装置](第一层-失控哨戒装置.md) | 固定在地上的低矮符柱，脉冲外溢 | **纯弱化**（0 伤害、2 层虚弱）+ 友方护盾 | 有实体的固定设备，不变形 / 不吞魔力 |
| [酸蚀黏液](第一层-酸蚀黏液.md) | 带蚀痕的浑浊黏液团，渗酸雾 | **易伤放大器**（可堆叠） | 有质体黏液（史莱姆系复用），非能量体 |
| [活化铠甲](第一层-活化铠甲.md) | 人形单兵空壳铠甲，关节咬合光缝 | 高单点近战（8 伤）+ 高血前排 | 单兵体型，无石翼 / 无宝石 / 不复活（复活留给精英档）|

## 第二层

- 精英怪方向：兽化德鲁伊、可操控玩家的荆棘斥候、能召唤爪牙的腐化精灵头领。

## 第三层

- 精英怪方向：全图位移的公主幽魂、大臣亲属卫队（卫队与术士）、可召唤巨兽且兼用远近战的斗兽狂徒。
