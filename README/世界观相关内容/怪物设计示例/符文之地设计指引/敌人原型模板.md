# 敌人原型模板

每个新怪物至少填写以下项目，避免只从技能或数值反推设定。

```markdown
# 名称

## 基本归属
- 区域：外围生活圈 / 进场道路 / 居住警戒区 / 研习实验区
- 来源：居民、野兽、流寇、学徒、守卫、构装体、炼金事故、原生体
- 受潮汐影响阶段：轻度 / 中度 / 重度 / 非浸染（如流寇）

## 叙事与视觉
- 灾变前身份或功能：
- 为何出现在这里：
- 外观识别点：
- 关卡中传达的信息：

## 战斗定位
- 定位：近战、远程、控制、护卫、召唤、骚扰、逃跑、目标单位等
- 行动理由：技能如何来自原身份、环境或异变：
- 与同场敌人的配合：
- 击败/撤离后的叙事结果与掉落理由：

## 校验
- 是否与区域功能相符：
- 是否与潮汐阶段相符：
- 是否与已有同类重复：
```

## 示例：失控材料搬运傀儡

- **区域**：进场道路或材料仓外部；**来源**：构装体；**阶段**：中度。
- **来历**：原本负责将炼金材料送往工坊，结界失效后仍机械执行“运送/排除障碍”的指令。
- **战斗定位**：直线冲撞与推开单位；可撞碎临时路障，但不应拥有高阶法师式法术。
- **叙事用途**：说明机构后勤与封锁已失控，并为进入材料库建立线索。
