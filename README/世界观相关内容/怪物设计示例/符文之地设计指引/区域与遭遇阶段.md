# 区域与遭遇阶段

## A. 外围生活圈（前半段）

**地点**：村舍、城镇边缘、道路、农地、林地、野外营地。

**叙事任务**：展示灾变如何波及普通人和日常生活；玩家尚未进入符文之地本体。

**优先敌源**：受轻/中度浸染的居民与旅人、魔化野兽、窃贼和强盗、零散低阶魔力原生体。

**避免事项**：大批奥术守卫、高阶法师、完整的实验室产物；这些会过早暴露机构核心，也削弱后续区域差异。

**目标示例**：护送平民、守住物资车、在增援到来前清除路障、阻止窃贼带走补给。

## B. 外围设施与进场道路（中段）

**地点**：检查哨、废弃驿站、货运道路、结界外缘、材料仓外部。

**叙事任务**：让玩家意识到机构曾试图隔离灾害，但封锁正在瓦解。

**优先敌源**：伏魔护卫、失控低阶结界装置、携带材料逃离的人员、受污染的运输兽，以及少量原生体。

**目标示例**：关闭泄漏节点、夺取通行符文、在结界崩溃前撤离、阻止敌人逃向聚落。

## C. 机构外缘：居住、警戒与收容区（后段）

**地点**：宿舍、食堂、庭院、守卫哨所、收容室和大门。

**叙事任务**：呈现法师共同体的生活被中断，以及防卫系统由保护转为威胁。

**优先敌源**：失控学徒、伏魔护卫、活化铠甲、逃逸收容物和中型原生体。

**目标示例**：保护幸存者、解除失控哨戒、压制逃逸试验品、在封门前穿越区域。

## D. 机构核心：研习、实验与炼金区（核心段）

**地点**：讲堂、档案室、观测室、符文实验室、炼金工坊、材料库。

**叙事任务**：直接揭示潮汐研究、失控实验和源头线索。

**优先敌源**：狂暴法师、奥术守卫、符文兽、活化构装体、炼金异变体和大型原生体。

**目标示例**：打断仪式、回收危险档案、关闭炼金反应、阻止 Boss 吸收能量。
