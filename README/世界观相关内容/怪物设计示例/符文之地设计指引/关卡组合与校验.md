# 关卡组合与校验

## 组合原则

- 每场战斗先确定一个**地点主题**，再选 1 个主敌源和至多 1 个辅助敌源。
- 前半段的威胁来自灾变波及与社会秩序崩溃；后半段才逐渐转为机构内部的魔法事故与防卫失控。
- 精英关应强化区域核心矛盾，而非只是堆叠高权重敌人：村落精英可围绕保护/撤离，收容区精英可围绕封锁/逃逸，实验区精英可围绕仪式/泄漏。

## 遭遇组合示例

| 地点 | 主敌源 | 辅助敌源 | 可用目标 |
|---|---|---|---|
| 被遗弃的村舍 | 受灾居民 | 魔化野兽 | 护送幸存者离开，避免伤及平民。 |
| 商路检查哨 | 流寇 | 失控哨戒装置 | 守住补给或夺取通行符文。 |
| 结界外缘 | 伏魔护卫 | 小型原生体 | 在泄漏扩大前关闭节点。 |
| 学徒宿舍 | 失控学徒 | 活化日常器物 | 解除控制或保护被困人员。 |
| 材料库 | 守卫构装体 | 炼金事故产物 | 回收危险材料并阻止爆炸。 |
| 符文实验室 | 狂暴法师 | 中/大型原生体 | 打断仪式，阻止能量被吸收。 |

## 提交前检查

- 玩家此时是否已经进入符文之地本体？若否，避免使用核心实验区专属敌人。
- 敌人的原身份、出现位置、技能和掉落能否用一句话连起来？
- 是否至少有一个场景目标、地形或环境物件能说明这里原本的功能？
- 怪物组合是否重复使用“魔力浸染”作为唯一解释？如是，补充社会、生态或设施层面的来源。
- 精英或 Boss 是否揭露了一个更深层的机构信息、灾变原因或角色线索？
