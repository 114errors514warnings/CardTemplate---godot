# 怪物阵营与生态

| 敌人来源 | 合理地点 | 核心表现 | 设计限制 |
|---|---|---|---|
| 受灾居民/旅人 | 村舍、城镇、道路 | 恐惧、逃离、短暂失控；可保留生前工具。 | 不应表现为训练有素的法术部队。 |
| 魔化野兽 | 农地、林地、荒野、运输路线 | 本能攻击、群体行动、巢穴或领地意识。 | 技能来源应为动物特征加魔力异化。 |
| 流寇 | 道路、废墟、外围营地 | 趁乱掠夺、偷取资源、撤退或呼叫同伙。 | 目的应是利益，不等同于被潮汐直接控制。 |
| 学徒与法师 | 居住区、研习区、实验区 | 失控施法、未完成咒式、研究工具转为武器。 | 强度与法术复杂度随深入机构而提高。 |
| 守卫与构装体 | 哨所、仓库、收容区、大门 | 执行被扭曲的保护/驱逐指令，重防御或区域封锁。 | 需说明原本守护的对象或地点。 |
| 炼金/符文事故产物 | 实验区、工坊、材料库 | 泄漏、分裂、腐蚀、爆炸或吸收能量。 | 需能对应具体实验或材料事故。 |
| 魔力原生体 | 高魔力泄漏处、地脉节点、核心区 | 吞噬、分裂、汇聚与成长。 | 外围只少量出现，核心区才可成为主力。 |

## 同源敌人的阶段化

同一来源可设计为“外围—进场—核心”三个阶段。例如：普通居民 → 携带失控护符的居民 → 被实验能量彻底重塑的法师；或小型原生体 → 中型原生体 → 能召唤/吞噬同类的大型个体。阶段变化必须有叙事与视觉依据，不能只提高数值。
