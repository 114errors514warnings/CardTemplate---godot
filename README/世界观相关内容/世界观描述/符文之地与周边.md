# 符文之地与周边

## 定义

“符文之地”首先是一座由法师群体建立并维持的**魔法研究机构**，而非泛指第一层全部地貌。它承担魔法研究、符文实验、炼金制造与人才培养等职能，同时也是常驻法师及其学徒的生活共同体。

魔力潮汐爆发后，机构的研究设施、居住区及外围聚落均受到影响；但受灾方式与可遭遇的敌人应随地点改变。

## 机构本体

符文之地本体可由以下功能区构成：

- **研习区**：讲堂、藏书室、符文档案室与观测设施；承载学派、导师和学徒的日常研究。
- **实验区**：符文实验室、炼金工坊、材料库与隔离设施；高浓度魔力、炼金废料和失控试验品的主要来源。
- **居住区**：法师宿舍、学徒住处、公共食堂、庭院与服务设施；此处的灾难应优先呈现“生活被打断”和居民异变，而非纯粹的战斗实验场。
- **警戒与收容区**：结界节点、守卫哨所、仓库、收容室与大门；适合出现奥术守卫、活化构装体及失控防御机制。

上述功能区是玩法与叙事的空间基准，可根据关卡规模拆分或合并。

## 外围地区与推进关系

玩家在第一层**前半段并未进入符文之地本体**，而是在其辐射范围内推进：村舍、城镇、道路、农地、林地和荒野。这里的居民、商队、野兽与流寇最先承受外泄魔力造成的灾害。

建议的叙事推进为：外围生活区的异常与求生 → 通向机构的道路和废弃设施 → 机构外缘的警戒/收容区域 → 研习、实验与居住核心区 → 潮汐源头或第一层 Boss。这样可让敌人从“受波及者”自然过渡到“魔法灾害的直接产物”。

## 怪物设计原则

- 外围怪物应保留原有社会与生态来源，例如居民、猎人、旅人、野兽、强盗或商队护卫。
- 机构内部怪物必须能对应一个功能区或事故来源，例如实验失控、守卫指令扭曲、炼金泄漏或收容物逃逸。
- 同一怪物可随接近核心而强化，但要在名称、外观、技能或环境线索中体现其受魔力影响的阶段差异。
- 不把“符文之地”当作无差别魔法废墟：居住区、实验区与警戒区应拥有不同的敌人组合和战斗目标。
