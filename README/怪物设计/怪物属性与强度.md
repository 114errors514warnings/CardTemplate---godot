# 怪物属性与强度

## 强度计算规则

- 以勇士作为强度基准，定义其强度为 `1.00`
- 勇士基准属性：
	- HP = 40
	- 每回合最高伤害 = 15
	- 说明：勇士基础攻击为 3，基础攻击牌 `攻击` 的伤害修正为 2；在 3 点能量上限下，单回合最多可打出 3 张 `攻击`，因此单回合最高伤害按 `3 x (3 + 2) = 15` 计算
- 怪物强度公式：

```text
强度 = (MAX_HP / 40 + 每回合最高伤害 / 15) / 2
```

- 仅使用 `HP` 与“单回合可直接造成的最高伤害值”作为简化衡量，不额外把护盾、易伤、攻击力增益等间接收益折算进主公式

- `3003 堕魔守卫` 的攻击意图已改为 `1;2|1;2|1;2`，表示同一条意图中的 3 次 `Damage` 共用同一个随机目标。

- 怪物强度当前只作为数值粗估，后续如果把护盾、抽牌压制、持续成长等因素纳入，会得到更准确的强度曲线。
