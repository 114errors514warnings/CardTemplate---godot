## 一、策划案 · 游戏基础设定

### 1.1 世界观主题

- **风格**：西式中世纪玄幻
- **背景设定**：魔力的潮汐让王国、森林和符文之地陷入混乱，王国剑士、精灵王和法师在各自逃离混乱之地后偶遇，决定探寻世界陷入混乱的原因，并让世界恢复平静
- **美术风格**：明日方舟式 2.5D 纸片人 + 手绘卡面，战场采用**六边形网格地图**

### 1.2 核心玩法

- 使用卡牌控制代表角色的**战棋行动**
- 每回合固定能量点（**AP**）+ 卡牌抽弃机制（每回合仅能保留一定数量的手牌）
- **角色可以每回合使用能量移动一次**
- **怪物每回合拥有固定数量的行动次数，每次行动随机执行一个意图**

### 1.3 玩法概述

> 《末日挽歌》融合了**卡牌构筑、战棋和 Roguelike 闯关**，玩家需合理地操作 3 名角色在六角形的场景中进行战斗，通过动态构建的卡组在随机生成的回型地图中展开冒险。

> 玩家会在游戏过程中不断深入回型地图的同时遭遇简单或困难的战斗、各类事件并获得卡牌、材料、金币或装备，在商人处和村落进行交易以构筑卡组、将材料合成为道具或装备来提升小队战斗力。

> 核心循环为：在随机遭遇中运用卡牌进行战术战斗，通过击败敌人获取新卡牌与关键遗物，并在营地升级卡牌或回复、在商店精简卡组，通过持续的资源管理与战术决策强化卡组协同。

**初始体验**：初始拥有三个角色，类似杀戮尖塔选择地图中的节点前进，并在不同的场景中遭遇事件、与敌人战斗，在此过程中获取增益，增强小队的战斗力来挑战更强的敌人。

### 1.4 涉及元素

Notion 列出的玩法系统清单：

- 下一个节点的设计（六角形地图，可以自由探索，但需要承担随着时间流逝，敌人变强、节点变化、获得 debuff 的代价）
- 战棋玩法和卡牌玩法结合
- 道具、装备和 buff 带来的战斗影响
- 资源（金币，材料或其他非交易资源）的合理利用

### 1.5 不同的攻击类型（Notion 详述）

**近战**

| 攻击类型 | 描述 |
|----------|------|
| 单目标攻击 | — |
| 范围攻击 | — |
| 突刺攻击 | 位移指定距离，在第一个目标前停下，并对其造成伤害 |

**远程**

| 攻击类型 | 描述 |
|----------|------|
| 指定目标攻击 | 不可被其他目标或地形阻挡 |
| 弹道攻击 | 发射子弹朝向固定方向射击，对命中的第一个目标造成伤害，被闪避则会继续弹道 |
| 范围攻击 | 不可被其他目标阻挡，但可以被地形阻挡 |
| 穿透范围攻击 | 可以穿透地形 |
| 弹道范围攻击 | 子弹拥有体积，碰撞体积不同，可能不局限于当前方向直线上的目标，碰撞到目标后以当前所在格为中心造成范围伤害 |

### 1.6 概念详述

| 概念 | Notion 定义 |
|------|-------------|
| **金币** | 战斗或事件中获取的货币资源，可以在事件、商人中使用 |
| **材料** | 用于在炼金台合成道具或者在锻造台合成或强化装备（需要花费金币），可以在商人处 **1/4 价格回收** |

### 1.7 地图系统

- 采用**层层包裹**的设计，设置网格状节点层层推进
- 三个精英怪分居中央三角（格点较大，占 **3 个单位**）
- boss 位于中央（占 **5 个单位**）
- 每个节点占一格，节点之间的路线占一个

### 1.8 时间系统

- 每经过一个节点都会消耗一个时间点
- 消耗特定数量的时间点后经过一天
- 一天结束时可以通过**扎营**进行休整，消除所有 debuff 并恢复一定生命值
- 每经过一定天数，都会获得（**Notion 原文此处截断，未给出具体内容**）

### 1.9 局内地图

- **Alina 式的六角形地图**
- 优点：契合 2.5D 风格，角色无论朝向哪个方向都会有具体的 x 轴方向

### 5.2 重剑士 · 卡组构建思路

Notion 列出的三个流派：

**流派 1：叠盾防守流**
- 通过反甲和反击造成伤害
- 核心卡：
  - **城墙**（当你拥有护盾时，敌人的攻击会优先以你为目标）
  - **回合外攻击变群攻**（即旋风斩）
  - **全身撞击**（造成等同防御点数的伤害，即盾牌冲撞）
  - **护盾翻倍**

**流派 2：大费打击流**
- 可叠加的超高单点伤害
- 核心卡：
  - **绝力一击**（绝力打击）
  - **武装**（升级自身和手牌中的一张牌）

**流派 3：卖血力量流**
- 通过自己掉血或者受到伤害叠加力量，并通过特定攻击回血

## 八、Notion 总结一览

| 维度 | Notion 表述 |
|------|-------------|
| **游戏类型** | 卡牌构筑 + 战棋 + Roguelike 闯关 |
| **战斗规模** | 3 名角色 vs 多怪物（每层多种） |
| **战场** | **六边形网格**地图，Alina 式 |
| **回合机制** | 角色每回合：移动一次（消耗能量）+ 出牌（消耗 AP）；怪物每回合：固定行动次数 + 随机意图 |
| **能量** | AP，每回合恢复至上限；buff 可让 AP 临时超过上限 |
| **卡牌等级** | C / B / A / S 4 级；除 S 外都有 3 个升级分支选项 |
| **卡牌类型** | 状态 / 技能 / 战斗（策划案定义）；卡库已实有 D/B/A/S 级 |
| **核心资源** | 金币（货币）+ 材料（合成/锻造，1/4 价回收） |
| **养成维度** | 装备 5 部位（武器/头/身/脚/饰品最多3）+ 技能树（4 周期）+ 战斗 buff |
| **地图系统** | 层层包裹网格节点；3 精英三角 + 中央 boss |
| **时间系统** | 每节点 1 时间点；满则过 1 天；可扎营（清 debuff + 回血）；每过特定天数获 1 debuff |
| **视野 / 地形** | 战争迷雾 + 视野范围；岩浆/森林/高地/动态地形 |
