### 核心系统改造

1. **TurnStartEffect 统一结算**（StateSystem.cs）
   - `StateRuntimeData` 增加 `TurnStartResource` 和 `TurnStartAmountPerStack` 字段
   - `AddOrUpdateState` 增加重载支持传入 TurnStart 参数
   - `OnTurnStart()` 中 `TurnStartEffect` 统一结算：读取资源类型→总量→分发 Energy/Shield
   - 废弃原有的 `ExtraEnergy` 独立处理逻辑

2. **Crit 暴击**（StateSystem.cs + EffectSystem.cs + Card.cs）
   - `ModifyIncomingDamage` 签名改为 `(Card card, IUnitInstance source, IUnitInstance target, int baseDamage)`
   - 当 `card.HasKeyWord(Crit)` 时伤害 ×2，并移除 `RemoveAfterActivate` 标记的运行时关键词
   - `EffectContext` 增加 `Card` 字段，`ApplyAttack` 增加 `card` 参数

3. **关键词运行时生命周期**（Card.cs + BattleSytem.cs）
   - `Card.AppliedKeywords`：运行时附加关键词列表
   - `HasKeyWord()` 同时查询固有 + 运行时关键词
   - `EndPlayerTurn`：保留卡牌后遍历移除 `RemoveAtTurnEnd` 关键词
   - `ModifyIncomingDamage`：Crit 触发后移除 `RemoveAfterActivate`

4. **DrawCard 支持友军目标**（Card.cs）
   - `ApplyDrawCardEffect` 遍历 `resolvedTargets` 而非仅 source
   - 每个 CharacterInstance 独立抽牌

5. **MirrorShieldToAllies 累积护盾**（Card.cs）
   - `ApplyEffect` 循环中维护 `accumulatedShield`
   - Shield 效果完成后累加 `ShieldGained`
   - MirrorShieldToAllies 传入 priorShield 参数

6. **OnHpLost 钩子**（StateSystem.cs + BattleSytem.cs）
   - 新增 `OnHpLost()`：检查 GainAttackOnHpLoss 状态后添加 AddAttack 层
   - `OnUnitHpChanged()` 中 newHp < oldHp 分支调用

7. **OnMonsterAttackPlayer 反击**（StateSystem.cs + EffectSystem.cs）
   - 新增 `OnMonsterAttackPlayer()`：遍历 attacker 的 CounterAttackWhenAttacking 状态
   - 通过 `StackSegment.OwnerUnit` 匹配受击者，每个匹配的 segment 触发一次反击
   - `AttackEffect.Apply` 中非 counterAttack 且 source 是 Monster、target 是 Character 时调用

8. **HpLossPerCardPlayed**（StateSystem.cs）
   - `OnCardPlayed()` 不再限于 Attack 牌才执行：先检查 HpLossPerCardPlayed 扣血，再检查 CourageArmor

9. **DrawLock**（BattleSytem.cs + Card.cs）
   - `DrawCardsToHand()`：有 DrawLock → 跳过
   - `ApplyDrawCardEffect()`：每个目标检查 DrawLock → 跳过
   - 回合开始时由 decay 逻辑自动移除

10. **NextBattleCardFree**（BattleSytem.cs）
    - `PlayHandCard()`：战斗牌 + NextBattleCardFree → 费用改为 0 → 移除状态

11. **GetAllyUnits 友方解析**（BattleSytem.cs）
    - 新增 `GetAllyUnits(source)`：source 是 Character→返回其他玩家；source 是 Monster→返回其他怪物
    - `ResolveEffectTargets` 新增 `AllAllies(5)` 分支

12. **战前新增卡牌支持角色目标**（BattleSetupData.cs + AddCharacterCard.cs）
    - `CharacterCardIdsPerPlayer` 字典：按角色 index 存储专属卡牌
    - `AddCharacterCardIdForPlayer(index, cardId, count)`: index=0→全部角色, 1-3→指定角色
    - `EnsurePlayerDefaultDeckInitialized` 遍历角色时使用 `GetCharacterCardIdListForPlayer(index)`
    - AddCharacterCard 参数格式变为 `卡牌ID [数量] [角色index(1-3)]`
