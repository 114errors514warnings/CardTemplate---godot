5.8
1、效果系统扩展：新增 AddCost（增加能量）、ClearAllStates、DrawCard、Heal、ShieldSlam（盾牌冲撞）等 Effect；其中 ShieldSlam 伤害 = 攻击力 + 自身护盾值（经状态修改器处理）
2、卡牌新增与接入：新增"深呼吸"（20000003）与"盾牌冲撞"（11002001）两张卡，并完成对应 EffectType、结算分发与 CSV 配置联动
3、状态系统修复：修复不可叠层状态多次打出同名状态牌时仅回收最后一张的问题，改为保留历史绑定回调并在状态归零时统一触发回收
4、抽牌流程修复：修复卡牌效果触发 DrawCard 时抽牌堆不足不洗牌的问题，改为抽牌堆为空时自动将弃牌堆洗回后继续抽牌（与回合抽牌逻辑一致）
5、卡组配置与操作面板增强："新增卡牌"改为增量配置（默认卡组 + 新增卡牌统一洗牌）；新增"删除卡牌"按钮（参数：卡牌ID + 可选数量），战斗开始前可按数量删除，超出则删至0
6、回合结束与关键词体系：玩家回合结束时自动处理手牌弃置；新增 CardKeyWord 系统并实现"保留"关键词，保留牌在回合结束时不会进入弃牌堆（CSV 第8列改为 CardKeyWord，兼容旧 true 写法）
