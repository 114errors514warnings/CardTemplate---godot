# 9月施工文档

## §7 连续移动与攻击表现（2026-09-11）

### 已实施

- 玩家移动增加路径规划：进入移动模式后，未按鼠标时只预览“一次移动动作可达”的悬停路径；按住左键拖拽则预览完整连续路线，松开后显示并排的“确定移动 / 取消移动”。确定后才逐格执行。路径的每次实际入格都会保留原有的陷阱、机关、死亡和占位结算；途中离场或路径被阻挡时，已完成步骤保留、剩余步骤取消。
- 移动次数与“单次动作可经过格数”拆分为 `EffectiveMovesPerTurn` 与 `EffectiveMoveDistancePerAction`。初始每次动作经过 1 格；后续装备或状态可独立修改动作距离，路径资源按 `ceil(路径格数 / 动作距离)` 计算，不能再把格数永久等同于次数。
- 空闲状态不显示移动高亮；悬停/拖拽路线经过格以绿色高亮，并连接角色与各经过格。HUD 展示剩余移动次数、每次动作距离。Esc、再次点击移动或“取消移动”均可无成本取消规划。
- `BattlefieldSession` 对角色普通攻击、空间攻击牌和怪物伤害意图发出统一的 `BattlefieldAttackEvent`；`BattlefieldView` 依攻击模式播放近战挥击或远程弹道、命中闪光、伤害/护盾吸收与击败文字。移动与攻击表现按队列串行，怪物逐只结算时等待当前表现播放完毕再进入下一只。
- 修复怪物行动的规则/表现时序：怪物回合现在按“开始行动 → 单格移动 → 下一格移动 → 单段意图效果 → 收尾”推进，场景每个节拍等待前一节拍的表现结束。移动端点在后续移动待播时保持视觉坐标，避免一帧回退到逻辑终点而闪现。
- 攻击表现改为朝目标定向的起手、前冲挥击或弹道、命中十字与受击抖动；HP/护盾数字在命中帧才切换，攻击牌根据自身空间形状而不是一律按当前武器外观播放。
