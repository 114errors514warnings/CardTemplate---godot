# 9月施工文档

## §1 已确认需求

- 2026-09-08 新增决策：障碍可封闭区域但单位不得生成其中；移动消耗能量，次数由人物新增属性与装备决定；默认攻击为相邻单格，范围由武器与卡牌决定，无武器/双防具仍能攻击。
- 已决策：死亡立即释放格，坠落即死且无掉落；飞行例外与死后障碍留扩展接口。所有位移进入都触发陷阱/机关。
- 已决策（后续修订）：每格一个单位；道具与装备允许多件混放，陷阱/机关各自单个、彼此及与物品堆互斥。掉落遇已有物品堆直接加入，遇触发物件才寻找最近合法接收格。陷阱投放仍要求无单位无任何物件；机关仅开局生成。此条替代此前每格一件物件的约定。
- 已决策：换装免费，卸装按丢弃处理；地面武器拾取装入手位，武器进入道具栏仅预留许可接口。必杀非爪牙全退场可胜利并按击败比例计奖；生存第 N 回合后结束且全额获奖；HUD 卡牌、道具、装备拖动允许。
- 已决策：移动动作基础距离为一格，基础情况下每次动作消耗 1 能量并计一次；可一次提交多格路径，后续移动距离增益按动作改变可经过格数。装备额度立即生效且不重置已用次数。
- 已决策：卡牌范围挂钩武器攻击距离，不挂钩武器攻击范围；突进/远程受阻挡，穿透例外；爆炸影响实际命中目标附近单位。突进撞到可位移单位形成半伤连锁，撞免疫单位/障碍则回弹并惩罚被击退者，原攻击者不承受碰撞负面效果。
- 已决策：坠落机制杀计通关价值、不掉物品、不触发淬炼斩杀。穿透突进落点、爆炸参数、回弹后方阻挡及半伤基数仍待细化。
