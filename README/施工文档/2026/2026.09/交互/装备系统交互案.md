# 装备系统交互案

> 规定局外**装备界面**的入口、分区、拖动与换装规则，以及局外装备状态进入战斗的通路。佩戴限制、合法组合、饰品数量与战斗中换装规则以[装备、材料、道具系统](../../../../玩法说明文档/系统规则/物品系统/装备、材料、道具系统.md) §3.1 与[六边形战场玩法](../../../../玩法说明文档/系统规则/战斗系统/六边形战场玩法.md) §五为准。

## 完成情况（2026-09-28）

- 状态：**未实现**。局外装备状态只有一个字段：`RunCharacterSlotSave.EquippedWeaponDefinitionId`（`Scripts/Run/RunSaveData.cs:98`）。写入点在战斗胜利当刻（`Scripts/Run/RunBattleScene.cs:326`，只取左手 `loadout.LeftHand`）；读取点在开战时 `BattlefieldSession.RestoreRunWeapon`（单件武器 → 左手；`HandsRequired == 2` 时同时占左右手）。
- `EquippedArmor` / `EquippedHelmet` / `EquippedBoots` / `Accessory` 全库 **0 命中**；`DataBase/Equipment/` 下**只有 `Weapon.csv`**，没有防具 / 头盔 / 鞋 / 饰品表。
- 已定的玩法口径：手位 = 左右手武器/防具槽，单手各占一槽、双手占满两槽（玩法 §5.1-5.2）；头盔、护甲、鞋、饰品部位保留，**饰品当前最多 3 件**、后续数量待定；双手装备不排斥头 / 甲 / 鞋 / 饰品；战斗中换装免费；职业技能的初始武器在新建运行局时写入角色槽位（`RunSession.StartNewRun`）。
- 实现后：定稿的交互描述迁到 `README/交互说明文档/`。

## 一、入口与层级

- 入口：运行局常驻顶部按钮栏（`RunUiLayers.GlobalButton = 50`）**通用行**新增 `装备` 按钮，紧排 `背包` 之后（按钮创建点 `Scripts/Run/RunFlowScene.cs:336-340`）。
- 层级：界面挂 `RunUiLayers.Modal = 40`；单实例；与[背包界面](背包系统交互案.md)互斥（打开一个自动关闭另一个）。
- 关闭：`关闭` 按钮或 `Esc`；关闭不改变状态，**每次穿脱成功立刻写档**。
- 战斗 / 事件进行中、结算未关闭时打开 = **只读**（可查看装备与数值，不能拖动，悬停提示「战斗中不可换装 —— 战斗中换装只在战场内进行」）。

## 二、界面结构

```text
┌ 装备 ────────────────────────────────────────────────────┐
│ 〔重剑手〕 〔精灵〕 〔法师〕                                  │ ← 上边栏：角色 Tab
├──────────────────────────────────────────────────────────┤
│   ┌── 头部 ──┐    ┌── 身体 ──┐    ┌── 脚部 ──┐              │
│   │  空      │    │  空      │    │  空      │              │ ← 第 1 行 3 格
│   └─────────┘    └─────────┘    └─────────┘              │
│   ┌── 饰品1 ─┐    ┌── 饰品2 ─┐    ┌── 饰品3 ─┐              │
│   │  空      │    │  空      │    │  空      │              │ ← 第 2 行 3 格
│   └─────────┘    └─────────┘    └─────────┘              │
├──────────────────────────────────────────────────────────┤
│        ┌── 左手 ──┐    ┌── 右手 ──┐              〔关闭〕    │
│        │   空     │    │   空     │                        │
│        └─────────┘    └─────────┘                        │
└──────────────────────────────────────────────────────────┘
```

- **上边栏**：当前队三名角色的 Tab，顺序 = `RunSaveData.CharacterSlots` 的槽位序；文案用**角色显示名**，同名角色按槽位序加编号（`Scripts/Run/CharacterSlotNaming.cs`，与结算面板同一取名口）。点 Tab 只切换显示，不改变镜头与选中。
- **主体 6 格**：以**一行 3 个、共 2 行**均匀排列 —— 第 1 行 `头部 / 身体 / 脚部`，第 2 行 `饰品1 / 饰品2 / 饰品3`；每格格宽等高、左右边距与列间距一致、上下两行对齐。
- **饰品格数量按配置渲染**（当前 3）：多于 3 时按同一格样式续排下一行，少于 3 时该行格数随之减少；`饰品` 是"同一部位多槽"的写法，不拆成不同部位。
- **手位横条**（默认值）：左右手两格等宽等高、居中。因为[背包界面](背包系统交互案.md) §二已有手位拖放目标，这里是同一状态的第二处入口；不需要时可整条删除，不影响 6 格。
- 每格内容：空位显示部位名 + `空`；已装备显示装备名、负荷与关键数值（攻击距离 / 防御值 / 伤害修正 / 移动修正，取 `Weapon.csv` 同名列）；悬停显示完整说明、稀有度与来源。
- **部位文案**：界面用**头部 / 身体 / 脚部 / 饰品**（用户口述），与玩法文档的**头盔 / 护甲 / 鞋 / 饰品**是同一部位的两种称呼 —— 实现用同一字段，不做两套数据、不做两份配置。

## 三、拖动与换装

拖动只在**「无内容进行中」**放行（口径同[背包界面](背包系统交互案.md) §三：地图可选态 / 事件已结算 / 结算面板已关闭 / 不在营地）。

| 来源 → 目标 | 允许 | 条件与结果 |
|---|---|---|
| 背包 → 部位格 / 手位 | 允许 | 按 `Slot` 校验部位（头 / 身 / 脚 / 饰品 / 手位），部位不符即拒绝并提示「部位不符」 |
| 部位格 → 背包 | 允许 | 卸下，装备进背包装备分类（局外不落地丢弃） |
| 部位格 → 同部位的另一格 | 允许 | 仅饰品之间可互换；其它部位只有一格，拖到自身格无操作 |
| 部位格 → 手位（或反向） | 不允许 | 提示「部位不符」 |
| 手位 → 手位 | 允许 | 按玩法 §5.2 合法组合表：单手 ×2 / 单手 + 单手防具 / 双手独占两槽；双手装备与已有手位装备互换需两槽同时让位 |
| 手位 → 背包 | 允许 | 卸下（默认不允许放随身道具格，见[背包界面](背包系统交互案.md) §三 的许可通道） |

- 非法原因文案固定四类：`部位不符`、`双手装备需两个空手位`、`饰品栏已满`（数量按配置）、`战斗中不可换装`。
- 局外换装**不消耗时间点、不消耗金币**（默认值，见 §九）；不做丢弃（丢弃不在本范围）。
- 换装只改**局外装备字段**，不在界面里就地修改战斗内单位属性：属性修正（攻击 / 防御 / 移动额度 / 攻防距离）在**下一场战斗开场**生效。战斗中使用中的装备仍按玩法 §5.2（免费换装、换下的装备落地到当前格物品堆）。

## 四、与战斗的关系

| 环节 | 现状 | 本项要求 |
|---|---|---|
| 战斗开场 | `HexBattleScene` → `BattlefieldSession.RestoreRunState(CharacterSlots, DeckSlots)`（`HexBattleScene.cs:179`）→ `RestoreRunWeapon` 只读单个 `EquippedWeaponDefinitionId` | 扩成读**左右手两个字段 + 六个部位字段**：手位照旧落成 `PlayerLoadout.LeftHand / RightHand`（双手装备占两槽）；部位装备的属性/状态/效果经现有属性、状态与 Effect 系统生效（玩法 §5.2 末） |
| 开局武器来源 | 新建运行局时写职业初始武器（`RunSession.StartNewRun`，`GetInitialWeaponDefinition`） | 保持不变，只是写入左右手字段 |
| 战斗内换装 | 手位可换、免费（玩法 §5.2）；换下的装备落地到角色所在格物品堆 | 不变 |
| 战斗内换部位装备 | 玩法未定义，且既有实现没有对应入口 | **默认不支持**：战斗中只允许换手位装备（§九 第 3 条） |
| 战后回写 | 胜利当刻把左手写回 `EquippedWeaponDefinitionId`（`RunBattleScene.cs:326`）；P2-13 收尾的默认值是"**战后拾取的装备不写回局外装备字段**" | 回写范围扩到**左右手两个字段**；"战后拾取不回写"这条默认值**不改**（见 9 月施工文档 §39.5） |
| 装备状态缺失时的兜底 | `RestoreRunWeapon` 遇未知 `DefinitionId` 直接抛 `ArgumentException`（旧档会直接建场失败） | 建议改为**警告 + 清空该格**并继续建场（§九 第 4 条） |

## 五、存档字段与迁移

新增/扩展 `RunCharacterSlotSave`（`Scripts/Run/RunSaveData.cs:92-98`）：

| 字段 | 类型 | 说明 |
|---|---|---|
| `LeftHandDefinitionId` / `RightHandDefinitionId` | `string` | **新增**；空串 = 空手位 |
| `EquippedWeaponDefinitionId` | `string` | **保留**：旧档读入时映射到左手；双手装备同时写两字段。保留字段是为了不动既有读写点与旧档 |
| `EquippedHelmetDefinitionId` / `EquippedArmorDefinitionId` / `EquippedBootsDefinitionId` | `string` | **新增**：头部 / 身体 / 脚部 |
| `EquippedAccessoryDefinitionIds` | `List<string>` | **新增**：饰品，长度 = 配置数量（当前 3），空串 = 空位 |

- **迁移与 P0-3 合并**：`TimePoints` 改 `float`（[代码需求清单](../玩法/代码需求清单.md) P0-3）同样需要 `SchemaVersion 2 → 3`，两项**合成一次版本升级与一次迁移函数**，避免旧档连走两轮迁移。
- 迁移规则：`SchemaVersion < 3` 时，`EquippedWeaponDefinitionId` 非空 → `LeftHandDefinitionId`，且当该武器 `HandsRequired == 2` 时同步写入 `RightHandDefinitionId`；物品与卡组字段不动。
- 读档校验：装备 `DefinitionId` 必须在装备表里存在；不存在时清空该格并打印一条日志（不丢整档、不炸建场）。

## 六、配表前置

- 防具 / 头盔 / 鞋 / 饰品表：建议 `DataBase/Equipment/Armor.csv`，表头 `ArmorId,DefinitionId,Slot,HandsRequired,DefenseValue,DamageBonus,MoveBonus,ResourceCost,Load`，其中 `Slot ∈ Head|Body|Feet|Accessory`；经 `DataBase/FilePathRegistry.csv` 注册为 `Data.Equipment.Armor`；`Slot` 与界面 6 格一一对应，未知 `Slot` 报错而不是静默丢弃。
- 手位装备继续用 `DataBase/Equipment/Weapon.csv`（`EquipmentType` 已含 `Armor`，用于"手位防具"），表头不改。
- 两张装备表都加 `Load` 列（背包负荷，见[背包系统交互案](背包系统交互案.md) §四），并在[配表规范](../../../../功能说明文档/数据系统/数据配置/配表规范.md)的装备表小节落一条列定义。

## 八、验收

1. 顶部按钮栏出现 `装备`；单实例开关，与 `背包` 互斥，`Esc` / `关闭` 都能退出。
2. 上边栏恰好三名角色 Tab，文案与结算面板的角色显示名一致（重复角色带槽位编号）；切 Tab 只换显示。
3. 主体为**一行 3 个 × 共 2 行**：第 1 行头部 / 身体 / 脚部，第 2 行饰品 ×3；格宽高与列间距一致、两行对齐，窗口拉伸后仍均匀。
4. 饰品数量改为 2 时该行渲染 2 格；改为 4 时续排第 3 行，不重叠不溢出。
5. 拖动：背包 → 部位格 / 手位成功；部位不符、双手装备冲突、饰品满三种情形各自给出对应原因；不可拖动时（战斗中）悬停说明原因。
6. 卸下装备进背包、不落地；装上手位后该角色下一场战斗开场即为该装备（双手装备占满两槽），部位装备的属性修正在开场生效。
7. 旧档（`SchemaVersion 2`）读入不崩：原 `EquippedWeaponDefinitionId` 成为左手（双手武器同时占两手），部位格为空；未知 `DefinitionId` 清空该格并打印日志。
8. 战斗中换装仍按玩法 §5.2（手位免费换装、换下落地），界面在战斗中为只读。
9. `dotnet build` / `dotnet test`（238 例）/ `--battlefield-smoke` / `--run-flow-ui-smoke` 不回归；`--battlefield-smoke` 的夹具若用到 `EquippedWeaponDefinitionId`（`BattlefieldSceneSmoke.cs:191-193`）需同批改为左右手字段。
