- 地图、战斗、营地和村庄场景提供统一暂停入口；剧情选项、友伤确认和奖励选择等不可中断状态禁用暂停。

## P0：开始事件与场景推进

### 已实现（2026-09-21）

- `EVT-START-001` 标记 `autoComplete=true`，剧情 UI 直接显示唯一“前往地图”按钮；点击后才完成开始事件并进入可选地图。
- 非战斗事件的选项效果结算后不自动关闭剧情 UI，而是锁定原选项并显示唯一“前往地图”按钮。
- 内容尚未完成时，运行局地图按钮打开只读地图，按钮文本为“返回”；结算完成后根场景恢复可选地图，节点才可点击。
- 内容（关卡/事件）完成后不销毁内容：地图以“已打开”的覆盖层叠到内容之上，顶部按钮栏保持当前内容形态——与局内按“地图”完全一致。
- 事件中除战场本身外不显示任何战斗 UI（关卡目标、手牌、装备、结束回合等全部隐藏），事件内容存活期间不恢复；打开地图时剧情 UI 整体让位（保留实例），关闭地图后原样恢复。
- 结束面板（等待“前往地图”）不再显示“跳过”。

- 新局建立后进入开始事件；开始事件自动结算，只显示“前往地图”。
- 点击“前往地图”打开地图 UI，选择可达节点后锁定地图输入，淡出当前内容并淡入节点场景。
- 非战斗事件选项结算后显示“前往地图”，不自动恢复地图输入。
- 事件选项进入战斗时，选项确认后直接进入指定战斗；战斗结束后仍停留在战斗结算场景。
- 所有“前往地图”调用同一地图 UI 入口。

## P0：战斗结束与奖励节奏

- 战斗目标完成后停止战斗输入，显示胜利、失败或保护目标失败原因。
- 结果摘要显示角色生命变化、敌方击败/离场价值、掉落、奖励折损原因和未领取奖励状态。
- 奖励选择完成后显示“前往地图”；点击后才叠上可选地图，不自动离开战斗结算。
- 结算未确认时不再禁用地图按钮：按钮恒可用，此时打开的是只读地图（节点不可点击），结算确认点“前往地图”后才恢复可选，因此不会重复领取或跳过结算。
