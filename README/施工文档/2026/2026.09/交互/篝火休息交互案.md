## 转场步骤

1. 地图淡出。
2. 切换到三名角色围绕火堆的营地画面。
3. 营地淡入并显示休息交互。
4. 休息结算后淡出营地，返回地图并开始新一天。

## 营地基础画面

- 画面表现为三名角色围绕火堆。
- 不显示全屏或底部 UI 底板。
- 仅常驻四个独立按钮：添加食物、烹饪、守夜、休息。
- 营地期间地图、战斗和原背包界面不接受输入。

## 添加食物

点击后进入食物分配状态：

```text
左侧
├─ 上：本次篝火的饱食度进度条
└─ 下：已添加食物的格状列表

右侧
└─ 当前局背包中的食物格状列表
```

- 左右两侧格中的食物可自由拖动。
- 从背包拖到篝火列表时，预览本次休息的饱食度与食物效果。
- 篝火列表明确区分“仍提供效果”和“只提供饱食度”的食物；首次使效果饱食度超过上限的食物及其后的食物，显示为无效果状态。
- 从篝火列表拖回背包时，撤销对应预览。
- 点击“休息”前，食物只存在于本次营地草稿，不正式消耗。
- 点击“休息”后，篝火列表中的食物统一消耗并按玩法规则结算。

## 烹饪

- 点击后显示可合成食物、所需材料、有效期、饱食度和篝火效果。
- 每次休息最多合成 2 次；合成只消耗材料，不消耗额外时间点。
- 合成完成后的食物进入背包还是直接加入左侧篝火草稿，等待规则确认；无论哪种方式，都必须在点击“休息”前允许玩家撤销本次营地草稿。

## 守夜

- 守夜选择包括不守夜、轮流守夜和单人守夜，并在 UI 中实时显示生命回复、夜袭和睡眠不佳影响。
- 不守夜为全额回复且有夜袭概率；轮流守夜使每名角色回复降为 2/3；单人守夜使守夜角色不回复，并在下一场战斗获得“睡眠不佳”。
- 守夜选择在点击“休息”前可修改，不立即结算。

## 休息

点击后按顺序：

1. 锁定已添加食物和守夜选择。
2. 消耗篝火食物。
3. 应用饱食、回复、烹饪和守夜结果。
4. 处理夜袭或睡眠不佳。
5. 推进到新一天并刷新当天时间点。
6. 返回六边形局内地图。
