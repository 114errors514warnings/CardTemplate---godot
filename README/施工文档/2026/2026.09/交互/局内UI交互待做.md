## P0：独立地图 UI

### 已实现（2026-09-21）

- 局内常驻地图按钮（运行局顶部按钮栏右组）；地图打开期间按钮继续显示（文本为“返回”），重复点击关闭，再次点击重新打开。
- 地图 UI 覆盖当前节点场景；战斗、事件、结算中打开为只读，内容完成回到选点状态后节点可选。
- 地图按钮恒可用，不再因内容操作未完成而灰显：未完成时打开得到只读地图，节点点击被拦在 `MapScene.OnNodeClicked`（只读时直接返回）。
- 开始事件、普通事件与**非战斗来源**结算的“前往地图”走同一入口（`RunFlowScene.ReturnToSelectableMap`）；**战斗来源结算关闭面板后不再自动回地图**（停留战场，见下一条）。
- 事件未结算时打开的地图可查看地图，节点选择禁用；关闭后回到原事件状态（剧情 UI 原样保留、不销毁）。
- 内容完成后不销毁内容：地图以“已打开”的覆盖层叠到内容之上，顶部按钮栏保持当前内容形态。
- **战斗结算后停留战场（2026-09-28）**：本场确实打过这一局时（`RunBattleScene.HasLiveBattlefield`），关闭结算面板只把地图转为**可选**、**不打开** —— 战场保持可见可点、浮窗常驻，要离开时点常驻栏「地图」打开可选地图；**事件 / 商人发卡**与**没有战后落档的旧档**（没有实机战场）仍按原行为直接打开可选地图（有落档时按落档重建战场并停留战场）。浮窗位置同时由「右侧中部」上移到「右侧上部」（不再压住「当前格道具 / 随身道具」）。**战后战场操作态（隐藏手牌 / 能量 / 额度 / 牌堆 / `结束回合`，只保留「移动」且点可达格即移动、不消耗能量与移动次数）已落地（2026-09-28）**，设计与实现见[战斗结算后战场操作交互案](战斗结算后战场操作交互案.md) §四–§六 / [代码需求清单 P2-13](../玩法/代码需求清单.md) / [9 月施工文档 §38](../9月施工文档.md)。**同日收尾（用户改判）**：战后**可拾取**当前格道具 / 装备（拖到随身槽 / 手位，其余方向仍关闭），且**位置与拾取结果落档** —— 读档重进结算界面时按落档重建同一张战场（见[战斗结算后战场操作交互案](战斗结算后战场操作交互案.md) §5.1 / §七 4 与 [9 月施工文档 §39](../9月施工文档.md)）。**未在改判中提出的内容一律保留默认值**（角色 Tab 行保留、战后移动距离不限、战后拾取的装备不写回局外装备字段），已按用户 2026-09-28 口径收口为定稿取值（见 [9 月施工文档 §39.5](../9月施工文档.md)）。

## P1：输入层级与转场

- 地图 UI、剧情 UI、暂停菜单、友伤确认和奖励选择建立统一覆盖层优先级；最高层以外的输入全部阻断。
- Esc 与右键只关闭当前最高层可取消界面；奖励领取、放弃本局和节点进入确认不能被 Esc 绕过。
- 节点进入、返回地图、战斗结算和营地转场使用统一淡入淡出与加载锁，防止重复点击进入同一节点或重复领取奖励。

## P1：失败、放弃与存档去向

- 暂停菜单增加“放弃本局游戏”，显示当前层数、角色状态、未领取奖励与二次确认。
- 普通战斗失败、保护目标失败、主动放弃和事件中退出分别定义存档保留、返回地图或结束本局的结果。
- 继续游戏必须恢复到地图、事件、战斗开始或结算中的正确状态。

## P2：节点进入确认

- 普通敌袭和普通事件可直接进入。
- 高危敌袭、精英、Boss 和消耗大量时间的节点显示关卡类型、预计时间、敌方威胁和确认入口。
- 确认后锁定节点，取消后保持地图 UI 打开。

## P2：局内摘要入口

- 地图按钮旁增加只读摘要入口，显示角色生命、食物、材料、金币、钥匙、当天时间点和当前层数。
- 摘要不能中断当前事件、奖励选择或战斗结算。
- 战斗中是否提供简化只读版摘要，等待规则确认。
