## P0：独立地图 UI

### 已实现（2026-09-21）

- 局内常驻地图按钮（运行局顶部按钮栏右组）；地图打开期间按钮继续显示（文本为“返回”），重复点击关闭，再次点击重新打开。
- 地图 UI 覆盖当前节点场景；战斗、事件、结算中打开为只读，内容完成回到选点状态后节点可选。
- 地图按钮恒可用，不再因内容操作未完成而灰显：未完成时打开得到只读地图，节点点击被拦在 `MapScene.OnNodeClicked`（只读时直接返回）。
- 开始事件、普通事件和战斗结算的“前往地图”都走同一入口（`RunFlowScene.ReturnToSelectableMap`）。
- 事件未结算时打开的地图可查看地图，节点选择禁用；关闭后回到原事件状态（剧情 UI 原样保留、不销毁）。
- 内容完成后不销毁内容：地图以“已打开”的覆盖层叠到内容之上，顶部按钮栏保持当前内容形态。

### 待做

- 节点悬停显示节点类型、主要内容、预期时间消耗和进入条件；事件未结算时仅允许此悬停信息。

- 主动结束当天入口显示剩余时间点比例和对应的生命回复预览。

## P1：输入层级与转场

- 地图 UI、剧情 UI、暂停菜单、友伤确认和奖励选择建立统一覆盖层优先级；最高层以外的输入全部阻断。
- Esc 与右键只关闭当前最高层可取消界面；奖励领取、放弃本局和节点进入确认不能被 Esc 绕过。
- 节点进入、返回地图、战斗结算和营地转场使用统一淡入淡出与加载锁，防止重复点击进入同一节点或重复领取奖励。

## P1：失败、放弃与存档去向

- 暂停菜单增加“放弃本局游戏”，显示当前层数、角色状态、未领取奖励与二次确认。
- 普通战斗失败、保护目标失败、主动放弃和事件中退出分别定义存档保留、返回地图或结束本局的结果。
- 继续游戏必须恢复到地图、事件、战斗开始或结算中的正确状态。
