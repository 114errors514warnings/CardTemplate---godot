# 9月施工文档 · 2026-09-09 · 六边形出牌/道具拖拽与目标型道具落地

> 承接 [9月施工文档.md](9月施工文档.md) 与 [六边形战场完整执行方案.md](六边形战场完整执行方案.md)。本轮把“出牌交互、道具交互、目标型道具、战场布局”从设计落到运行时代码（C# / 场景 / JSON），并同步系统规则文档。

## §1 本轮涉及文件

- `Scripts/Battlefield/Presentation/HexBattleScene.cs`：手牌区底板、出牌/道具拖拽、布局、槽位高亮。
- `Scripts/Battlefield/Presentation/BattlefieldView.cs`：施法预览（去掉旧的“施法者→目标”线）。
- `Scripts/Battlefield/Runtime/BattlefieldSession.cs`：出牌/道具空间路由、直线“首目标”、目标型道具结算。
- `Scripts/Battlefield/Core/BattleBoard.cs`：`GroundObject` 增加投掷型空间规格 + `ItemSpatialShape` 枚举。
- `Scripts/Battlefield/Core/BattleRangeResolver.cs`：道具形状的受影响格解析。
- `Scripts/Battlefield/Core/BattleDeploymentService.cs`、`BattleMapDefinition.cs`：固定物件空间字段 + “石头/测试石块”配置。
- `Scripts/Entity/Card/Card.cs`：六边形作用域内“对空格/无敌人”出牌允许效果落空。
- `DataBase/Battlefield/FoundationMap.json`：新增固定“石头”目标道具。

## §2 手牌区底板

- `BuildUi` 中手牌区由 `VBoxContainer` 改为 `PanelContainer` 底板：深色半透明背景 + 米色细描边 + 圆角；`handRow` 设 `SizeFlagsVertical=ShrinkCenter`，卡片在底板内水平居中、垂直居中，不拉伸卡面。
- 受视口 1600×900 与手牌区锚点 `(0.24,0.64,0.60,0.87)`（宽约 576px）限制，底板左右内边距仅 4px、上下 12px，避免卡片压到描边。

## §3 出牌拖拽（对齐旧版战斗系统）

- 新增 `_Input` 统一处理：按住手牌(`TryStartDragFromPosition`) → 跟手(`UpdateDragState`) → 松开(`FinishCardDrag`)。拖拽期间 `GetViewport().SetInputAsHandled()`。
- **无需目标卡**（`Shape==None`）：拖动时始终跟随鼠标；松开时若已拖出手牌区则 `TryCastPendingTo(null)`（打向当前角色所在格），否则取消并把卡牌放回手牌区。
- **需要目标卡**（`HasSpatial`）：拖出手牌区后卡牌吸附屏幕顶部中央，绘制“卡牌中心→鼠标”引导线（新增 `dragLine` `Line2D`）；`UpdateCastPreview(CurrentHoveredCell())` 展示黄候选/红影响格；松开在合法候选格上（**不论格上是否有单位**）→ `TryCastPendingTo(hover)` 施放并清预览；否则取消并隐藏引导线。
- 移除旧的 `StartCastCard`（点击施放）与 `OnMapClick` 的地图点击施放分支；移动规划仍在 `OnMapClick`。
- `BattlefieldView.DrawCastPreview` 去掉旧的“施法者→目标格”线，改由“卡牌中心→鼠标”引导线代替；黄/红格高亮保留。

## §4 对“空格/无敌人”也能出牌（效果落空）

- `BattlefieldSession.TryCastCard`（Single/Burst/Line）：移除 `enemies.Count==0` 即失败的校验，改为 `selected = enemies.Count>0 ? enemies[0] : null`。
- `Card.Apply`：仅当处于六边形空间作用域（`BattlefieldEffectTargetScope.Current != null`）时，`NeedTarget && target==null` 不再失败。
- `Card.ApplyEffect`：仅在该作用域内、某效果解析不到目标时跳过该效果（打空），继续后续效果；旧战斗系统（无作用域）保持原失败行为。
- 结论：目标格只需在射程内即可成功“打出”（消耗卡牌+能量）；攻击对空打空，抽牌/护盾等其它效果仍生效。

## §5 装备栏与道具区布局

- 左右装备栏等宽等高：左手 `(0.028,0.71,0.13,0.87)`、右手 `(0.87,0.71,0.972,0.87)`（宽 0.102 对称、上下对齐）。
- “当前格道具”`curItemPanel` 移到右侧 `(0.78,0.30,0.945,0.44)`；“随身道具”3 格 `carryPanelNode` 移到其下方 `(0.78,0.48,0.945,0.62)`。

## §6 道具 prefab 拖拽交互

- 道具显示为卡片式 prefab（`MakeItemPrefab`：道具名 + 效果摘要，如 “石头 / 伤害3 直线3”、“治疗药剂 / 治疗+6”）。
- “随身道具”3 格改为固定 `PanelContainer` 槽位（`WellBox` 凹槽样式，空槽显示“空”），**非按钮**；槽位 `MouseFilter=Ignore`，仅槽内道具卡片可交互。
- 拖拽流程与卡牌并列（`_Input`）：`TryStartItemDragFromPosition` / `StartItemDrag` / `UpdateItemDrag` / `FinishItemDrag` / `CancelItemDrag` / `CleanupItemDrag`。
- 无目标道具：跟手；拖出道具栏（当前格道具面板 + 随身槽之外）松开 → 使用。
- 目标道具：拖出后吸附顶部中央 + 引导线 + 黄/红格预览；放到合法目标格松开 → 使用/投放；否则取消并隐藏线。
- 丢到随身槽 → 移动/交换（`TryMoveItemBetweenSlots`）；从当前格拿起 → `TryPickItemFromCurrentCell`；从随身槽拖回当前格道具面板 → 放回地面（`TryDropItemOnCurrentCell`）。
- 拖放高亮：`UpdateItemDropHighlights` 在鼠标悬停到某随身槽 / 当前格道具面板时亮黄色边框，拖拽结束 `ClearItemDropHighlights` 清除。
- 交换：`TryMoveItemBetweenSlots` 目标已满直接交换；`TryPickItemFromCurrentCell` 目标已满时把原槽道具放回当前格。
- Bug 修复：Godot 不允许对已有父节点的节点直接 `add_child`。在 `StartItemDrag` / `StartCardDrag` 里先 `RemoveChild` 再 `AddChild`；取消路径先判断父节点确实是 `dragLayer` 再 `RemoveChild`。

## §7 目标型道具模型

- `BattleBoard.cs`：`ItemSpatialShape { None,Single,Line,Fan,Ring,Diamond }`；`GroundObject` 增加 `SpatialShape / ItemMaxRange / ItemRadius / ItemLength / ItemTrapId / DamageAmount / NeedsTarget`。
- `BattleRangeResolver.ResolveItemAffectedCells`：单 / 直（从施法者向前 length 格）/ 扇（origin 顶点 ±60°）/ 环（落点 radius 一圈）/ 菱（宽线近似）。
- 会话新增：`GetItemCastCandidates`、`GetItemAffectedCells`、`IsValidItemTarget`、`TryUseItemAt`、`TryUseItemFromCurrentCell`、`TryMoveItemBetweenSlots`、`TryDropItemOnCurrentCell`、私有 `ApplyItemEffect`、`ResolveLineUntilBlocked`。
- 投掷陷阱例子：`SpatialShape=Single` + `ItemTrapId` + `ItemMaxRange`，候选格过滤“有单位 / 有道具 / 不可通行”（即“不能投到存在单位或道具的格子”）。
- `BattleObjectData` / `BattleDeploymentService`：固定物件可配空间字段；随机生成的“石头 / 测试石块”走 `ConfigureThrowableItem`（Line，length 3，伤害 3）。
- `FoundationMap.json` 在 `(0,0)`（一号勇士出生格）放固定“石头”（`SpatialShape=Line, ItemMaxRange=3, ItemLength=3, DamageAmount=3`）便于实测。

## §8 直线攻击“首目标”规则

- 默认直线攻击只命中方向上的**第一个单位或障碍**（障碍也算目标），后续不穿透；除非标记穿透。
- `BattlefieldSession.ResolveLineUntilBlocked(dir, length, penetrates)`：从施法者沿方向走 length 格，遇首个单位/障碍即停（非穿透时）。
- 卡牌：`TryCastCard`、`GetAffectedCells` 对 `Line` 复用该逻辑；`GetCastCandidates`(Line) 原本就是 6 方向遇挡即停。
- 道具：`GetItemAffectedCells`(Line) 用该逻辑；`GetItemCastCandidates`(Line) 只返回 **6 条方向直线上的格子**（到 `ItemLength`，遇单位/障碍即停），不再把整个半径六边形都作为黄色候选。
