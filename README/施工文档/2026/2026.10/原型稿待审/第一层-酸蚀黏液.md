# 酸蚀黏液

> ⚠️ **待审草稿（未认可）**：Agent 产出、尚未经用户认可，**不是**《怪物设计示例》范例；认可后由用户决定是否移入 `README/世界观相关内容/怪物设计示例/`（规则见 [10月施工文档 §3](../10月施工文档.md)）
> 第一层高等档普通敌袭（`F1-007` / `F1-008` / `F1-009`）的**腐蚀 / 易伤单位**。原型表见《符文之地设计指引/敌人原型模板》。

## 基本归属

- **区域**：材料库外部、货运通道、实验区外溢的走廊（《区域与遭遇阶段》B / D）。
- **来源**：**炼金 / 符文材料事故产物**（泄漏后自行凝结的腐蚀体）。
- **受潮汐影响阶段**：重度浸染（本身就是事故产物）。

## 叙事与视觉

- **灾变前身份或功能**：材料库里的符文溶剂 / 炼金残液。
- **为何出现在这里**：结界失效后容器破裂，溶剂顺地势流到货运通道，与潮汐魔力结合成会缓慢移动的半流体。
- **外观识别点**：**带蚀痕的低矮黏液团**，体表不断渗出酸雾；行动时留下腐蚀痕（≠ 彩虹色、不发光）。
- **关卡中传达的信息**：事故不是一处「大爆炸」，而是无数处小泄漏 —— 机构是被自己的材料慢慢吃掉的。

## 战斗定位

- **定位**：中近距离弱化（易伤）单位，附带小额伤害。
- **行动理由**：「酸蚀喷吐」是黏液喷溅腐蚀护甲（易伤）；「腐蚀啃咬」是贴身后的持续侵蚀（伤害 + 1 层易伤）。
- **与同场敌人的配合**：它自己伤害很低，但把敌人的伤害**放大 1.5 倍** —— 与伏魔护卫 / 活化铠甲 / 驮兽同场时，玩家的容错空间被显著压缩。
- **击败 / 撤退后的叙事结果与掉落理由**：凝结体碎裂后留下**炼金材料 / 符文溶剂**（掉落表见 `DropTableId 2001`）。

## 与第一层 Boss 的区分

| 第一层 Boss | 视觉关键点 | 本单位的差异 |
|---|---|---|
| 汲能者 | 虹彩能量漩涡、纯粹能量生命、无意识但会吞噬魔力并**持续生长** | 本怪是**有质体的腐蚀黏液**（史莱姆系），颜色浑浊带蚀痕，不成长、不吞魔力、不是能量体 |
| 卡珊德拉 | 悬浮法师 + 幻象水晶 | 本怪无智力、无施法语义（是喷射与啃咬，不是咒式）|
| 磐石巨像 | 黑曜石 + 宝石巨型构装体 | 本怪是软体，与石质构装体无任何重合 |

> 按《怪物类别》「已经有的史莱姆等内容可以重复使用」的口径，本怪与 3101 小型符文史莱姆同属**原生体 / 黏液系**，但职责完全不同：3101 是小额伤害 + 1 层易伤的教学怪，本怪（3119）是可堆叠的**易伤放大器**。

## 校验

- **是否与区域功能相符**：✅ 炼金 / 符文事故产物明确属于材料库与工坊区域。
- **是否与潮汐阶段相符**：✅ 重度浸染的事故产物。
- **是否与已有同类重复**：✅ 与 3101 同族但不同轴（3101：3 伤 / 1 层易伤；本怪：2 伤 / 2 层易伤或 2 伤 + 1 层易伤），不与任何 Boss 形象重合。
- **数值落表**：`Monster.csv` 3119（14 / 2 / 1），意图 `1|3;2;1;2`（2 伤 + 2 层易伤）与 `1|3;2;1;1`（2 伤 + 1 层易伤），价值 6 / 4，综合价值点数 **19**。
