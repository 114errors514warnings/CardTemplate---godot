# 失控哨戒装置

> ⚠️ **待审草稿（未认可）**：Agent 产出、尚未经用户认可，**不是**《怪物设计示例》范例；认可后由用户决定是否移入 `README/世界观相关内容/怪物设计示例/`（规则见 [10月施工文档 §3](../10月施工文档.md)）
> 第一层高等档普通敌袭（`F1-007` / `F1-008` / `F1-009`）的**纯弱化单位**。原型表见《符文之地设计指引/敌人原型模板》。

## 基本归属

- **区域**：检查哨、材料库外部与收容区走廊的固定结界设备（《区域与遭遇阶段》B / C）。
- **来源**：**结界装置**（失控的低阶哨戒设备）—— 不是生物、不是构装体战士，而是插在地上不动的法器残骸。
- **受潮汐影响阶段**：中度浸染（功能被放大成无差别压制）。

## 叙事与视觉

- **灾变前身份或功能**：机构用来「标记 / 阻拦越界者」的哨戒符柱，靠压低目标气力来驱离。
- **为何出现在这里**：结界网络瓦解后，符柱失去了归属判定 —— 它仍按时脉动，只是把**所有会动的东西**都当作越界者压制。
- **外观识别点**：**固定在地面、不移动**的低矮符柱；顶部开裂、符纹外溢成脉冲环。
- **关卡中传达的信息**：机构的外围封锁是靠设备维持的；设备还在工作，但已经没有人在指挥它。

## 战斗定位

- **定位**：后排纯弱化单位（0 伤害）、第二意图为友方护盾支援。
- **行动理由**：脉冲压制（对角色叠虚弱）是符柱原本的驱离功能被放大；结界过载是同一套结界把剩余能量转成护盾。
- **与同场敌人的配合**：给玩家叠虚弱（输出 ×0.75）的同时给前排怪补盾，**是「不清就一直亏」的压力源**。
- **击败 / 撤退后的叙事结果与掉落理由**：被打碎后掉落**符纹材料 / 结界碎片**（掉落表见 `DropTableId 2001`）。

## 与第一层 Boss 的区分

| 第一层 Boss | 视觉关键点 | 本单位的差异 |
|---|---|---|
| 汲能者 | 不断变形的虹彩能量漩涡、核心是无法直视的强光、会吞噬魔力继续成长 | 本怪是**有实体的固定装置**：不会变形、不吞噬魔力、不成长，只是一个坏掉的符柱 |
| 卡珊德拉 | 悬浮大法师 + 幻象水晶 | 本怪不悬浮、不施法、不制造幻象（脉冲只造成「虚弱」，不造成视觉欺骗）|
| 磐石巨像 | 巨型类人构装体、宝石、石翼、大门口 | 本怪是**矮小的地面设备**，没有躯体、没有守护大门的叙事 |

## 校验

- **是否与区域功能相符**：✅ 《关卡组合与校验》已把「失控哨戒装置」列为检查哨的辅助敌源。
- **是否与潮汐阶段相符**：✅ 设备型事故（不是生物异变）。
- **是否与已有同类重复**：✅ 现池没有任何 0 伤害单位；3105 林雾施咒者移除后，弱化源只有 3107（低血、带伤害）与 3101（小额易伤）。本装置补上**高等档需要的状态密度轴**。
- **数值落表**：`Monster.csv` 3118（12 / 0 / 3），意图 `3;0;2;2`（对随机一名角色 2 层虚弱）与 `2;0`（半径 3 友方各 3 护盾），价值 4 / 3，综合价值点数 **15.5**。
- **实现口径**：`3;<EffectTargetType>;<状态>;<层数>` 中 `0 = Auto = 随机一名角色`（六边形战场按索敌目标结算）；两条路径都不得把弱化加给怪物自身（`--battlefield-smoke` 的 `BATTLEFIELD_MONSTER_STATE_TARGET_PASS` 守住这条）。
