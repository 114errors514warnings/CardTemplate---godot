# 伏魔护卫

> ⚠️ **待审草稿（未认可）**：Agent 产出、尚未经用户认可，**不是**《怪物设计示例》范例；认可后由用户决定是否移入 `README/世界观相关内容/怪物设计示例/`（规则见 [10月施工文档 §3](../10月施工文档.md)）
> 第一层高等档普通敌袭（`F1-007` / `F1-009`）的前排单位。原型表见《符文之地设计指引/敌人原型模板》。

## 基本归属

- **区域**：机构外缘的检查哨、哨所与封门线（《区域与遭遇阶段》B / C）。
- **来源**：守卫与构装体 —— **人类护卫**（机构自己的哨兵），不是构装体、不是原生体。
- **受潮汐影响阶段**：中度浸染（仍在执行「封锁 / 驱逐」指令，但开始主动出击）。

## 叙事与视觉

- **灾变前身份或功能**：负责检查哨通行与封门的制式护卫，装备符纹长矛与短盾。
- **为何出现在这里**：结界瓦解后，被扭曲的「驱逐入侵者」指令仍在生效 —— 他们不再查验通行符文，只把靠近的一切当作入侵者。
- **外观识别点**：制式兵团甲 + 符纹长矛；甲缝里透出的微光是**符纹余辉**，不是宝石或石翼。
- **关卡中传达的信息**：这里曾是机构的外围防线；防线还站着，但认得的人已经没有了。

## 战斗定位

- **定位**：近战前排、直线封锁（`MeleeLine` 距离 3）。
- **行动理由**：长矛的直线突刺来自制式训练；「破门冲撞」是封门程序被扭曲后的强行突破动作。
- **与同场敌人的配合**：站在缺口正面吃伤害，让后排的失控哨戒装置安心叠虚弱、酸蚀黏液安心叠易伤。
- **击败 / 撤退后的叙事结果与掉落理由**：被击溃后甲胄与符纹长矛散落 → 掉落以**材料 / 装备**为主（战利品表见 `DropTableId 2001`）。

## 与第一层 Boss 的区分

| 第一层 Boss | 视觉关键点 | 本单位的差异 |
|---|---|---|
| 磐石巨像 | 黑曜石 + 魔法宝石构成的**巨型**类人构装体、破石翼、胸口奥术引擎 | 本怪是**人类体型的活体护卫**，有甲胄与长矛，无宝石 / 无石翼 / 无奥术引擎，也不守护大门本体 |
| 卡珊德拉 | 悬浮法师 + 环绕的幻象水晶 | 本怪不悬浮、不施法、无幻象 |
| 汲能者 | 虹彩能量漩涡、纯魔力原生体 | 本怪是血肉之躯 + 制式装备 |

## 校验

- **是否与区域功能相符**：✅ 检查哨正是「守卫与构装体」的标准投放点（《怪物阵营与生态》）。
- **是否与潮汐阶段相符**：✅ 中度浸染（行为被指令扭曲），不是重度异变。
- **是否与已有同类重复**：✅ 现池只有 3104 符文石卫（构装石卫、纯防御）与 3110 城卫见习兵（Low 档弱前排）；伏魔护卫是**有直线攻击能力的进攻型前排**，补上高等档的前排伤害轴。
- **数值落表**：`Monster.csv` 3117（30 / 7 / 4），意图 `1`（近战直线 3 格 7 伤）与 `1;-2`（相邻 5 伤 + 移动 3），价值 7 / 5，综合价值点数 **36**。
