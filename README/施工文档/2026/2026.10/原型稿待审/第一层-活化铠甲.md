# 活化铠甲

> ⚠️ **待审草稿（未认可）**：Agent 产出、尚未经用户认可，**不是**《怪物设计示例》范例；认可后由用户决定是否移入 `README/世界观相关内容/怪物设计示例/`（规则见 [10月施工文档 §3](../10月施工文档.md)）
> 第一层高等档普通敌袭（`F1-008` / `F1-009`）的**高单点近战**单位。原型表见《符文之地设计指引/敌人原型模板》。

## 基本归属

- **区域**：收容区、卫所、宿舍走廊（《区域与遭遇阶段》C）。
- **来源**：**构装体 —— 被魔力注入的空壳铠甲**（收容区逃逸物）。
- **受潮汐影响阶段**：中度浸染（无自我意识，只按残留指令行动）。

## 叙事与视觉

- **灾变前身份或功能**：收容区与卫所的备用制式铠甲（无人穿戴时应静止悬挂）。
- **为何出现在这里**：潮汐魔力注满空壳，残留的「穿戴即执勤」指令被当作真实命令执行 —— 铠甲自己站起来走出储物间。
- **外观识别点**：**人形单兵空壳铠甲**，关节处是魔力咬合的光缝，甲内空无一物；不是石质、不发光成引擎状、没有翼。
- **关卡中传达的信息**：机构的防卫资产正在「自己行动」；越靠近收容区，越能感到防卫系统已经不认识自己人。

## 战斗定位

- **定位**：单兵高单点近战（相邻 8 伤）+ 近战直线突进（3 格 5 伤）。
- **行动理由**：斩击是铠甲携带武器的原功能；「铠甲冲撞」是它**只为移动到执勤位置**而采用的直线推进动作（不是法术）。
- **与同场敌人的配合**：负责贴脸换血、吃掉玩家一轮爆发；黏液与装置在它身后叠易伤 / 虚弱，让它的 8 点伤害变得难以承受。
- **击败 / 撤退后的叙事结果与掉落理由**：散架为**甲片与魔力铸件**（掉落理由：铠甲本体即是材料来源）。

## 与第一层 Boss 的区分

| 第一层 Boss | 视觉关键点 | 本单位的差异 |
|---|---|---|
| 磐石巨像 | **巨型**类人构装体、黑曜石 + 魔法宝石、破碎石翼、胸口奥术引擎、守大门 | 本怪是**人形单兵身形**、金属甲片、无宝石 / 无石翼 / 无引擎；叙事上它守的是**收容区与宿舍**，不是机构大门 |
| 卡珊德拉 | 悬浮法师 + 幻象水晶 | 本怪不悬浮、不施法 |
| 汲能者 | 虹彩能量漩涡 | 本怪是**空壳装甲**（有实体外形），不是能量体 |

> **刻意保留的差异轴**：精英档的活化铠甲是「被击败后可以**复活**」的版本（《普通与精英怪示例》第一层精英方向）；本怪是普通档版本，**不回血、不复活、不分裂**，两者共用形象与来源，只在机制上分层。

## 校验

- **是否与区域功能相符**：✅ 收容区 / 卫所 / 宿舍走廊是活化铠甲的明确规定投放点。
- **是否与潮汐阶段相符**：✅ 中度浸染（残留指令被激活），不需要「重度异变」解释。
- **是否与已有同类重复**：✅ 现池的构装单位只有 3104 符文石卫（24 HP / 3 攻 / 纯防御），缺少**进攻型构装前排**；本怪补上高等档的「高单点 + 高血」轴，且不与任何 Boss 同名同形。
- **数值落表**：`Monster.csv` 3120（32 / 8 / 5），意图 `1`（相邻 8 伤）与 `1;-3`（近战直线 3 格 5 伤 + 移动 3），价值 8 / 5，综合价值点数 **38.5**。
