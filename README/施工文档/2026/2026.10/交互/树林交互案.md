> 规定村庄**树林**的进入代价、搜寻产出的材料与次数。共用口径（地图形态、移动、时间点、确认 tips 组件）见[村庄地图交互案](村庄地图交互案.md)，本文只写树林自己的规则。

## 一、代价与次数

| 项 | 值 | 说明 |
|---|---|---|
| 进入代价 | **1 时间点 / 次** | 时间点不足 → 不弹 tips，只给一行原因（§五） |
| 可重复 | **是**：只要时间点够，入口格可反复踏入 | 与锻铁铺 / 餐厅的「每次进入 1 时间点」同口径 |
| 占用 | 5 格（东边折线 5）+ 入口格 1 | 见[村庄地图交互案](村庄地图交互案.md) §2.2 |
| 产出 | 材料**直接进背包** | 不落档单独字段（复用 `BagEntries`） |

## 二、确认 tips 内容

沿用村庄案 §六 的 4 行气泡：

| 行 | 内容 |
|---|---|
| 1 | `树林` |
| 2 | `搜寻：材料 ×2`（具体种类在结算时才揭晓，见 §三） |
| 3 | `代价：1 时间点` |
| 4 | `进入` / `稍后` |

- 第 2 行**只写件数、不写种类**（搜寻是随机产出；效果预览的「逐字一致」要求只约束可确定的量，口径同[事件系统](../../../../玩法说明文档/系统规则/事件系统/事件系统.md) §一）。

## 三、产出表（草案）

- 每次搜寻**固定抽 2 次**：每次先按稀有度定档，再在该档的现役材料里均匀取一种。

| 稀有度 | 权重 | 材料（`DataBase/Item/Material.csv`） |
|---|---:|---|
| 普通 | **70%** | 苔藓 102 / 药草 101 / 蟾蜍 105 / 鸟类羽毛 107 / 铜矿石 201 / 铁矿石 202 |
| 罕见 | **25%** | 月光草 103 / 毒蛇 106 / 蝎尾 108 / 毒囊 109 / 银矿石 203 / 黑曜石 204 |
| 稀有 | **5%** | 龙血藤 104 / 凤凰羽毛 110 / 秘银 205 / 陨铁 206 |

- 两次可以抽到同一种材料 → 按背包的叠加口径**合并成一条**（数量 +1），不新开条目。
- 期望值：`2 × (70% 普通 + 25% 罕见 + 5% 稀有)` ≈ 1.4 普通 + 0.5 罕见 + 0.1 稀有；按[商人交互案](商人交互案.md) §五 的价格折算约 **27 金币/次**（2 时间点成本 ≈ 80 金币的 1/3），**低于**花 1 时间点去买 —— 树林的意义是**不花金币**、且产出随机的多样性，数值待随关卡金币收入校准（待拍板第 1–2 条）。

## 四、流程

1. 踏入入口格 → 弹确认 tips（§二）。
2. 点 `进入` → 扣 1 时间点 → 抽 2 次 → 直接入背包（超载时按背包既有口径「入账照入、提示超载」，不做拒绝）。
3. 反馈：角色上方浮字（`药草 ×1 / 苔藓 ×1`）+ 底部提示行一行文案；提示行在 tips 关闭后仍显示 2 秒。
4. 名称牌不变（树林没有「用过」状态）。
5. 点 `稍后` → 关 tips、不扣时间点、不产生材料（要再搜需走开再走回，村庄案 §五）。

## 五、失败原因表

| 情形 | 时机 | 文案 |
|---|---|---|
| 时间点不足 | 踏入入口格时（**不弹 tips**） | `时间点不足：需要 1.0，当前剩余 0.4。` |

- 树林没有别的拒绝面：不用金币、不占次数、不看状态（背包超载照旧入账并提示，见 §四 第 2 步）。

## 七、验收

1. 时间点 ≥ 1.0 → 踏入入口格弹 tips（`搜寻：材料 ×2` / `代价：1 时间点`）；点 `进入` → 扣 1.0、产出 2 件材料入背包、浮字与提示行正确。
2. 时间点 < 1.0 → 不弹 tips，给原因。
3. 同一材料抽到两次 → 背包里是**一条 ×2**（不是两条 ×1）。
4. 产出稀有度分布可在单测里用固定种子验证落在 70 / 25 / 5 的区间内。
5. 反复踏入入口格（走开再走回）→ 每次各扣 1.0，产出各自独立；时间点不足后停止。
6. `dotnet build` / `dotnet test` / `--run-flow-ui-smoke`（新增树林段）不回归。

## 八、待拍板（当前默认值）

| # | 问题 | 默认值 | 回改方式 |
|---|---|---|---|
| 1 | 每次产出的材料件数 | **2 件** | 改 `VillageForage.PicksPerSearch`（要配表则另开村庄数值表；`VillageLayout.csv` 只锁占格与入口格 —— 见[村庄案 §十](村庄地图交互案.md)） |
| 2 | 稀有度权重 | **70 / 25 / 5** | 改 `VillageForage` 的权重表并重算 §三 的期望值 |
| 3 | 是否允许空手而归 | **不允许**（固定 2 件） | 加一个「空手」档（例如 5% 概率产出 0 件），并把 tips 第 2 行改为 `搜寻：材料（可能空手）` |
| 4 | 是否只在白天可搜 | **全天可搜**（只看时间点够不够） | 加时段判据：晚上进入时给 `天黑了，林子里看不清路。` |
| 5 | 材料种类是否分区域 / 按层 | **每层同一张池**（现役 16 行材料） | 按层拆池：把材料表与会抽的池改成按 `Act` 过滤 |
| 6 | 是否受每日 Debuff 影响 | **不受**（村庄不在其覆盖范围内，村庄案 §八） | 覆盖范围扩张后若要影响，加一条产出折损 |
