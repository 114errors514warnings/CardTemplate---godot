## 一、代价与次数

| 项 | 值 | 说明 |
|---|---|---|
| 进入代价 | **无**（进入本身不是操作） | 2026-10-05 口径：踏入入口格不扣时间点、也不因时间点不足而拒弹 tips |
| 每次搜寻 | **1.0 时间点**（树林专属表值） | 点一次 `进入`（= 搜寻一次）扣一次 = 全局数据表**第 8 列 `ForestForageTimePointCost`**（当前 `1.0`）；**与村庄其他操作的 0.1 分开配**（第四轮口径）；不足时 → 给一行原因（§五），必须去旅馆 / 民宿过夜 |
| 可重复 | **是**：只要时间点够，入口格可反复踏入 | 每次搜寻各扣一次；进入本身不扣（第三 / 第四轮同） |
| 占用 | 5 格（东边折线 5）+ 入口格 1 | 见[村庄地图交互案](村庄地图交互案.md) §2.2 |
| 产出 | 材料**直接进背包** | 不落档单独字段（复用 `BagEntries`） |

## 二、确认 tips 内容

沿用村庄案 §六 的 4 行气泡：

| 行 | 内容 |
|---|---|
| 1 | `树林` |
| 2 | `搜寻：材料 ×2`（具体种类在结算时才揭晓，见 §三） |
| 3 | `代价：每次搜寻 1.0 时间点（点「进入」才收）` |
| 4 | `进入` / `稍后` |

- 第 2 行**只写件数、不写种类**（搜寻是随机产出；效果预览的「逐字一致」要求只约束可确定的量，口径同[事件系统](../../../../玩法说明文档/系统规则/事件系统/事件系统.md) §一）。

## 三、产出表（草案）

- 每次搜寻**固定抽 2 次**：每次先按稀有度定档，再在该档的现役材料里均匀取一种。

| 稀有度 | 权重 | 材料（`DataBase/Item/Material.csv`） |
|---|---:|---|
| 普通 | **70%** | 苔藓 102 / 药草 101 / 蟾蜍 105 / 鸟类羽毛 107 / 铜矿石 201 / 铁矿石 202 |
| 罕见 | **25%** | 月光草 103 / 毒蛇 106 / 蝎尾 108 / 毒囊 109 / 银矿石 203 / 黑曜石 204 |
| 稀有 | **5%** | 龙血藤 104 / 凤凰羽毛 110 / 秘银 205 / 陨铁 206 |

- 两次可以抽到同一种材料 → 按背包的叠加口径**合并成一条**（数量 +1），不新开条目。
- 期望值：`2 × (70% 普通 + 25% 罕见 + 5% 稀有)` ≈ 1.4 普通 + 0.5 罕见 + 0.1 稀有；按[商人交互案](商人交互案.md) §五 的价格折算约 **27 金币/次**（成本 = **1 时间点** ≈ 40 金币，[事件系统](../../../../玩法说明文档/系统规则/事件系统/事件系统.md) 的等价三角），**低于**直接花时间点去买 —— 树林的意义是**不花金币**、且产出随机的多样性，数值待随关卡金币收入校准（待拍板第 1–2 条）。

## 四、流程

1. 踏入入口格 → 弹确认 tips（§二）—— **不扣时间点**，时间点只剩 0.4 也照弹。
2. 点 `进入` → 校验时间点（不足则给 §五 原因、不抽样）→ 扣 **一次搜寻的时间点（树林专属表值 `ForestForageTimePointCost`，当前 1.0）** → 抽 2 次 → 直接入背包（超载时按背包既有口径「入账照入、提示超载」，不做拒绝）。
3. 反馈：角色上方浮字（`药草 ×1 / 苔藓 ×1`）+ 底部提示行一行文案；提示行在 tips 关闭后仍显示 2 秒。
4. 名称牌不变（树林没有「用过」状态）。
5. 点 `稍后` → 关 tips、不扣时间点、不产生材料（要再搜需走开再走回，村庄案 §五）。

## 五、失败原因表

| 情形 | 时机 | 文案 |
|---|---|---|
| 时间点不足 | 点 `进入` 后（**tips 照常弹**：进入本身不是操作，既不扣点、也不因时间点不足拒弹） | `时间点不足：需要 1.0，当前剩余 0.4。请前往旅馆或民宿过夜，或回营地结束当天。` |

- 树林没有别的拒绝面：不用金币、不占次数、不看状态（背包超载照旧入账并提示，见 §四 第 2 步）。

## 七、验收

1. 时间点 ≥ 1.0 → 踏入入口格弹 tips（`搜寻：材料 ×2` / `代价：每次搜寻 1 时间点（进入免费）`）；点 `进入` → 扣 1.0、产出 2 件材料入背包、浮字与提示行正确。
2. 时间点 < 1.0 → tips **照弹**（进入不扣点）；点 `进入` 被拒，给「请前往旅馆或民宿过夜，或回营地结束当天」的一行原因，且**不扣点、不产材料**。
3. 同一材料抽到两次 → 背包里是**一条 ×2**（不是两条 ×1）。
4. 产出稀有度分布可在单测里用固定种子验证落在 70 / 25 / 5 的区间内。
5. 反复踏入入口格（走开再走回）→ 每次**搜寻**各扣 1.0（进入本身不扣），产出各自独立；时间点不足后停止并给去处指引。
6. `dotnet build` / `dotnet test` / `--run-flow-ui-smoke`（新增树林段）不回归。
