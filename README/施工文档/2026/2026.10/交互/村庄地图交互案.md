## 一、定位

- 村庄是世界地图**中心固定格**的特殊节点（`MapNodeType.Village`，`FixedNode.csv` 的 `Village` 行）；本批把它从「解析成一个事件（现为 `Event / EVT-F1-001` 占位）」改为「进入村庄地点场景」。
- 村庄是**补给节点**：把金币 / 时间点换成回复、装备、食物与材料；不做战斗，不做成长值（地图玩法 §4.1）。
- 村庄**只能进入一次**（节点一次性）；村庄**内部**的设施可重复进入，各按 §五 的代价。

### 2.3 布局图与格数账（定稿）

图例：`H` 旅馆 / `F` 树林 / `R` 餐厅 / `I` 民宿 / `S` 锻铁铺；**小写 = 该设施的入口格**（`h` `f` `r` `i` `s`）；`E` 入口格（世界地图进入点）；`X` 离开格；`.` 空地。列位 = `2q + r`（与 `MapLayout.CenterOf` 的屏幕横坐标 `x = q + r/2` 对应，pointy-top）：

```text
r=-3:    H H H H
r=-2:   S . h . F
r=-1:  S s . . X F
r= 0: S E . . . f F
r= 1:  I . . . . F
r= 2:   I i r . F
r= 3:    I R R R
```

- 格数账：设施 **18**（旅馆 4 + 民宿 3 + 锻铁铺 3 + 餐厅 3 + 树林 5）+ 入口格 **5** + 入口格（世界地图）**1** + 离开格 **1** + 空地 **12** = **37** = R=3 的 `3R(R+1)+1`。
- 连通性：内圈 19 格（= 5 个设施入口格 + 入口格 + 离开格 + 12 空地）本身就是半径 2 的完整六边形盘面 → 天生连通；设施本体全在外圈，不会把内圈切断。故从入口格出发，5 个设施的门与离开格**全部可达**，不需要额外的连通性规则。
- 落档前自查（只读脚本，不入库）：判据 = ① 版图恰 37 格 ② 5 个设施占格互不重叠且各自连通 ③ 每个设施占格都在外圈 ④ 每个入口格只落在内圈、与本设施占格相邻、且不与别的入口格重复 ⑤ 内圈 19 格从入口格 BFS 全覆盖（含离开格与 5 个门）⑥ 入口格 ≠ 离开格 → 六条全通过（输出 `VILLAGE_LAYOUT_PASS`）。批 1 落地时把这六条写成单测（`VillageLayoutTests`），配表改一行就能红灯。

## 三、进入与离开

- **进入**：世界地图上点村庄节点（中心固定格）→ 淡出世界地图、淡入村庄场景；角色落在**入口格**。
- **离开**：走到**离开格**。本批不加别的主动出口（与[地图交互](../../../../交互说明文档/地图/地图交互.md)「内容完成后不自动回地图」一致：村庄内容没结束就一直是村庄）。
- 离开时：淡出村庄、返回世界地图（保持选点态），村庄节点按既有路径**标记已访问**；再次经过不重复触发。
- 村庄是「内容」：挂内容宿主（`RunFlowScene.ContentKind = "village"`）；期间世界地图以只读态可查看（同事件口径），战斗 / 事件 / 结算不能与它同时存在。
- 读档重进：按 `PendingContentType = "village"` 恢复村庄场景，并恢复角色所在格与设施使用标记（§十 第 6 条）。

## 四、移动与时间点

| 动作 | 时间点 | 说明 |
|---|---|---|
| 移动到相邻格 | **0** | **局内移动不消耗时间点、也不消耗能量**（2026-10-05 口径纠偏，取代旧稿的 0.3）：时间点只在**世界地图**「节点 → 相邻节点」那一跳消耗（数值读全局数据表 `GameVariables.csv` 的 `MoveTimePointCost` = 0.3，见[配表规范](../../../../功能说明文档/数据系统/数据配置/配表规范.md)），从村庄离开、前往下一个节点时才由世界地图侧计 |
| **进入任何设施** | **0** | 进入本身**不是操作**：不看、不扣时间点（2026-10-05 第三 / 第四轮同口径，取代第二轮「树林 / 锻铁铺 / 餐厅各 1 时间点」）；旅馆的 **1 金币**是过夜费、民宿免费；时间点不足也不挡进入（界面照开，操作时再拦） |
| **在设施里执行一次操作** | **0.1**（村庄基准值）/ **1.0**（树林搜寻） | 2026-10-05 第四轮口径：① 村庄设施（**锻造 / 烹饪 / 点菜（餐厅买入）**）各扣 **0.1** = 全局数据表第 7 列 `VillageOperationTimePointCost`（= 1 个战斗回合）；② **树林每次搜寻单独配**第 8 列 `ForestForageTimePointCost`（= **1.0**，与村庄其他操作**分开**）；③ 部分操作另收少量金币：锻造 = 配方金币、点菜 = 菜价。**进入设施本身不是操作**（不扣点）；纯交易不计：**出售食物不算**；旅馆 / 民宿的过夜是跨天，不是操作。**「进餐」本轮移出**（食物系统还没有「食用」动作） |
| 进入旅馆 / 民宿 | **0** | 旅馆扣 1 金币，民宿免费 |
| **在村庄过完这一天** | **不发 Debuff** | 这一天结束时**不获得**每日 Debuff（它只在世界地图上跨天时累积）；旅馆「清 Debuff」清的是**既往**层数（§八） |

- 时间点不足只会卡住**设施操作**（局内移动与进店都免费，任何时候都走得动）：**拒绝该动作**并在提示行给原因（`时间点不足：需要 0.1，当前剩余 0.0。请前往旅馆或民宿过夜，或回营地结束当天。`，树林那条用 `1.0`）；村庄内**不自动转营地**（离开村庄后由世界地图侧按现有口径处理）—— 待拍板第 2 条。**注意**：村庄操作一次 0.1 = 时间点的最小计量单位，进程里不存在「比一次操作更小、又非 0」的剩余，所以这条拒绝路径实际上只在表值被调大（≥ 0.2）时才会走到。
- 移动判定复用局内地图的可达性查询（不另写一套）：点可达格 → 沿路径走一格格到位；不可达格不响应。
- **边界口径（2026-10-05 用户裁定）**：「消耗时间点」只发生在**世界地图**上「节点 → 相邻节点」的移动（普通敌袭 / Boss 关 / 村庄等节点之间）；**地点局内**（村庄，将来的商人）的走动一律**零消耗**，能量也一样不扣。故村庄内的移动没有任何时间点门槛。
- **四段代价互不抵扣（2026-10-05 第四轮口径定稿）**：① 世界地图「节点 → 相邻节点」= **0.3**（读全局数据表第 6 列 `MoveTimePointCost`）；② 地点**局内移动** = **0**；③ **进入设施** = **0**（不是操作；旅馆 1 金币是过夜费）；④ **设施内每次操作** = **0.1**（村庄基准值，第 7 列 `VillageOperationTimePointCost`）/ **1.0**（树林搜寻，第 8 列 `ForestForageTimePointCost`）。例：走到锻铁铺门口（0）→ 进店（0）→ 打造一次（0.1 + 配方金币）；从树林出来接着逛不额外扣。
- **村庄内的时间点补给只有两条路（2026-10-05 第三轮）**：**旅馆 / 民宿过夜**（1 金币 / 免费 → 推进到新一天 → 补满 4.0）、或**离开村庄回营地**结束当天（剩余时间点按比例转休息收益）。**进村不再补满**（「重置为最大」已取消）；时间点进程回到[地图玩法 §5.2](../../../../玩法说明文档/系统规则/地图玩法/地图玩法.md) 的「只增不减」不变式，代码侧没有任何回退式重置。

## 五、设施入口触发

- 触发条件：角色**踏入入口格**（移动完成的那一刻）。
- 触发即分流：
  - **确认 tips 类**（旅馆 / 民宿 / 树林）：角色头顶弹确认 tips（§六），等玩家点 `进入` / `稍后`；
  - **专用界面类**（锻铁铺 / 餐厅）：直接打开对应界面（界面自带 `关闭`）。
- 拒绝（**次数 / 状态 / 金币**不满足，与时间点无关 —— 时间点不足只拦「操作」）→ **不弹 tips、不开界面**，只给一行原因（各案定义），角色留在原格。
- 点 `稍后` → 关 tips，角色停在入口格；**要再触发必须先走开再走回**（避免原地站着重复弹）—— 待拍板第 3 条。

## 六、确认进入 tips（3 案共用组件）

- 形态：跟随角色的**气泡**（挂角色上方 24 px、带尖角指向角色），宽 260、圆角 12；**不做全屏遮罩**、不打断地图。
- 内容固定 4 行：

| 行 | 内容 |
|---|---|
| 1 | 设施名 + 图标 |
| 2 | 本次进入的效果摘要（含数值预览，如 `回复 15 生命；清除每日 Debuff 2 层`） |
| 3 | 代价（如 `代价：1 金币`；免费写 `代价：无`；按次收费的设施写 `代价：每次搜寻 1 时间点（进入免费）`） |
| 4 | 两个按钮：`进入` / `稍后` |

- tips 打开期间**锁定移动输入**（不能边走边看）；同一时刻最多 1 个 tips。

## 八、昼夜与 Debuff

- **晚上判定**：`RunTimePoints.RemainingToday(总进程) ≤ 1.0`（当天已用 ≥ 3.0 = 3/4 天）→ 视为晚上；旅馆 / 民宿的「晚上效果更好」按这个判据（各案的数值表）。
- 阈值写成一个常量 + 单测锁边界（剩余 1.0 / 1.1 两侧），命名与 `RunTimePoints` 同风格（建议 `RunTimePointsNight.Threshold = 1.0f`）。
- **每日 Debuff**（地图玩法 §5.4）：村庄是本局唯一能**清除**它的地方（旅馆）；按 §5.4 前期口径村庄**不在** Debuff 覆盖范围内，故村庄设施效果不受它影响。
- **在村庄过完这一天 → 不发 Debuff（2026-10-05 口径，第三轮保留）**：每日 Debuff 只在**世界地图上跨天**时发放；在村庄内结束当天（旅馆 / 民宿过夜，或将来放开 §十二 第 4 条的「结束当天」）**不发放**当天的这一层。故「村庄内过夜」的净效果 = 回复 + 清**既往**层（旅馆专属）+ 补满新一天的 4.0 时间点 + **不新增** Debuff。
- **时间点补给（2026-10-05 第三轮）**：村庄内**唯一**能把时间点补满的是**旅馆 / 民宿过夜**（推进到新一天 → 4.0）；设施每次操作收 1.0，不足 1.0 时按 §四 给「请前往旅馆或民宿过夜，或回营地结束当天」的指引。进村那一刻**不补满**（「重置为最大」已取消，进程保持只增不减）。
- 休息类设施（旅馆 / 民宿）**推进到新一天**（当天剩余作废 → 新一天 4.0），**不触发篝火休息**：不吃食物、不选守夜、不触发夜袭与「睡眠不佳」（[篝火休息与食物](../../../../玩法说明文档/系统规则/营地系统/篝火休息与食物.md) §一：村庄的回复独立于篝火休息）；跨天时食物有效期照常 −1。

## 十一、验收

1. 点村庄节点 → 淡入村庄场景，角色落入口格，37 格一屏居中可见。
2. 5 个设施单位的占格与 §2.2 定稿表逐格一致（NodeId 集合相等），名称牌可见，入口格是设施中唯一可踏入的格；外圈 18 格被设施铺满、内圈 19 格全可走。
3. 局内移动到相邻格**不消耗**时间点（也不消耗能量）：任何时间点余量下都能走；时间点只在世界地图「节点 → 相邻节点」那一跳消耗（离开村庄、前往下一个节点时由世界地图侧计 0.3）。
4. 踏入旅馆 / 民宿 / 树林入口格 → 弹跟随角色的确认 tips（4 行 + 两个按钮）；点 `稍后` 关闭且不重复弹。
5. 踏入锻铁铺 / 餐厅入口格 → 直接开对应界面（Modal 层），`Esc` / `关闭` 可退。
6. 村庄内背包可整理（装备 / 道具栏落点不被拒）；常驻栏 `结束当天` 不可点。
7. 走到离开格 → 回世界地图并标记节点已访问；再点该节点不再进入。
8. 在村庄内退出再读档 → 回到村庄场景，已用设施标记保留。
9. `dotnet build` / `dotnet test` / `--run-flow-ui-smoke`（新增村庄段）不回归。
10. **进入设施不消耗时间点**：时间点只剩 0.4 也能进店 / 进树林 / 进旅馆与民宿（界面照开）。
11. **每次设施操作扣 1.0**：搜寻一次、打造一次、烹饪一次各扣 1.0；结算后常驻栏与界面标题行的时间点同步刷新（`第 N 天 · 剩余 X.X / 4.0`）。
12. 当天剩余 < 1.0 → **不能执行操作**：按钮转 `时间点不足` 禁用，费用行 / 提示行给 `时间点不足：需要 1.0，当前剩余 0.4。请前往旅馆或民宿过夜，或回营地结束当天。`；去旅馆 / 民宿过夜后补满 **4.0** 可继续操作。
13. 进村那一刻**不再**补满时间点（第三轮取消「重置为最大」）；离开村庄后世界地图移动照旧计 0.3。
14. 在村庄内过夜（旅馆 / 民宿）**不发放**当天的每日 Debuff（`P2-20` 落地后可用调试口核对层数不增；旅馆只清既往层）。
