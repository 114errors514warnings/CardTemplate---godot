# 战斗系统打磨说明

> 方向①：现有战斗系统的"地基级"打磨。**不新增角色卡牌**。

## 目标

把当前**分散在多处**的硬编码（状态名中文映射、状态颜色、状态持续时间、状态效果描述）**统一到 `StateDefinition`**，让未来新增 / 改状态时**只改 CSV 一处**就能生效。

## 现状（重复实现点）

| 位置 | 内容 | 重复 |
|------|------|------|
| `Scripts/UI/CardBattleScene.cs:747-765` | `GetStateDisplayName` 硬编码 switch | ✓ |
| `Scripts/UI/UnitInstanceView.cs:367-385` | `GetStateDisplayName` 硬编码 switch | ✓ |
| `Scripts/UI/CardBattleScene.cs:711-725` | `ShowStateTooltip` 硬编码效果描述 | ✓ |
| `Scripts/UI/UnitInstanceView.cs:387-401` | `GetStateChipBackground` 硬编码颜色 | ✓ |
| `Scripts/UI/CardBattleScene.cs:766-772` | `BuildStateDurationText` 分散判断 | 部分 |
| `Scripts/UI/CardBattleScene.cs:738` | `ShowStateTooltip` 调用 | — |

**问题**：4 处 `switch` 重复定义状态名 / 颜色 / 描述。新增状态（如 `IsDebuff=true` 的 `Slow`）需要改 **4 处** + CSV = **5 处**。
