# 战斗系统打磨说明

> 方向①：现有战斗系统的"地基级"打磨。**不新增角色卡牌**。

## 目标

把当前**分散在多处**的硬编码（状态名中文映射、状态颜色、状态持续时间、状态效果描述）**统一到 `StateDefinition`**，让未来新增 / 改状态时**只改 CSV 一处**就能生效。

#### 枚举关系（关键决策）

`StateDecayTiming`（5 值含 `Never`）与 `DecayTrigger`（4 值不含 `Never`）**保持独立枚举**——

- `Never` 是状态定义属性（"我不衰减"），**不是**调点（不存在"从不被触发"调点）
- 通过 `StateDecayProcessor.ShouldDecayAtTiming(timing, trigger)` 按同名时匹配（line 133-143）
- 早期实施中 `def.DecayTiming != trigger` 编译失败——通过 `ShouldDecayAtTiming` 桥接（`StateDecayTiming` 与 `DecayTrigger` 是不同枚举，**不能直接比较**）

- 勇气铠甲 (9) `OnTurnEnd + Flat + 1`：玩家 A 打出 → 本玩家回合结束 -1 → 移除（仅本回合）
- 持盾防守 (13) `OnTurnStart + ClearAll`：玩家回合开始 → 给 3 护盾 → 立即清除
- 蓄势待发 (16) `OnTurnStart + ClearAll`：玩家回合开始 → 立即清除（覆盖整个玩家+怪物循环）
- 易伤 (1) `OnTurnStart + Flat + 1`：玩家回合开始 -1 → 多叠层用
- 燃烧 (3) `Never + None + 0`：永久，不衰减

#### 风险与缓解（实施结果）

| 风险 | 缓解结果 |
|------|----------|
| `OnTurnStart` 内删 `toRemove` 影响 `TurnStartEffect` / `ShieldGuard` 移除 | 用 `ClearAll` 模式 + `StateDecayProcessor` 处理 ✅ |
| 调点顺序错误导致给资源时状态已移除 | 严格 `OnTurnStart` 在前、`ProcessDecayAtTiming` 在后 ✅ |
| `OnAttackPlayed` / `OnDamaged` 触发点多 | 性能可接受（遍历 `unit.States` 通常 0-5 项）✅ |
| 其他模块引用 `def.IsPermanent` 失败 | 全局搜索 `IsPermanent` 替换为 `DecayTiming == Never` 判定 ✅ |
