# 动效系统打磨说明

> 方向②：补全战斗动效，让卡牌模拟器从"逻辑可跑"升级为"看着爽"。
> 依赖方向 ① 完成的 `StateDefinition.ChipColor` / `EffectDescription` 字段。

## 目标

让战斗中的**所有数值变化**都有**视觉过渡**（HP 下降、护盾获得、状态附加、卡牌打出）。**不新增角色卡牌**。

|------|------|------|
| 飘字伤害 | `CardBattleScene.ShowDamageNumberOnUnit` line 154-189 | ✓ 已实现 |

| 死亡覆盖 | `UnitInstanceView.ShowDeadOverlay` line 228-256 | ✓ 已实现 |

**问题**：飘字有 2 处重复实现，**没抽出**通用 Tween 工具类；其他动效全部缺失。

## 待做需求

### 优先级 P0（基础动效）

#### 1. 通用 Tween 工具类
- **目标**：抽 `Scripts/UI/Animation/TweenHelper.cs` 静态类，封装缓动函数 + 并行 / 串行
- **API**：
  ```csharp
  TweenHelper.FadeIn(control, duration: 0.3f, easing: Tween.EaseOut);
  TweenHelper.FadeOut(control, duration: 0.3f, callback: () => control.QueueFree());
  TweenHelper.ScaleTo(control, Vector2.One * 1.2f, duration: 0.15f, back: true);
  TweenHelper.Slide(control, from, to, duration: 0.5f);
  TweenHelper.Shake(control, intensity: 8f, duration: 0.3f);  // 震动
  TweenHelper.FlashColor(control, Colors.Red, duration: 0.1f); // 闪红
  ```
- **依赖**：纯 Godot API（`CreateTween` / `TweenProperty`）
- **工作量**：1.5 天

#### 2. 卡牌打出飞行轨迹
- **现状**：打出后直接从手牌列表消失，进入弃牌堆
- **目标**：打出的卡牌**飞行**到目标单位 → 目标命中 → 飞回弃牌堆
- **改动**：
  - `CardPlayController.PlayHandCard` 入口加异步流程
  - 飞行使用 `TweenHelper.Slide`
  - 命中时 `TweenHelper.ScaleTo` 弹一下
- **工作量**：2 天

#### 3. 血条下降动画
- **现状**：`UnitInstanceView.Bind` line 49 `healthBar.Value = unit.HP`（直接设值）
- **目标**：HP 变化时 `Tween` 从 oldValue → newValue，0.3s 缓动
- **改动**：
  - `UnitInstanceView` 缓存 `lastHealthBarValue`
  - 每次 `Bind` 调 `TweenHelper.Slide` 从 last → current
  - HP <= 0 时额外触发 `TweenHelper.Shake` + 闪红
- **工作量**：1 天

#### 4. 护盾获得 / 消失动画
- **现状**：护盾数值直接设值，无视觉
- **目标**：护盾增加时飘"+X 护盾"绿字（`TweenHelper.FadeIn` + `Slide`），消失时飘"-X"红字
- **改动**：
  - 抽 `CardBattleScene.ShowFloatingText(unit, text, color)` 通用方法
  - 护盾变化时（EffectSystem.ApplyShield 后 / 回合开始清零后）调
- **工作量**：1 天

### 优先级 P1（核心体验）

- **依赖**：方向 ① 的 `StateDefinition.ChipColor`
- **改动**：
  - `UnitInstanceView.PopulateStates` 加 Tween
  - `StateSystem.OnStateEnded` 回调里调淡出
- **工作量**：1.5 天

#### 6. 怪物意图切换动画
- **现状**：意图换行时 `MonsterIntentionFormatter` 直接换文本
- **目标**：新意图 fade-in + 旧意图 fade-out（0.3s 交叉），目标标记（`SelectedIntentionTarget`）高亮玩家
- **改动**：

  - `MonsterIntentionService.UpdateMonsterIntentionPreviewTarget` 后高亮目标玩家
- **工作量**：1 天

#### 7. 反击命中震动 + 闪光
- **现状**：`EffectSystem.TryTriggerCounterAttack` 触发后无视觉

- **改动**：

#### 8. 蓄势待发反击出牌动画
