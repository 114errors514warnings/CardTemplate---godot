## 待做需求

### 优先级 P0（必做 — 8月文档 §3.3 I 4 步流程）

#### 1. 主菜单场景（MainMenuScene）
- **需求来源**：8月文档 §3.3 I "主菜单"
- **目标**：游戏入口，开始游戏 / 设置 / 退出
- **新场景**：`Scenes/MainMenu/MainMenuScene.tscn`
- **新脚本**：`Scripts/UI/MainMenuScene.cs`
- **元素**：
  - 标题："卡牌模拟器"
  - 按钮：开始游戏 / 设置 / 退出
  - 简单背景（ColorRect / 渐变）
- **工作量**：1.5 天

#### 2. 关卡选择（地图场景）— 最小版本
- **需求来源**：8月文档 §3.3 I "关卡选择（地图可后置）"
- **目标**：节点图，章节内多关卡
- **新场景**：`Scenes/Map/MapScene.tscn`
- **新脚本**：`Scripts/Map/MapScene.cs` + `Scripts/Map/MapNode.cs`
- **数据**：`DataBase/Map/Act1.csv`（节点 ID / 类型 / 坐标 / 邻居）
- **节点类型**：
  - `Combat` 普通战斗
  - `Boss` boss 房（章节末尾）
- **UI**：从起始节点画折线到下一层节点，可点击
- **工作量**：5-7 天

#### 3. 战利品选择（CardRewardScene）
- **需求来源**：8月文档 §3.3 I "战利品"
- **目标**：战斗胜利后选 1 张卡加入牌组
- **新场景**：`Scenes/Reward/CardRewardScene.tscn`
- **新脚本**：`Scripts/UI/CardRewardScene.cs`
- **改动**：
  - 战斗胜利时跳到 `CardRewardScene`
  - 选完后跳回 `MapScene` 或 `MainMenuScene`（未实现 §4 时跳 MainMenu）
- **工作量**：1.5 天

#### 4. 战斗结算场景（BattleResultScene）
- **需求来源**：8月文档 §1.4 "完整战斗关卡"（"至少一条通关链路"需要结算反馈）
- **目标**：战斗结束后的统一界面（胜利 / 失败）
- **新场景**：`Scenes/BattleResult/BattleResultScene.tscn`
- **新脚本**：`Scripts/UI/BattleResultScene.cs`
- **元素**：
  - 大字"胜利！" / "失败"
  - 战斗统计（伤害输出、承受伤害、回合数、剩余 HP）
  - 按钮：继续 / 重试 / 返回主菜单
- **调用时机**：`BattleSytem.CheckBattleEndAndHandle` 改为 `EmitSignal("BattleEnded", result)`，由 `CardBattleScene` 监听切场景
- **工作量**：2 天

#### 5. 完整战斗循环接线
- **需求来源**：8月文档 §3.3 I 整条流程
- **目标**：把"主菜单 → 关卡选择 → 战斗 → 战利品" 4 步用 `SceneTree.ChangeSceneToFile` 串起来
- **改动**：
  - `MainMenuScene`：开始游戏 → 跳到 `MapScene`（act 1 起始）
  - `MapScene`：点 Combat 节点 → 跳到 `BattleSetupWindow`（沿用现有）→ 战斗 → 跳 `BattleResultScene`
  - `BattleResultScene`：胜利 → 跳 `CardRewardScene`；失败 → 跳回 `MainMenuScene`
  - `BattleSytem.EndGame` 改为 emit signal 而不是 `ShowSetupWindow`（破坏现有流程需小心）
- **工作量**：2 天

### 优先级 P1（应做 — §1.4 "完整战斗关卡"）

#### 6. boss 房 + boss 怪物
- **需求来源**：8月文档 §1.4"完整战斗关卡" + §3.3 F 怪物体系补全
- **目标**：每章节末尾的 boss 房
- **新增**：`DataBase/Unit/Boss/` 下 boss CSV（**不新增角色卡牌**，boss 算"怪物补全"）
- **改动**：
  - 地图章节末尾节点标记为 `Boss`
  - 进入 boss 房时强制 `BattleSetupWindow` 显示 boss 信息
- **工作量**：2-3 天
