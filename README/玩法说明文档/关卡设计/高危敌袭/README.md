- **高危敌袭不分档**：`NormalCombatRule.csv` 只给普通敌袭分 Low / Mid / High；高危池只有 `Difficulty High` 一种行 → 四关**同难度、池内等权（`Weight 1`）**，玩家每次进「危」节点随机取一关。若希望随层递进，需另加池行或加档（**待拍板**）。
- 与直属对照：高等档普通敌袭 = 168 / 22 / 11 / 4；精英 = 210 / 27 / 13 / 5。**高危档夹在中等（130 / 18 / 9 / 3）与高等之间**，但奖励更高（2002 档）。

## 三、记账口径与容差

- **口径**：意图**等概率**求期望；状态按**名义层数**（不乘命中人数，含加攻）；**护盾只算给友方的部分**（自身盾不计，与 F1-008 / F1-009 的 3.5 口径一致）；爪牙不计（本组无爪牙）。
- **容差**：四关按 **±3.5%** 记账（`F1-H-003` 是唯一五项全中的基准关）；额外压力（`F1-H-001` 的**金币损失**、`F1-H-002` 的**空间封锁**、`F1-H-003` 的**状态叠层时机**、`F1-H-004` 的**距离压制**）**不计入四项指标**，与 F1-006 / F1-007 的处理同口径。
- ⚠️ **共用模板的联动风险**：`3118 / 3119 / 3126` 同时被 F1-008 / F1-009 与本组四关使用，`3120 / 3123` 也与 F1-008 / F1-009 交叉 —— **任一模板改数值，六关都要同步重算**（见[关卡档位表 §五](../../系统规则/数值平衡/关卡档位表.md)）。
