# F1-H-003 收容区泄漏（高危敌袭 · C 机构外缘）

> 第一层**高危敌袭**第 3 关（节点类型 `HighRiskCombat`，池 `P-F1-HIGH-RISK`）。档位目标见[关卡档位表](../../系统规则/数值平衡/关卡档位表.md) **「高危敌袭」行**：总 HP **145** / 每轮直接伤害 **20** / 状态·强化压力 **10** / 护盾支援 **3**（纯攻清场 **4.0** 轮）。
> ⚠️ **构思稿（2026-10-02），未配表**：`DataBase/Level/Config/F1-H-003.csv` 尚不存在，`LevelIndex.csv` / `LevelPool.csv` 也没有本关行。按[工作守则 §十](../../../AIWorkSpace/AgentOps/工作守则.md)「构思阶段只出文档，不落配置」，**本轮零 `DataBase/**` 改动**；数值为草案，需实配时校准。
> 地点主题取自[符文之地设计指引·区域与遭遇阶段](../../../世界观相关内容/怪物设计示例/符文之地设计指引/区域与遭遇阶段.md) **C 机构外缘：居住、警戒与收容区（后段）**（收容室 / 庭院 / 守卫哨所；优先敌源＝失控学徒、伏魔护卫、活化铠甲、逃逸收容物、中型原生体；目标示例＝「压制逃逸试验品」「解除失控哨戒」）。
> 本关是**状态叠层轴**的高危关：把它放在 C 区段，是因为这一段的威胁不是「更强」，而是「**越拖越硬**」—— 装置与学徒把状态叠满，玩家在状态里越打越慢。

## 一、关卡思路

一间收容室破了：腐蚀性的收容物正在外溢，看守它的活化铠甲还在执行封锁命令，两名学徒被状态压得失控。

- **活化铠甲（3120）堵在宽缺口正中**：32 HP / 8 攻 / 5 防。相邻 8 伤（残甲斩击）或 3 格直线 5 伤 + 移动 3（铠甲冲撞）。它是本关唯一必须硬解的耐久点，也是「每轮伤害 20」的主力。
- **两只受侵蚀巡逻犬（3108）从缺口两侧压上**：相邻 4 伤，或以 1 点自身护盾待机。它们逼玩家在「先打铠甲」与「先清犬」之间选。
- **三罐酸蚀黏液（3119）**：2 伤 + 2 层易伤 / 2 伤 + 1 层易伤。与本关另两处状态源叠加后，玩家的**有效输出会被压掉约三成**。
- **两座失控哨戒装置（3118）**：100% 给随机一名角色 2 层虚弱，50% 给半径 3 友方各 3 盾 —— 护盾支援 3.0 的来源，同时让「打不动」的问题翻倍。
- **一名失控学徒（3126）**：3 层易伤 / 7 伤远程直线。18 HP，是本关最脆也最该优先点的目标。

核心决策：**三处状态源（装置 ×2 + 黏液 ×3 + 学徒 ×1）先拆哪一个**（拆完输出才回得来）、**要不要先绕开铠甲清两翼的犬**（犬只有 14 HP，但会持续扣血）、**在易伤叠到第几层时必须转防守**。

## 六、玩家决策

1. **先拆装置还是先拆学徒**：装置（12 HP ×2）停虚弱 + 断护盾，学徒（18 HP）停 3 层易伤；两者都在后排，而铠甲正在正面推进。
2. **要不要先清两翼的犬**：犬只有 14 HP，但会持续扣血并牵扯站位；不处理它们就要在铠甲面前被打第二份伤害。
3. **易伤到几层转防守**：黏液 + 学徒每轮 5 层的名义密度下，第 3 回合后玩家的承伤倍率会明显上升 —— 建议在第 3 回合开始预留防御牌。
4. **别站在 `0,-2` 缺口正中**：那是铠甲冲撞（3 格直线 + 移动 3）与多线黏液的交点；从缺口两侧分开进入能少吃一份范围。

## 七、配表前验收

1. 三人 4 能量、无装备队伍在 **4.5 轮**（上限口径 3.6 轮）完成全歼，累计净伤害 ≈ **48**（期望口径；安全区间）。
2. **铠甲必须是本关的耐久轴**：它单独要吃掉约 1 轮输出（32 HP + 5 防）；若实测 1 轮即倒，需复核防御口径或换 3117。
3. **三处状态源都要落在角色身上**（`3;0;…`：黏液 2/1 层易伤、装置 2 层虚弱、学徒 3 层易伤），怪物自身 0 层。
4. **装置的盾只给友方**（半径 3）：铠甲与附近黏液应吃到 3 点，装置自身不吃。
5. **不出现出生在断墙、坑洞、玩家出生格或封闭区域的单位**（`BATTLEFIELD_LEVEL_CONFIG_PASS` 覆盖建场自检）。
6. 本关**不使用** `BattleRule`（无逃跑、无条件意图），意图按等概率出。
