## 一、关卡思路

一对**伴侣法师**在同一个实验台上失控：男方把符能全部灌进攻击，女方一边缠绕一边给两人撑起护幕 —— **男方是输出、女方是安全阀**。这一关的压力轴是**「互补二人的拆解顺序」**，而且**场上只有这两个人**（2026-10-02 第二版：去掉全部散兵；**第三版：散兵留下的缺口由这两人的数值全额补足**）：

- **男方（失控男法师 3123）= 纯输出，两种攻击方式，每条都挂易伤**：**符能投掷**（投掷 / 射程 4 / 移动 1，**18 伤 + 6 层易伤**）与**暴走突进**（近战直线 2 / **移动 3**，**22 伤 + 6 层易伤**）。投掷是**投掷几何**（只看距离、不吃障碍截断）→ 躲柱子没用，只有**拉距离**；近战带 3 格移动 → 他会主动贴上来打 22 点，逼你决定"谁去顶"。
- **女方（失控女法师 3124）= 支援，三种动作，每条都挂虚弱**：**缠绕投掷**（投掷，**6 伤 + 5 层虚弱**）／**抽能护幕**（半径 3 友方各 **12 点护盾**，同时抽走**随机一名角色 5 层虚弱**）／**伴侣共鸣**（自身与伴侣各 +1 层力量 + **随机一名角色 5 层虚弱**，力量段**需代码 P2-25**）。她每轮只出其中一条 → 玩家能读出"这轮她要撑盾还是缠我"。
- **为什么"少次数、每次 5–6 层"**：本关只剩 2 只单位，档位的**状态压力 11 层/轮**只能这么凑（男方 6.0 + 女方 5.0 = **11.0**）。这不是把玩家往死里打：`通用State.csv` 的易伤 / 虚弱**强度与层数无关**（`StateSystem.ModifyIncomingDamage`：只要层数 > 0 就 ×1.5 / ×0.75），**层数 = 持续回合数**（`DecayTiming=OnTurnStart` / `Flat` / 1），而且**清状态牌是整条移除**（`TryRemoveFirstNormalDebuff` → `RemoveState` 清掉该状态全部层数）→ 5–6 层 = "更久、但一张清状态牌就能整条拆掉"的**可反制**压力。
- **女方死后，男方狂暴**：新增两条**与原本攻击方式一一对应**的意图 —— **符能连掷**（投掷，**7×3 = 21** + 6 层易伤）与**连续突进**（近战，**8×3 = 24** + 6 层易伤）。单次伤害**下降**（18 → 7、22 → 8）、总额**上升**（18 → 21、22 → 24），期望 20.0 → **22.5**（**+12.5%**）。
- **本关没有散兵**（第二版用户指令）：编组从 v1 的 9 只、第一版构思的 7 只收到 **2 只**；档位的「总 HP 168」全部由伴侣二人分摊（**88 + 80**），并且**每轮伤害 22.0 / 状态 11.0 / 护盾 4.0 / 清场 4.2 轮** 也全部由这两人承担 —— 散兵原先分摊的四条轴，**由面板 + 意图数值整条接回来**（这是第三版相对第二版唯一的改动）。

核心决策：**先斩女方还是先顶男方**——杀女方 = 拆掉护幕（−4.0 盾/轮）与 5 层虚弱，但立刻触发男方狂暴（20.0 → **22.5** 伤/轮）；留女方 = 每轮多一次高额虚弱或护幕，但男方"只有"20.0 伤。**这是本关第一次把"杀死一个敌人可能是坏主意"做成可读的选择**（代价：需要 P2-24 规则）。

**价值补足核对（主验收口径 = 被移除散兵的关卡怪物价值）**：口径 = [综合价值点数](../../../系统规则/数值平衡/单位数值平衡标准.md)（面板 HP + 意图加权价值，K = 1.0）。**v1 全关 210.0** = 伴侣对 **72.5**（3123 = 38.0 + 3124 = 34.5）+ 散兵 **137.5**（学徒 3126×3 = 73.5 + 装置 3118 = 15.5 + 黏液 3119×2 = 38.0 + 小史 3122 = 10.5）；**v3 两人合计 219.25**（3123 = 88 + (30 + 34 + 33 + 36) ÷ 4 = **121.25**、3124 = 80 + (16 + 22 + 16) ÷ 3 = **98.0**）→ **+4.4%**，把 137.5 的缺口**整条补回**（伴侣对增量 146.75 ≥ 137.5）。⚠️ v1 全关价值 210.0 与「精英档总 HP 210」数值相同只是**巧合**（价值点数含意图加权、档位表总 HP 只用面板 HP），本关口径仍是**高等档普通敌袭**。

**档位四项指标对照（顺带贴住）**：总 HP 168（目标 168，**0%** ✓）、每轮伤害 **22.0**（目标 22，**0%** ✓；狂暴后 22.5，+2.3%）、状态压力 **11.0**（目标 11，**0%** ✓）、护盾 **4.0**（目标 4，**0%** ✓）、清场 **4.2 轮**（2026-10-07 新口径 = 168 ÷ 40；旧记法 4.7 用的是已废止的 ÷36）—— 四项全中。去散兵留下的缺口由两位伴侣的**面板 + 意图数值**整条接回（先补价值，档位自然贴住）。

> **状态轴为什么能靠 2 只单位凑齐 11**（第二版结论作废的根据）：`通用State.csv` 里易伤 / 虚弱的**强度与层数无关** —— `StateSystem.ModifyIncomingDamage` 只在 `stacks > 0` 时把伤害 ×1.5 / ×0.75 一次，**层数等于"还能持续几回合"**（`DecayTiming=OnTurnStart` / `DecayMode=Flat` / `StacksToRemove=1`）；清状态牌走 `TryRemoveFirstNormalDebuff` → `RemoveState`，**整条移除**。所以"每轮 6 + 5 层"= 把两条 debuff 续到 6 / 5 回合长，玩家有明确反制，**不是**"单发 5 层 = 死刑"。
> ⚠️ **最痛的一击**：男方常态 **22 单发**，若目标已带易伤 → `floor(22 × 1.5) = 33`，而标准三人队角色满血只有 **30**（`Character.csv` 1002 / 1003 / 1004）→ **无盾即倒**。这是"9 只散兵的伤害预算压进 2 只"的必然结果，处理手段 = **清易伤 / 预铺护盾 / 拉距离**（见 §七）。
> **低峰值旋转钮（保留，默认不启用）**：若实机反馈"22 单发过于惩罚"，把男方常态的两条也改多段 —— 符能投掷 `1;-6\|1;-6\|1;-6` = **6×3 = 18**、暴走突进 `1;-1\|1;-1` = **11×2 = 22**，总额与状态都不变、单次峰值 22 → 11（带易伤 16），档位四项指标一分不动。**默认不切** —— 22 单发是"把散兵的伤害预算并进 2 只"的必然结果，见[核心区法师怪设计 §5.1](../../../怪物设计/核心区法师怪设计.md)。

> **狂暴后的轴**：女方退场 → 男方期望从 20.0 升到 **22.5** → 本关每轮伤害 22.0 → **22.5**（+2.3%，仍在档位内）；而 5 层虚弱与护幕同时消失（−5.0 状态、−4.0 护盾）。也就是说"先杀女方"换来的是**一条更陡的伤害曲线**，这正是本关想让玩家权衡的东西。

## 七、玩家决策

1. **先斩女方还是先顶男方（本关唯一的、也是全部的选择）**：杀女方 = 立刻拆掉护幕（−4.0 盾/轮）与 5 层虚弱，但男方期望从 20.0 跳到 **22.5**；留着女方 = 每轮多一次"5 层虚弱 / 12 点护幕 / 双人加力量"，但男方"只有"20.0 伤。**本关没有杂兵可以拖时间**，所以这个选择从第一回合就要做。
2. **两轮换一个开关**：女方 80 HP / 3 防 —— 三人队集火（≈ 36/轮）两轮能杀、一轮杀不掉。**"花两轮关掉支援、然后硬吃狂暴"是标准解**；不吃狂暴就得去磨 88 HP 的男方，更久。
3. **投掷要拉距离、近战要卡位**：男方的投掷只看距离（**不吃障碍截断**），躲柱子无效、拉距离有效；近战突进带移动 3，贴上来那一轮就是 22 点（狂暴后 `8×3` = 24）。
4. **护幕要吃在爆发轮之前**：女方 12 点护幕只给半径 3 内的友方（也就是男方与她本人）—— 你的爆发轮撞上护幕就等于白打一轮，**读她的意图再决定这轮打谁**。
5. **易伤要算进承伤计划**：男方的每一条攻击都会给你丢 **6 层易伤**，一旦你身上已经有易伤，他下一击就是 `22 × 1.5 = 33` —— **超过角色的 30 点满血**。三条处理路径：**清状态牌**（整条移除，最划算）、**预铺护盾**（33 点护盾吃满一击）、**拉出近战距离**（投掷只有 18）。被 5 层虚弱缠住的角色则改去打控制 / 铺盾 —— 虚弱同样可以被一张清状态牌整条拆掉。

## 八、配表前验收

> 前提：§四 的狂暴要等 **P2-24**、§三 女方「伴侣共鸣」要等 **P2-25** 落地。

1. 三人 4 能量、无装备队伍平均 **4–5 回合**完成战斗（纯攻 4.2 轮 = 上限口径 / 期望口径 5.6 轮，见[关卡档位表 §一](../../../系统规则/数值平衡/关卡档位表.md)）；若 3 回合内清完，说明虚弱 / 易伤没有实际生效，先查状态施加链路。
2. **狂暴只在女方退场后出现**：女方在场时男方的意图只能是 `18` / `22`（不得出现 `7×3` / `8×3`）；女方退场后的下一批次起只能出现 `7×3` / `8×3`。无 `BattleRule` 的关卡行为必须完全不变。
3. **男方常态的易伤必须落在角色身上**：符能投掷（`1;6|3;2;1;6`）命中后，被命中的角色身上出现 **6 层易伤**（`SelectedTarget` = 本意图最近命中的目标），怪物自身 0 层（与 `BATTLEFIELD_MONSTER_STATE_TARGET_PASS` 同口径）。
4. **伴侣共鸣加的是怪物不是玩家**（P2-25 落地后才能测）：出手后**女方与男方**各得 1 层加攻，**三名角色 0 层**。⚠️ 当前实现会把 `AddState` 施加到玩家身上（见[核心区法师怪设计 §8.2](../../../怪物设计/核心区法师怪设计.md)）—— 这条断言落地前**必然失败**，是 P2-25 的验收点。
5. **抽能护幕只覆盖半径 3 内的友方、虚弱可以落到任意角色**：出手后**男方**（距离 2）与**女方自己**各得 **12 点护盾**，并给**随机一名角色 5 层虚弱**（状态段写 `0` = `Auto`，纯护盾意图**不能**用 `2`，见[怪物配置](../../../../功能说明文档/数据系统/数据配置/怪物.md)）；本关没有第三方友方 —— 若出现"给玩家上盾"或"罩不到男方"，就是目标 / 半径口径取错。
6. **投掷与直线的几何差异**：男方投掷（`ThrowSingle`）在柱后仍能命中（不吃截断），近战突进必须相邻/同轴；两者用同一张图实测。
7. **场上只有 2 只敌人**：F1-008 编组任何时刻都只应有 3123 / 3124 两个实例（若配表后仍看到学徒 / 装置 / 黏液 / 石卫 / 小史莱姆，说明 CSV 没按 v3 重写）。
8. 不出现出生在障碍、坑洞、玩家出生格或封闭区域的情况（`BATTLEFIELD_LEVEL_CONFIG_PASS`）。
