# F1-005 符文隘口（中等 · 地形）

> 首版数值草案；本关是全部第一层普通敌袭里**唯一使用专属地图**的关卡（`M-F1-002`）。

## 一、关卡思路

地形关。战场中央横着一道符文石壁（5 格永久障碍 + **视线阻断**），只在 `(-2,-1)`、`(-2,0)` 留了一条**2 格宽的缺口**，缺口西侧紧贴一个坑洞；玩家出生区在石壁东侧，敌人全部部署在石壁西侧。

由此产生本关独有的取舍：

- 远程怪（哨站弩手、符文引导学徒）的**直线射击穿不过石壁** → 贴着石壁可以规避，但也打不到它们；
- 想输出就必须**穿过缺口**或**绕过石壁南北两端**；
- 缺口只有 2 格宽、旁边是坑洞 → 站位被压缩，穿缺口会同时暴露在两只弩手的直线里；
- 绕两端是安全的远路（多花移动与回合，时间点与承伤随之上升）。

核心决策：**走缺口争取输出窗口，还是绕两端稳扎稳打**。这是与 `F1-003 城外哨站`（同样远近混编、但无地形）最本质的区别。

## 二、关卡类型与失败后果

歼灭类（[六边形战场玩法 §7.0](../../../系统规则/战斗系统/六边形战场玩法.md)）：击败全部必杀敌人即胜利；玩家方全灭则本局结束。本关不含保护目标。

| 指标 | 计算 | 结果 |

| 总 HP | 16 × 2 + 18 + 24 + 18 × 3 + 9 | 137 |

| 累计净伤害（玩家防御估 9/轮）| (17.5 − 9) × 3.8 | ≈ 32 |

与档位目标对照：总 HP 137（目标 130）、每轮伤害 17.5（目标 18）、护盾 4（目标 3）、清场 3.8 轮（目标 3.6）——四项都在目标附近；**状态/强化压力 5.5 低于目标 9**，因为本关的额外难度来自地形走位而非状态叠加。

## 六、配表前验收

1. **连通性**：出生区到 8 只怪物都必须存在可通行路径（缺口 1 条 + 南北两端 2 条）；建议烟测跑一次确认寻路不会卡死。
2. **视线**：弩手与学徒的直线射击在石壁处被挡下，不得出现"隔墙射击"。
3. 石壁与坑洞都是**永久地形**，本关 `RandomObstacleCount` / `RandomItemCount` 必须为 0，不得在其上生成物件。
4. 坑洞与石壁组合后仍需保证玩家有过缺口后的落脚格（当前为 `(-2,-1)` 两侧的 `(-3,0)`、`(-1,-1)` 方向）。
5. 实测"走缺口 vs 绕两端"两条路线的回合差应落在 2–4 回合内，否则地形收益过强或过弱。
