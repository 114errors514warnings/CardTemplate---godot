# F1-006 劫匪团伙（中等 · 抢劫）

> 首版数值草案；**窃取金币已接入（2026-09-22，按怪物实例记账、被击杀实例结算返还）；逃跑意图已接入（2026-09-23）**；**奖励折损尚未实现**（口径已于 2026-09-27 定稿为「综合价值点数」，算例见 §4.1，实现清单见 §六）。

## 一、关卡思路

劫匪不是来杀人的，是来抢钱的。近战劫匪在造成伤害后**窃取玩家金币**，并在**第 6 回合结束时带着赃款逃跑**。于是这一关的压力不是"会不会掉血"，而是"金币会不会被抢走"：

- 想保住钱 → 必须在时限内清完近战劫匪；
- 想减少承伤 → 要先清后排远程劫匪；
- 但时间只够做一件事，所以这一关的核心决策是**"先清远程还是先截住偷钱的"**。

远程劫匪在后排用直线射击逼迫玩家分兵，近战劫匪则贴着玩家边打边偷，形成"两个都要处理"的困境。

## 二、关卡类型与失败后果

歼灭类：击败全部必杀敌人即胜利；玩家方全灭则本局结束。

**已定（2026-09-27）**：劫匪逃跑后仍是**通关**（离场满足通关条件，见 [六边形战场玩法 §7.1 / §7.4](../../../系统规则/战斗系统/六边形战场玩法.md)），但逃跑者**不计为击败**，按"应击败 / 实际击败"的综合价值点数比例折损卡牌奖励。不再按"未通关"处理。

### 意图选择规则（按 2026-09-23 规格）

| 规则 | 内容 |
|---|---|
| **常态** | 第 1–2 个敌方回合只用**低攻**（意图 0）|
| **高攻门槛** | 第 **3** 个敌方回合：若不是逃跑，**必定**使用**高攻**（意图 1）|
| **第 4 回合起** | 非逃跑的回合，低攻 / 高攻**等概率** |
| **逃跑触发** | 每只**近战**劫匪在**成功攻击命中玩家 2 次**后（**被格挡也算**），此后**每个回合 50%** 概率把意图切成逃跑 |
| **逃跑锁定** | 一旦进入逃跑，该单位后续每回合都只用逃跑意图 |
| **逃跑传染** | 任一场上敌人进入逃跑 → **下一回合全体敌人**的意图都变逃跑 |
| **窃取** | **所有攻击命中都触发窃取**（按该怪物自身的「窃取」层数扣金币），与意图无关 |

- 逃跑行为本身见[六边形战场玩法 §7.6](../../../系统规则/战斗系统/六边形战场玩法.md)：不攻击，向最近边界移动，移动结算后位于边界格即离场；离场按 §7.4 折损奖励。
- 数值取"近战 低攻 4 / 高攻 6、远程 低攻 3 / 高攻 4"的原因：所有攻击都窃取后，总压力 = 掉血 + 金币损失，且逃跑会提前结束战斗，因此把血的压力控制在加权约 19.4/轮（2 近战 + 3 远程）——按 3.28 轮满打会超中等档 18 的目标，但**逃跑提前结束战斗**会把它压回 18 附近，这是本关"时间换压力"的设计前提。

- 近战劫匪移动 2 格，负责贴近并持续偷取；远程劫匪移动 2 格、距离 4，负责压制走位。
- 逃跑行为：劫匪切换为**逃跑意图**后不再攻击，改为向**离自身最近的地图边界**移动；移动结算后若位于边界格即**逃跑成功并离场**，带走已窃取的金币。逃跑成功**不计为击败**，按 `六边形战场玩法 §7.4` 折损通关奖励（卡牌奖励减少）。

## 四、数值计算

| 指标 | 计算 | 结果 |
|---|---|---:|
| 总 HP | 35 × 2 + 16 × 3 | 118 |
| **综合价值点数** | 38.33 × 2 + 18.33 × 3（口径见[单位数值平衡标准 §2.4](../../../../玩法说明文档/系统规则/数值平衡/单位数值平衡标准.md)）| **131.67** |
| 每轮直接伤害（第 1–2 回合，低攻）| 2 × 4 + 3 × 3 | 17 |
| 每轮直接伤害（第 3 回合，高攻）| 2 × 6 + 3 × 4 | **24**（爆发点）|
| 每轮直接伤害（第 4 回合起）| (17 + 24) ÷ 2 | 20.5 |
| 加权每轮伤害（按 3.28 轮）| (17 × 2 + 24 + 20.5 × 0.28) ÷ 3.28 | ≈ **19.4** |
| 纯攻清场轮数 | 118 ÷ 36 | 3.28 |
| 累计净伤害（玩家防御估 9/轮）| (19.4 − 9) × 3.28 | ≈ **34** ✅ 落在中等档 36 以内 |
| 逃跑时点 | 近战命中 2 次后每回合 50%；任一人逃跑 → 下回合全体逃跑 | 通常第 3–4 回合开始逃、**1 回合内离场** |
| 期望窃取命中次数 | 2 只近战 × 每只约 2–3 次攻击（近战 35 HP，玩家每轮输出 36、约 2 轮清完）| ≈ **4–6 次** |
| 期望被窃金额（层数 = 1）| 每次攻击按层数窃取 1 金，扣到总金币归零为止 | ≈ **4–6 金**（该场金币掉落 50，约 8–12%）|

与档位目标对照：总 HP 118（目标 130，偏低）、加权每轮伤害 19.4（目标 18，偏高——由逃跑提前结束战斗补偿）、护盾 3（目标 3 ✅）、清场 3.28 轮（目标 3.6 ✅）。**状态/强化压力低于目标 9**，因为本关的额外压力来自"金币损失 + 时限 + 卡牌折损"，而非状态。

### 4.1 折损档位算例（综合价值点数 = 面板 HP + 意图加权价值）

单怪综合价值：近战劫匪 = 35 + (4 + 6 + 0) ÷ 3 = **38.33**；远程劫匪 = 16 + (3 + 4 + 0) ÷ 3 = **18.33**；本关总综合价值 = **131.67**。

| 击败组合（近战 / 远程）| 实际击败价值 | 比例 | 卡牌档位 |
|---|---:|---:|---|
| 2 / 3（全歼）| 131.67 | 100% | 全额 3 张 |
| 2 / 2 | 113.33 | 86.1% | 全额 3 张 |
| 2 / 1 | 95.00 | 72.2% | 全额 3 张 |
| **1 / 3（逃 1 只近战）** | **93.33** | **70.9%** | **全额（贴阈值）** |
| 2 / 0 | 76.67 | 58.2% | **−1 张** |
| 1 / 2 | 75.00 | 57.0% | **−1 张** |
| 1 / 1 | 56.67 | 43.0% | **−2 张** |
| 0 / 3 | 55.00 | 41.8% | **−2 张** |
| 0 / 0（全体离场）| 0 | 0% | **−2 张**（最多减 2，保留 1 张）|

- **"逃 1 只近战"= 70.9%，只比 70% 阈值高 0.9 个百分点**，阈值或 K 系数一改就要重算本表。
- 因 §三 的"逃跑传染"，实战结局通常只有"抓得够快（全额）"与"3–5 只一起逃（−2 张）"两种，中间档（57–58%）只出现在"恰好清掉 1 近战 + 2 远程"之类少数组合。
- 与只看面板 HP 的旧口径对照：118 中击败 83 = 70.3%——两套口径在**本关档位结论完全一致**；差异出现在低威胁怪逃跑的场景（例：`3007 × 3 + 3116 × 3` 逃 2 只远程劫匪 → HP 口径 68.6% 判 −1 张，综合口径 73.0% 判全额），见[单位数值平衡标准 §2.4](../../../../玩法说明文档/系统规则/数值平衡/单位数值平衡标准.md)。

## 五、地图与玩家决策

- 沿用 M-F1-001（含 2 处视线遮挡障碍与 1 个坑洞）：远程劫匪的直线射击会被障碍挡下，玩家可利用障碍规避。
- 近战劫匪分居两翼与后方（`-4,0`、`-2,-1`、`1,-4`、`-1,-3`），远程劫匪在后排（`3,-1`、`2,-3`、`4,-2`）。
- 决策：集中火力截住近战劫匪（保钱）／先清远程（减伤）／接受损失直接推图。

### 6.3 已定参数

- **窃取默认层数 = 1**（层数即该怪物每次攻击窃取的金币数；推算见 §四：期望被窃 4–6 金 ≈ 该场金币掉落 50 的 8–12%）。**不会衰减**，除特殊状态变更外层数不变。
- **攻击数值**：近战 低攻 **4** / 高攻 **6**；远程 低攻 **3** / 高攻 **4**（近战已由 4 只减为 2 只并提高数值）。对应 `Monster.csv` 效果：近战 低攻 `1;-1`、高攻 `1;1`；远程 低攻 `1`、高攻 `1;1`。
- **意图移动预算**（`EnemyIntent.csv` 第 6 列 `MoveBudget`）：劫匪的**两种攻击意图统一为 2 格**（近战、远程皆是；远程高攻位原为"距离 1 + 移动 0"的护盾位残留，已改为与低攻一致的 `RangedLine / 距离 4 / 移动 2`，否则高攻永远索敌失败）；**逃跑意图 3 格**（见下条）。
- **逃跑移动**：**3 格/回合**（不留反应窗口；意图一旦显示为逃跑，玩家应当立即击杀——参考《杀戮尖塔》的逃跑意图，当回合就能生效）。
- **逃跑行为**：不攻击，向**最近的地图边界**移动（走满 3 格）；移动结算后位于边界格即离场。M-F1-001 半径 6、怪物起始半径 3–5 → **通常 1 回合即逃掉**。
- **边界定义**：默认取地图最外圈格点；若采用含出口锚点的地图需另行定义。
- **窃取目标**：**直接以总金币（`RunSaveData.Gold`）为目标**，不区分角色；**只有当总金币归零后，被窃金额才不再增长**（金币为 0 时不再加账；不为 0 时按每次攻击的层数持续扣减；**余额不足时扣到归零**，可部分扣除 —— 2026-09-26 已实现，见施工文档 §30.1）。

### 6.4 当前表现（已全部落地）

**已落地**：**窃取**（2026-09-22）—— 近战劫匪命中玩家即按其「窃取」层数扣金币、**按实例记账**，余额不足时**扣到归零**；被击杀的实例在结算时原额返还，**逃跑成功的不返还**。**逃跑**（2026-09-23）—— 逃跑意图不攻击、按 3 格/回合朝最近边界移动，抵达边界即离场（**有时间压力**，不能无限拖）。节奏：第 1–2 回合低攻 → **第 3 回合高攻爆发** → 第 4 起低/高等概率；近战命中玩家 2 次后每回合 50% 进入逃跑，任一人逃跑则下一批次起**全体逃跑**（M-F1-001 半径 6、怪物起始半径 3–5、逃跑 3 格/回合 → **通常 1 回合即逃掉**，想追回被窃金币就得优先点掉已进入逃跑的那只）。

> **已实现（2026-09-28，见 [9 月施工文档 §33](../../../../施工文档/2026/2026.09/9月施工文档.md)）**：结算侧**奖励折损**已落地——意图价值表 `DataBase/Balance/MonsterValue.csv` + `MonsterValuePoints`（综合价值点数 / 击败比例 / 档位），比例与档位落档 `SettlementLossTier / SettlementValueRatio`，结算面板显示折损行并据此出 3 / 2 / 1 份卡牌奖励。口径已于 2026-09-27 定稿为「综合价值点数」（= 面板 HP + 意图加权价值，见 §4.1 与[单位数值平衡标准 §2.4](../../../../玩法说明文档/系统规则/数值平衡/单位数值平衡标准.md)），实现清单见[代码需求清单](../../../../施工文档/2026/2026.09/玩法/代码需求清单.md) **P2-10.3** 与[施工文档 §31](../../../../施工文档/2026/2026.09/9月施工文档.md)。
