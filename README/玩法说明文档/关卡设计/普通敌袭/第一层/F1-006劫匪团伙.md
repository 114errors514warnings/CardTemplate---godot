# F1-006 劫匪团伙（中等 · 抢劫）

> 首版数值草案；**窃取金币已接入（2026-09-22，按怪物实例记账、被击杀实例结算返还）；逃跑机制尚未接入**，见 §六。

## 一、关卡思路

劫匪不是来杀人的，是来抢钱的。近战劫匪在造成伤害后**窃取玩家金币**，并在**第 6 回合结束时带着赃款逃跑**。于是这一关的压力不是"会不会掉血"，而是"金币会不会被抢走"：

- 想保住钱 → 必须在时限内清完近战劫匪；
- 想减少承伤 → 要先清后排远程劫匪；
- 但时间只够做一件事，所以这一关的核心决策是**"先清远程还是先截住偷钱的"**。

远程劫匪在后排用直线射击逼迫玩家分兵，近战劫匪则贴着玩家边打边偷，形成"两个都要处理"的困境。

## 二、关卡类型与失败后果

歼灭类：击败全部必杀敌人即胜利；玩家方全灭则本局结束。

⚠️ 待定项：劫匪逃跑后，本关按"未击败"计入奖励折损（[六边形战场玩法 §7.4](../../../系统规则/战斗系统/六边形战场玩法.md)）还是判为通关，需与逃跑机制一并确定。

## 三、怪物职责

| 规划怪物 | 数量 | 属性 | 意图 | 单次价值 |
|---|---:|---|---|---:|

### 意图选择规则（按 2026-09-23 规格）

| 规则 | 内容 |
|---|---|
| **常态** | 第 1–2 个敌方回合只用**低攻**（意图 0）|
| **高攻门槛** | 第 **3** 个敌方回合：若不是逃跑，**必定**使用**高攻**（意图 1）|
| **第 4 回合起** | 非逃跑的回合，低攻 / 高攻**等概率** |
| **逃跑触发** | 每只**近战**劫匪在**成功攻击命中玩家 2 次**后（**被格挡也算**），此后**每个回合 50%** 概率把意图切成逃跑 |
| **逃跑锁定** | 一旦进入逃跑，该单位后续每回合都只用逃跑意图 |
| **逃跑传染** | 任一场上敌人进入逃跑 → **下一回合全体敌人**的意图都变逃跑 |
| **窃取** | **所有攻击命中都触发窃取**（按该怪物自身的「窃取」层数扣金币），与意图无关 |

- 逃跑行为本身见[六边形战场玩法 §7.6](../../../系统规则/战斗系统/六边形战场玩法.md)：不攻击，向最近边界移动，移动结算后位于边界格即离场；离场按 §7.4 折损奖励。
- 数值取"低攻 2 / 高攻 4"的原因：所有攻击都窃取后，总压力 = 掉血 + 金币损失，且逃跑会提前结束战斗，因此把血的压力从原来的 3.5/轮降到均值约 3/轮（4 近战 + 3 远程 ≈ 19/轮，贴近中等档 18 的目标）。

- 近战劫匪移动 2 格，负责贴近并持续偷取；远程劫匪移动 2 格、距离 4，负责压制走位。
- 逃跑行为：劫匪切换为**逃跑意图**后不再攻击，改为向**离自身最近的地图边界**移动；移动结算后若位于边界格即**逃跑成功并离场**，带走已窃取的金币。逃跑成功**不计为击败**，按 `六边形战场玩法 §7.4` 折损通关奖励（卡牌奖励减少）。

## 四、数值计算

| 指标 | 计算 | 结果 |
|---|---|---:|
| 总 HP | 35 × 2 + 16 × 3 | 118 |
| 每轮直接伤害（第 1–2 回合，低攻）| 2 × 4 + 3 × 3 | 17 |
| 每轮直接伤害（第 3 回合，高攻）| 2 × 6 + 3 × 4 | **24**（爆发点）|
| 每轮直接伤害（第 4 回合起）| (17 + 24) ÷ 2 | 20.5 |
| 加权每轮伤害（按 3.28 轮）| (17 × 2 + 24 + 20.5 × 0.28) ÷ 3.28 | ≈ **19.4** |
| 纯攻清场轮数 | 118 ÷ 36 | 3.28 |
| 累计净伤害（玩家防御估 9/轮）| (19.4 − 9) × 3.28 | ≈ **34** ✅ 落在中等档 36 以内 |
| 逃跑时点 | 近战命中 2 次后每回合 50%；任一人逃跑 → 下回合全体逃跑 | 通常第 3–4 回合开始逃、**1 回合内离场** |
| 期望窃取命中次数 | 4 只近战 × 每只 1–2 次攻击（其 HP 20，玩家每轮输出 36）| ≈ **4–8 次** |
| 期望被窃金额（层数 = 1）| 每次攻击按层数窃取 1 金，扣到总金币归零为止 | ≈ **4–8 金**（该场金币掉落 35–50，约 9–19%）|

与档位目标对照：总 HP 128（目标 130 ✅）、每轮伤害 18.5（目标 18 ✅）、护盾 3（目标 3 ✅）、清场 3.6 轮（目标 3.6 ✅）。**状态/强化压力低于目标 9**，因为本关的额外压力来自"金币损失 + 时限"，而非状态。

## 五、地图与玩家决策

- 沿用 M-F1-001（含 2 处视线遮挡障碍与 1 个坑洞）：远程劫匪的直线射击会被障碍挡下，玩家可利用障碍规避。
- 近战劫匪分居两翼与后方（`-4,0`、`-2,-1`、`1,-4`、`-1,-3`），远程劫匪在后排（`3,-1`、`2,-3`、`4,-2`）。
- 决策：集中火力截住近战劫匪（保钱）／先清远程（减伤）／接受损失直接推图。

### 6.2 待代码实现

1. ~~**金币转移**~~：**已接入（2026-09-22）** —— 怪物每次攻击命中玩家时按其「窃取」层数从局内金币里扣，并**按怪物实例**记在该实例名下（`StolenGoldEntry.InstanceId` = 关卡 CSV 的实例 ID，如 `F1-006-M01`）；金币不足则一分不扣。见[状态系统 §2.4](../../../../功能说明文档/战斗系统/状态系统.md)。
2. ~~**结算回收**~~：**已接入（简化版，2026-09-22）** —— 胜利结算时，**只有被击杀的那个实例**名下金币原额返还（结算面板一行"追回被窃金币 +N"，直接入账），存活/离场的实例不返还并清账。设计稿里的"与常规金币奖励分开的『被窃取』tab"仍属后续需求（[代码需求清单](../../../../施工文档/2026/2026.09/玩法/代码需求清单.md) P2-10.1）。
3. **逃跑意图 `Flee`**：**未实现**。规则见[六边形战场玩法 §7.6](../../../系统规则/战斗系统/六边形战场玩法.md)（不攻击、向最近边界移动、抵达边界即离场；离场按 §7.4 折损奖励）。落地前有 **7 项阻碍**：
   1. **意图选择规则**：当前是"所有非空意图**均匀随机**"（`BattlefieldSession.PrepareEnemyIntentions` / `MonsterIntentionService.SelectIntentionForMonster`），不支持门槛 / 概率 / 必定 / 锁定；
   2. **无战斗回合计数器**：第 3 个敌方回合必定高攻无法判定；
   3. **`Monster.csv` 无法表达"无效果意图"**：解析要求每段非空、首数为 `EffectType`（1/2/3）（建议新增 `4=None`）；
   4. **`EnemyIntent.csv` 无 `Flee` 行为**：`AttackMode` 只有攻击方式枚举；
   5. **缺命中计数**：逃跑触发条件"成功攻击命中玩家 2 次（含被格挡）"需要实例级计数；
   6. **缺逃跑传染的全局状态**：任一单位逃跑 → 下一回合全体逃跑；
   7. **离场不能用 `Defeated` 表示**：否则 `RunBattleScene.RefundStolenGold` 会误判为"被击杀"而**错误返还被窃金币** → 需独立 `Escaped` 并在结算排除。
4. **回合门槛**：**未实现**（依赖上述第 1、2 项）。

细则与验收标准见[代码需求清单](../../../../施工文档/2026/2026.09/玩法/代码需求清单.md) **P2-10**。

### 6.3 已定参数

- **窃取默认层数 = 1**（层数即该怪物每次攻击窃取的金币数；推算见 §四：期望被窃 4–8 金 ≈ 该场金币掉落的 9–19%）。**不会衰减**，除特殊状态变更外层数不变。
- **攻击数值**：低攻 **3** / 高攻 **4**（近战与远程同档）。对应 `Monster.csv` 效果：近战 低攻 `1;-1`、高攻 `1`；远程 低攻 `1`、高攻 `1;1`。
- **逃跑移动**：**3 格/回合**（不留反应窗口；意图一旦显示为逃跑，玩家应当立即击杀——参考《杀戮尖塔》的逃跑意图，当回合就能生效）。
- **逃跑行为**：不攻击，向**最近的地图边界**移动（走满 3 格）；移动结算后位于边界格即离场。M-F1-001 半径 6、怪物起始半径 3–5 → **通常 1 回合即逃掉**。
- **边界定义**：默认取地图最外圈格点；若采用含出口锚点的地图需另行定义。
- **窃取目标**：**直接以总金币（`RunSaveData.Gold`）为目标**，不区分角色；**只有当总金币归零后，被窃金额才不再增长**（金币为 0 时不再加账；不为 0 时按每次攻击的层数持续扣减）。

### 6.4 在实现前的实际表现

**已更新（2026-09-22）**：本关现在**会偷钱** —— 近战劫匪命中玩家即按其「窃取」层数扣金币并记在该**实例**名下，被击杀的实例在结算时原额返还（见 §6.2）。**逃跑仍未实现**，所以本关当前没有时间压力，可以慢慢清场。

> 早期（窃取接入前）的表现是"普通近战 + 远程混编：不偷钱、不逃跑"，仅把「窃取」状态挂在被命中的角色身上；该描述已作废。
