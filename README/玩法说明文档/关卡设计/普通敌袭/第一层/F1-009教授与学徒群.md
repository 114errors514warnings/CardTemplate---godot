## 一、关卡思路

这是第一层**结构最规整**的高等档关卡：**两位教授**在讲台上（一位主讲、一位督学，**都叫「教授法师」**），**四名学徒分成两门课**坐在两排座位上（**都叫「学徒法师」**），门口由符文石卫把守。它把「**支援链**」这条轴推到极致：

- **两位教授，两条链（第一版的核心改动）**：
  - **主讲（3125 教授法师，34 HP，移动 0）**：每轮 50% 对**全体角色**施加 **3 层易伤**、50% 给**半径 4 内全部友方各 4 点护盾** —— 半径 4 足以罩住场上的 6 名友方（督学 + 4 名学徒 + 石卫）。不清掉她，玩家的输出永远追不上刷新的护盾。
  - **督学（3127 教授法师，34 HP，移动 0，新模板）**：每轮 50% 打**「3 伤 + 2 层虚弱」**、50% 打**6 伤（不挂状态）**。她不放大伤害，而是**压低你的输出**、把你从掩体后面赶出来。
  - 两人分工的原因见[核心区法师怪设计 §3.2](../../../怪物设计/核心区法师怪设计.md)：两只同样的教授只会把护盾与易伤翻倍（更难打但不改决策），分工之后才出现「先斩主讲还是先斩督学」。
- **学徒分成两门课（第一版的第二处改动）+ 第二版的"同名不同号"**：**3128（蚀刻课，易伤）** 与 **3129（束缚课，虚弱）** 各 2 名；两个型号**名字完全一样（都叫「学徒法师」）**，只有**编号与外观**不同（赤红蚀刻纹 vs 青灰锁链纹，见[核心区法师怪设计 §1.1](../../../怪物设计/核心区法师怪设计.md)）。它们的意图都是「**低伤 + 挂 3 层状态**」或「**6 伤、不挂状态**」—— **两条都造成伤害**，所以玩家不能靠"这只学徒这轮只挂状态"来省伤害预算；判断该先打谁要靠**看外观 + 看自己身上的状态**（身上易伤越高 → 先清蚀刻；输出被虚弱压住 → 先拆束缚）。
- **守门单位换成符文石卫**（24 HP / 4 防）：卡在离玩家出生区最近的通路上（`-2,-1`），想摸到后排的两位教授就必须先处理它或绕开它。
- **后排弱化**：失控哨戒装置（12 HP、移动 0）持续叠 **3 层虚弱**，位置在玩家出生区的另一侧。

核心决策：**能不能绕过石卫直接斩首教授**（两位教授都是 34 HP，但被 4 名学徒与石卫挡在最后排）、**先斩主讲还是先斩督学**（拆护罩 / 换回自己的输出）、**先清哪一种学徒**（蚀刻叠易伤 vs 束缚压输出 —— 这一条现在要靠外观与状态判断，不再有名字提示）。

## 二、关卡类型与失败后果

歼灭类（[六边形战场玩法 §7.0](../../../系统规则/战斗系统/六边形战场玩法.md)）：击败全部必杀敌人即胜利；玩家方全灭则本局结束。本关不含保护目标、无逃跑单位 → 全歼即全额奖励（无折损）。

## 六、玩家决策

1. **先斩主讲还是先斩督学**：主讲 34 HP 在最后排 `(-5,0)`，护罩矩阵一断，全队每轮少 4 点护盾；督学同样 34 HP，但她每轮的虚弱在**压制你的输出**。若能两回合内把射程/位移铺到讲台（法师与弓手用远程直线越过学徒），收益最大。
2. **先清哪门课**：**蚀刻学徒**（易伤）让全队挨打更疼、**束缚学徒**（虚弱）让全队打人更软。身上易伤叠到 3 层以上就先清蚀刻；发现自己的爆发轮被虚弱吃掉就先拆束缚。
3. **装置是性价比最高的一击**：12 HP、0 伤害、每轮 3 层虚弱；一张远程牌就能拆掉它，之后整轮输出不再打七五折。
4. **易伤要吃在护盾上**：主讲与两种学徒每轮合计 7.5 层名义状态，意味着"哪些角色被打"几乎决定这轮掉多少血；开局把护盾铺在会被直线锁定的角色身上，比事后治疗划算。
5. **守门石卫别硬吃**：24 HP / 4 防挡在通路上；用移动绕柱或先集火（它只有 3 攻，威胁低）都比"顶着它摸讲台"便宜。
6. **别站在学徒的直线上**：蚀刻咒 / 束缚咒 / 学徒箭都是距离 4 的远程直线，符文柱可以白拿一次截断。

## 七、配表前验收

> 前提：主讲「导师威压（全体角色）」要等 **P2-25**；学徒的两条意图**不需要**新代码（`1;<修正>|3;2;<状态>;<层数>` 链路已被 3119 / 3124 验证）。

1. 三人 4 能量、无装备队伍平均 **4–5 回合**完成战斗（纯攻 4.4 轮 = 上限口径 / 期望口径 5.9 轮）；若 3 回合内清完，说明易伤 / 虚弱没生效，先查状态链路。
2. **学徒的状态必须落在角色身上**：蚀刻咒 / 束缚咒出手后，被命中的角色身上应出现 3 层对应状态（与 `BATTLEFIELD_MONSTER_STATE_TARGET_PASS` 同口径：状态落在**角色**身上、怪物自身 0 层）。
3. **护罩矩阵要罩住全部 6 名友方**：出手后督学、4 名学徒与石卫身上都应有 4 点护盾（装置在另一侧，不应吃到）；若只有部分吃到，先查 `AllyRange / AreaRadius` 的半径口径。
4. **主讲「全体角色 3 层易伤」要打满 3 名角色**（P2-25 落地后才能测）：⚠️ 当前实现会只打到 1 名角色 —— 这条是 P2-25 的验收点，落地前**必然失败**（见[核心区法师怪设计 §8.2](../../../怪物设计/核心区法师怪设计.md)）。
5. **两位教授与装置的移动预算为 0**：三者都不得追击玩家（否则「讲台支援」与「后排弱化」的定位失效）。
6. **同名不同号必须看出来**（第二版新增验收点）：场上会有 **2 只「教授法师」**（主讲 / 督学）与 **4 只「学徒法师」**（蚀刻 / 束缚）—— 玩家只能靠**外观**分辨（深紫权杖 vs 黑金戒尺；赤红蚀刻纹 vs 青灰锁链纹）。若暂时没有外观差异，"先斩谁"会退化成盲选（见[核心区法师怪设计 §1.1](../../../怪物设计/核心区法师怪设计.md) 的外观列）。
7. 不出现出生在障碍、坑洞、玩家出生格或封闭区域的情况。

| 2 | 两种学徒的名字 | **都叫「学徒法师」**（用户第二版指令）| 型号靠**编号 + 外观**区分（3128 蚀刻 / 3129 束缚）|
