## 两阶段工作流（2026-10-01 规范）

| 阶段 | 触发条件 | 产出 | 禁止 |
|---|---|---|---|
| **① 构思 / 设计**（默认） | 用户说「设计 / 构思 / 出思路 / 加个典型」等 | 本目录下的**说明文档**（关卡思路、编组设想、档位四项指标估算、与[关卡档位表](../系统规则/数值平衡/关卡档位表.md)目标的偏离、待定项、待代码项）；数值可为草案并标注「需实配时校准」 | **不生成任何配置文件** |
| **② 配表 / 落地** | **用户明确要求**「配表 / 落地 / 写进配置」 | `DataBase/Level/Config/*.csv` + 按需的 `Monster.csv` / `EnemyIntent.csv` / `MonsterValue.csv` / `BattleMap/**` / `LevelPool.csv` / `LevelIndex.csv` | 不得擅自跨越（未获指令时只留在①） |
