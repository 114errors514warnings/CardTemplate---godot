# 关卡怪物设计

> 怪物名称与属性以 [怪物总表](怪物总表.md) 为准；关卡强度档位以 [关卡档位表](../系统规则/数值平衡/关卡档位表.md) 为准；行为价值以 [行为与属性价值估算](../系统规则/数值平衡/行为与属性价值估算.md) 为准。

## 一、进入关卡前仍需补齐的规则

| 缺口 | 需要定下的内容 | 对数值的影响 |
|---|---|---|
| 关卡档位 | 每层的低等、中等、高等、高危、精英和 Boss 的生命与每轮威胁目标 | 决定怪物是否能正常投放 |
| 遭遇编组 | 每类关卡的怪物数量、出生位置、波次和是否包含爪牙 | 单怪数值不能直接等于关卡难度 |
| 意图配置 | 每只怪物的攻击方式、距离、范围、移动预算、索敌和意图权重 | 决定数值能否实际打到角色 |
| 状态口径 | 易伤、虚弱、点燃、加攻等状态的层数、持续和触发时机 | 状态价值才能稳定计算 |
| 空间口径 | 射程、范围、位移、障碍和友伤的标准测试地图 | 空间收益不能凭印象定值 |
| 奖励与掉落 | 金币、材料、食物、卡牌和精英钥匙的掉落池与数量 | 风险才能与关卡收益对应 |
| 失败与撤离 | 怪物离场、波次失败、保护目标死亡和夜袭的结果 | 影响怪物是否需要计入通关价值 |
| 验收场景 | 三人队、单人队、满血与残血、无装备与有装备四类实测 | 防止只在一种队伍配置下平衡 |

> **爪牙的标记载体已就绪（2026-09-28）**：`Monster.csv` 新增 `IsMinion`（是否为爪牙）列，可逐怪标记（见[怪物配置](../../功能说明文档/数据系统/数据配置/怪物.md) / [9 月施工文档 §35](../../施工文档/2026/2026.09/9月施工文档.md)）；**遭遇编组本身（数量 / 出生位置 / 波次 / 是否含爪牙）仍待设计**——爪牙的运行侧还缺生成 / 波次与 HUD 表现（[代码需求清单 10.5](../../施工文档/2026/2026.09/玩法/代码需求清单.md)）。

## 二、首层普通敌袭口径

首层普通敌袭以三人队为基准：面板生命总值 60–70，每轮直接伤害威胁不超过 10。护盾、易伤和其他明确效果按[行为与属性价值估算](../系统规则/数值平衡/行为与属性价值估算.md)单独记录，不把实际命中人数乘入基础价值。

> ⚠️ **口径已更新（2026-10-01）**：上面这句「60–70」是首版草案口径，与现役关卡（F1-002 = 70、F1-003 = 74、F1-005 = 137、F1-007 = 256〔生存关〕）已经不符。
> **每层各档位的强度目标一律以 [关卡档位表](../系统规则/数值平衡/关卡档位表.md) 为准**（低等 90 / 中等 130 / 高等 168 / 高危 145 / 精英 210 / Boss 275），本节只保留下面的「意图内行为价值表」。

| 意图内行为 | 价值 |
|---|---:|
| 1 点伤害或护盾 | 1 |
| 1 层易伤或虚弱 | 2 |
| 1 层加攻 | 3 |

## 六、投放前验收

1. 每条意图都填写攻击方式、距离、范围、移动预算和索敌策略。
2. 每个编组核对总 HP、每轮直接伤害和单次意图价值。
3. 范围攻击必须以包含友伤的站位测试，不按理论最大命中人数加倍基础伤害。
4. 远程怪物必须在障碍、非共线和无合法射击位的场景中验证移动行为。
5. 怪物掉落需要至少指定金币、材料或食物中的一种来源；精英另指定钥匙或强化奖励。
