## 三、维护规则

- 新增或改名怪物：先改本表，再改 `Monster.csv`、`EnemyIntent.csv` 与关卡 CSV 的 Note。
- 本表不写关卡投放数值（总 HP、威胁目标见 [关卡档位表](../系统规则/数值平衡/关卡档位表.md)）。
