# 单位数值平衡标准

> 角色 / 怪物属性价值评定的前提与标准。卡牌侧见「卡牌数值平衡标准.md」（同目录）。

## 一、生命跨战斗继承机制（前提）

- 角色生命在一连串战斗（关卡流程）中继承
- **单场战斗损失的生命 = 永久损失**，跨场累积
- 只有通过**特殊休息节点**才能回复基于自身生命上限的一部分生命

## 二、单位属性价值口径（两种口径，不可混用）

| 口径 | 含义 | 计入方式 |
|------|------|----------|
| 价值点 | 处理该单位需投入的输出 | 怪物 = 面板 HP（全额）；护盾意图折算为额外拦截 |
| 威胁点 | 该单位整场对我方造成的等效伤害 | 每轮期望伤害 × 存活轮数 |

### 2.1 属性 → 点数

| 属性 | 点数 | 来源 / 理由 |
|------|------|-------------|
| 1 点生命 | 1 点 | 能承受 1 点伤害，与卡牌锚点「1 伤害 = 1 点」对齐；怪物全额、角色折扣见 §一 |
| 攻击 | 不计线性点 | 攻击只经「攻击牌 / 攻击意图」转化伤害 → 按回合产出流折算（§三 / §四）|
| 防御 | 不计线性点 | 防御只经「护盾段」转化拦截 → 按回合产出流折算（§三 / §四）|

### 2.2 回合产出公式

- 角色每轮伤害 = 攻击 × 每轮打出的攻击牌数（能量 3 → 至多 3 张 1 费攻击）
- 怪物每轮期望伤害 = 攻击 × 单意图攻击段数 × 攻击意图占比
- 怪物每轮期望护盾 = 防御 × 单意图护盾段数 × 防御意图占比
- 攻击意图占比 = 含攻击段的意图条数 ÷ 意图总条数；护盾意图占比同理

## 三、角色数值价值点（基准）

| 角色 | HP | 攻击 | 防御 | 每轮伤害（纯攻击牌）| 来源 |
|------|----|------|------|--------------------|------|
| 勇士 | 40 | 3 | 3 | 3 张 × 攻 3 = **9** | Character.csv：HP 40 / 攻 3 / 防 3 |
| 重剑手 | 30 | 3 | 3 | 3 张 × 攻 3 = **9** | Character.csv：HP 30 / 攻 3 / 防 3 |

- 3 人队每轮总输出 = **27**（9 × 3）
- 角色生命价值：掉血 = 永久损失（§一），单场不可全额计入 → 折扣系数见 §六待确认

## 五、初始关卡怪物价值目标（草案）

> 项目当前无正式关卡，`DataBase/Monster.csv` 的 7 只怪视为初期怪物池；「初始关卡一波」暂按 3 角色战斗评估。

**前提设定**：
- 我方 3 角色（勇士 + 重剑手 + 重剑手），无加成、纯攻击牌输出
- 队伍总 HP = 40 + 30 + 30 = **100**；掉血永久 → 整波可接受承伤 ≤ 总 HP 的 **1/3 ≈ 33**
- 我方每轮输出 27 → **3 轮总输出 81**

**推导**：
| 目标 | 约束 | 推导结果 |
|------|------|----------|
| 清场速度 | 3 轮清场，扣护盾拦截约 15% | 怪面板总 HP（价值点）≈ **60~70** |
| 承伤上限 | 3 轮怪总威胁 ≤ 30 | 每轮期望总威胁 ≤ **10** |

**结论：初始关卡一波怪的目标 = 面板总 HP 60~70（价值点），每轮期望总威胁 ≤ 10。**

**达标参考组合**：堕魔守卫 3003 + 诅咒弓手 3004 + 狂热祭司 3005
- 面板总 HP = 30 + 16 + 20 = **66**（价值点 66，在 60~70 内）✅
- 每轮期望威胁 = 4.5 + 1.5 + 2 = **8**（≤ 10）✅
