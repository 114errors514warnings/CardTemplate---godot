# 总体卡牌设计思路

> 摘录自 `README/系统规则/总体卡牌设计思路.md`（2026-08-29 迁移）

## 核心分级

1. 所有卡牌分为 **D、C、B、A、S** 5 级，通过升级可将低等卡转化为高等卡
2. **初始卡牌**由通用牌"攻击"、"防御"（都是 D 级） + 角色专有初始牌（C 级）构成
3. 除了角色的专有初始牌，所有 B 级及以下的牌均为通用牌
4. **B 级牌**在升级时能通过分支升级成不同的 A 级角色专属牌

## 等级表

| 等级 | 定位 | 来源 |
|------|------|------|
| D | 基础 | 通用牌（攻击、防御）|
| C | 角色专有初始 | 角色初始牌组 |
| B | 通用可升级 | 通用牌 |
| A | 角色专有 | B 级牌分支升级 |
| S | 顶级 | 角色专有最终形态 |

> 「来源」列表达的是**设计上的典型来源**，不是硬约束：A / S 级卡可以出现在通用表（商人第 5 包 = 3 张 A + 2 张 S 通用牌），角色专有表里也有 B 级牌（精灵「敏捷闪躲」、法师「法术护盾」）。归属看「卡牌归属与掉落」一节，不看等级。

## 卡牌归属与掉落（2026-10-03 用户口径）

- **归属只由卡牌所在表决定**：
  - `DataBase/Card/<角色名>Card.csv`（如 `重剑手Card.csv` / `精灵Card.csv` / `法师Card.csv`）= 该角色的**专有牌**；
  - `DataBase/Card/通用/通用Card.csv` = **通用牌**，不属于任何角色，所有角色都可用。
- **掉落规则**：战斗中掉落的牌**必须是该角色的专有牌，不包含通用牌** —— 候选池按「份 = 槽位」取该槽位角色的专有来源（`LoadingSystem.GetCharacterRewardCardIds` 过滤通用来源），战斗结算三选一与事件发卡两条路径同源。
- **例外开口**：用户口径里的「除非特殊装备效果」= `CardRewardOwnership.IncludeGenericSources`（默认 `false`）；该装备效果**尚未实现**，落地时按装备实例打开开关即可，其它调用面不必改。
- **等级条件（2026-10-04 用户口径，已实现）**：候选还要**只含该角色 B–S 级专属牌** —— 该角色的 **C 级初始牌**不算掉落（例：勇士的 `11001001` 破空斩 / `21001001` 战术抽牌 在 `CharacterDefaultDeck.csv` 里同时是初始牌）。实现 = 运行时卡表的 `CardTier` 列（[P1-6](../../../施工文档/2026/2026.09/玩法/代码需求清单.md) 的**最小版** = 施工清单 **T9**）+ `CardRewardOwnership` 一处过滤；精灵 / 法师 / 重剑手表等级已填满（零可见变化）。⚠️ **勇士（`1001`）没有设计等级数据源** → 该表缺列 = 不过滤 + 告警，C 级初始牌仍进候选（待设计侧补表 = **T12**）；落点见 [10 月施工文档 §26](../../../施工文档/2026/2026.10/10月施工文档.md) 与 [精灵法师卡牌接入待做](../../../施工文档/2026/2026.10/精灵法师卡牌接入待做.md)。
- **现状（2026-10-03）**：精灵 / 法师此前没有运行时卡表、其奖励池只有通用来源 → 本批新建两张专有表（各 1 行：敏捷闪躲 / 法术护盾），**同日晚些时候两张表各补齐到 4 行**（新版 3 张 B / A / S 已落表，`CharacterRewardPool.csv` 同时补上两名角色的专有来源 —— 此前两名角色掉落候选为空；见 [10 月施工文档 §23](../../../施工文档/2026/2026.10/10月施工文档.md)）；角色各 3 张**旧**设计牌的**落表**仍是待做（见[代码需求清单 P1-6](../../../施工文档/2026/2026.09/玩法/代码需求清单.md) 与[10 月施工文档 §20](../../../施工文档/2026/2026.10/10月施工文档.md)）。

## 与重剑手 CSV 对应

`DataBase/Card/重剑手Card.csv` 共 30+ 张卡：
- B 级（通用可升级）：预判、未雨绸缪、暂避锋芒、战术支援、攻守兼备、横扫、奋力一击、致残打击、迅捷打击
- A 级（角色专有）：强撑、死亡之舞、鼓气、勇气铠甲、反攻号角、燃血、蓄力、紧咬不放、持盾防守、到我身后、大地、统一战线
- S 级（顶级）：蓄势待发、绝力一击、阵地、城墙、旋风斩、盾牌冲撞、总攻、淬炼、矗立
