# 地图玩法

> 战斗之外的关卡流程玩法：地图选路 + 时间点 / 昼夜循环。地图几何示意见同目录「地图示意图.png」。

## 一、定位与总览

- 类杀戮尖塔的构筑式玩法：在地图上选择关卡或遇到其他类型的节点，通过完善自己的卡组来变强
- 目标：战胜三层地图的三个 Boss

## 二、地图结构

- 地图为一个大正六边形，由等比缩放的小型正六边形节点铺成
- 每个节点连接附近 3 个节点
- 连接线方向与两相邻节点中心的连线平行，长度与节点边长相同
- 大六边形每条边包含的节点数为奇数，以保证地图中心存在节点
- 几何细节以「地图示意图.png」为准

## 三、起点与终点

- 起点：地图最左侧节点，玩家从此开始游戏
- 推进：只能通过前往相邻节点进行探索，需要规划路线
- 终点：最右侧 Boss 节点，进入条件见 §四钥匙

## 四、节点类型

### 4.1 特殊节点（固定位置）

| 节点 | 固定位置 | 效果 |
|------|----------|------|
| 村庄 | 地图中心 | 完全回复生命值，并进行各类强化补给 |
| 精英怪 | 地图右上角 | 击败掉落 1 把钥匙 + 强化奖励 |
| 精英怪 | 地图右下角 | 同上 |
| 精英怪 | 中心和右侧节点的中点 | 同上 |
| Boss | 地图最右侧 | 持有 ≥2 把钥匙才能进入（钥匙可通过商人购买）|

> 钥匙数量（精英怪掉落 1 把 / 进入 Boss 需 ≥2 把）为草案值。

### 4.2 常规节点

| 类型 | 占比 | 说明 |
|------|------|------|
| 空白 | 10% | 比较少见 |
| 普通敌袭 | ~40% | 常规战斗，战胜后获得金币 |
| 高危敌袭 | ~12% | 难度高于普通敌袭，掉落更丰富的奖励，较稀有 |
| 普通事件 | | 不会进入战斗；选项以增益、减益或交易为主，也可能刷新成商人。所有普通事件中至少包含一个商人，最多两个 |
| 危险事件 | | **不一定进入战斗**：选项可以全部是纯减益（等价代价），也可以包含进入战斗的选项；会产生区别于普通敌袭的效果 |
| 商人 | | 使用战胜敌袭后获得的金币进行交易；地图上仅会刷新 1 个节点（不包含普通事件中出现的）|

> 各类型占比为草案值（空白 10% / 普通敌袭 ~40% / 高危敌袭 ~12%）；普通事件、危险事件占比暂未确定。

- **事件节点不可放弃**：玩家到达事件节点后必须选择一项，不提供「离开 / 放弃节点」选项。
- 由于不存在「什么都不做」的基准选项，同一事件内所有选项的净价值必须落在同一区间（等价代价、币种可不同）。
- 事件货币、价格表与选项配平规则见[事件系统](../事件系统/事件系统.md)。

## 五、时间点系统

时间点用于计量游戏进程。

### 5.1 时间点的获得

| 来源 | 规则 |
|------|------|
| 战斗 | 每经过 10 个战斗中的回合，获得 1 个时间点（草案值）|
| 移动 | 移动到相邻节点，额外增加时间点进程 3 回合 = **0.3 时间点**（草案值）|

- 时间点的**最小计量单位为 0.1**，对应战斗中的 **1 个回合**：1 时间点 = 10 回合。
- 时间点进程按 0.1 为步长累加，界面显示保留 1 位小数。

### 5.2 天

- **一天固定包含 4 个时间点**，不随游戏进程变化
- 时间点进程累计每满 4 点即进入新的一天，当天耗尽后进入休息
- 时间点进程**只增不减**：它是本局的运行时钟，任何玩法结果都不能让它回退（回退会改动跨天边界，并使休息回复公式失效）
- 唯一带"减少"意味的机制是**主动结束当天**：把当天尚未使用的时间点作废并按比例转化为休息收益（见[篝火休息与食物](../营地系统/篝火休息与食物.md)），这不是时钟回退

### 5.3 夜晚休息

日终或主动结束当天后进入篝火休息。生命回复、食物、篝火合成、守夜、夜袭和睡眠不佳见[篝火休息与食物](../营地系统/篝火休息与食物.md)。

### 5.4 每日 Debuff

- 每天结束都会获得 1 个 Debuff，不存在特例；Debuff 可叠加
- Debuff 在「位于不同格点」时收到，效果与所在格点类型绑定，作用于该类格点的遭遇
- 示例：位于普通敌袭格点收到的 Debuff = 普通敌袭敌人的血量增加（仅针对普通敌袭）
- 覆盖范围随时间推进扩大：
  - 前期：仅覆盖除村庄、精英怪、Boss 之外的格点（普通敌袭、高危敌袭、普通事件、危险事件等）
  - 进行到特定天数后：精英怪、Boss 也进入覆盖范围

## 六、数值说明

- 正文中的节点占比、钥匙数量、时间点换算（战斗 10 回合 = 1 时间点、移动 +3 回合进程 = 0.3 时间点、时间点最小单位 0.1、4 时间点 = 1 天）、夜晚回复公式、每日 Debuff 加成等数值均为玩法草案，后续可能调整，以实际实现为准
- 尚未明确的玩法内容（非数值）：普通事件 / 危险事件的占比、夜晚休息可消耗时间点进程进行的「其他操作」具体内容
