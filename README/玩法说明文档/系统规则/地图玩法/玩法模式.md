# 玩法模式与正式六边形战斗

## 纯净模式

- 主菜单“纯净模式”进入组队界面。
- 可选择重剑手、精灵、法师（1002/1003/1004），三个槽位均允许重复。
- 确认后进入既有地图、节点与遭遇流程。

## 剧情模式

- 主菜单“剧情模式”跳过组队，固定以重剑手、精灵、法师各一名创建新局。
- 进入地图后的节点、遭遇、结算、奖励与纯净模式一致；剧情事件内容在事件系统接入后覆盖于当前场景。

## 正式战斗

- 地图触发遭遇后进入 `RunBattleScene`，该场景承载新版 `HexBattleScene`，不再实例化旧版 `CardBattleScene`。
- 地形与物品布局使用 `FoundationMap.json` 的当前六边形基础地图；角色、手牌、生命和怪物编组由运行局存档及待处理遭遇注入。
- 装备状态属于角色槽位的局外存档。新局创建时写入职业初始武器；进入战斗时读取，胜利结算时回写。重开或失败不提交本场临时变更，因而可回到进战前状态。
