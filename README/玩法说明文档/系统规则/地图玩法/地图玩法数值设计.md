# 地图玩法数值设计

> 第一层通关流程、队伍成长曲线与敌方强度档位（草案）。玩法规则见「地图玩法.md」。
> 全部数值为草案，参数见 §八 可调清单，正式数值后续统一调整。

## 一、统一口径

- 价值单位：1 点 = 1 伤害 ≡ 1 护盾
- 我方每轮**能力点 C** = 3 人 × 3 张牌 × 3 点 = **27 起步**；输出与防守共用同一池
- 每轮分配：`防守 = min(C, 敌每轮威胁)`，`输出 = C − 防守`
- 战斗轮数 = 敌面板 HP ÷ 输出；敌方护盾意图并入威胁消耗
- 容错损耗 = `敌威胁 × 轮数 × 10%`（敌方攻击轮爆发穿透，草案常数）
- 成长：普通敌袭 / 普通事件每格 C+1；高危敌袭 +1.5；精英 +3；村庄强化 +2；商人无成长（资源性）
- 容错：队伍 HP = 100；**每 3 个时间点 = 1 夜，回 25 点**（草案，封顶 100）；村庄节点回满一次

## 二、地图几何与必经路线（k=7）

大六边形每条边 7 个节点 → 按半径 R=6、总 127 节点的解读（村庄与 Boss 中点精英必须落在节点上，故不用直径 7 的解读）。

| 固定点 | 位置 | 距村庄步数 |
|--------|------|-----------|
| 村庄 | 中心 | 0 |
| 起点 | 最左节点 | 6 |
| Boss | 最右节点 | 6 |
| 精英① | 村庄-Boss 连线中点 | 3 |
| 精英② | 右上角或右下角顶点 | 6 |

### 2.1 路段与非特殊格点

| 路段 | 步数 | 非特殊格点（步数-1）|
|------|------|--------------------|
| 起点 → 村庄 | 6 | 5 |
| 村庄 → 精英① | 3 | 2 |
| 精英① → 精英② | 4 | 3 |
| 精英② → Boss | 4 | 3 |
| 合计 | 17 | **13** |

起点不计入非特殊格点；全程访问 18 个节点（起点 + 13 非特殊 + 村庄 + 精英① + 精英② + Boss）。

## 三、13 个非特殊格点的期望构成

| 类型 | 占比 | 期望数量（13 格）| 收益 |
|------|------|------------------|------|
| 普通敌袭 | 40% | ≈ 5.2（取 5）| R |
| 普通事件 | 并入 | ≈ 4.9（取 5）| **R**（收益等同普通敌袭）|
| 危险事件 | 并入 | | **R**（收益等同普通敌袭）|
| 高危敌袭 | 12% | ≈ 1.6（取 1-2）| R_高（>R）|
| 空白 | 10% | ≈ 1.3 | 0 |
| 商人 | 固定 1 | 占用其中 1 格 | 资源交易 |

> 收益侧无需区分普通事件 / 危险事件的比例（收益均按普通敌袭 R 计）。

## 四、普通敌袭难度序列（跨层累计）

### 6.1 容错（HP）追踪

夜回发生在时间点 3 / 6 / 9 / 12 / 15；村庄节点（#6）回满一次。

| 关键点 | HP |
|--------|-----|
| #2 后 | 98 |
| #4 高危后 | 91 |
| #6 村庄 | 回满 100 |
| #9 精英①后 | 87 → 夜回 25 → 100 |
| #13 精英②后 | 92 → #15 夜回 → 100 |
| #17 Boss 后 | ≈ 86 |

结论：全程最低 HP ≈ 86，容错始终充裕。

## 七、第一层汇总

| 项目 | 结果 |
