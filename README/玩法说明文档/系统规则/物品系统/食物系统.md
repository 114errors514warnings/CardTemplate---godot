## 一、定位与来源

- 食物属于队伍战斗外背包，不占战斗内临时道具栏。
- 食物可由战斗掉落、事件奖励获得，或在休息时用篝火把低阶食物合成为高阶食物（§四）。
- 食物在**餐厅**（购买 / 出售 / 现做）与**营地**（篝火）提供饱食度与收益；两处口径见[餐厅交互案](../../../施工文档/2026/2026.10/交互/餐厅交互案.md)与[篝火休息与食物](../营地系统/篝火休息与食物.md)。
- 同一种食物以独立实例保存，各自记录稀有度、饱食度、有效期和附带效果。

## 二、有效期

- 食物以“天”为有效期。
- 每天休息结算后，背包内未使用食物的有效期减 1；到 0 时腐坏并移除。
- 过期食物不能放入篝火；放入篝火的食物在本次休息结束后全部消耗。

## 三、食物清单

| 稀有度 | 食物 | 饱食度 | 有效期 | 篝火效果 |
|---|---|---:|---:|---|
| 普通 | 粗麦饼 | 2 | 3 天 | 无 |
| 普通 | 香草炖菜 | 3 | 2 天 | 下一场战斗开始获得 2 点护盾 |
| 普通 | 烤蟾蜍 | 3 | 2 天 | 下一场战斗第一次受到伤害时，额外获得 1 点护盾 |
| 罕见 | 蜂蜜烤肉 | 4 | 3 天 | 下一场战斗攻击 +1 |
| 罕见 | 月光浓汤 | 4 | 2 天 | 下一场战斗开始清除 1 层普通弱化 |
| 罕见 | 毒蛇杂烩 | 4 | 1 天 | 下一场战斗攻击 +2，但开始时获得 1 层虚弱 |
| 稀有 | 龙血藤药膳 | 5 | 3 天 | 下一场战斗开始获得 5 点护盾并抽 1 张牌 |
| 稀有 | 凤凰羽羹 | 5 | 2 天 | 下一场战斗首次生命降至 0 时回复 20% 最大生命值；本场仅一次 |

## 四、篝火烹饪（食物升级）

- 每次休息最多合成 2 次食物；合成后可立刻放入本次篝火。
- **烹饪只消耗食物**（2026-10-02 起实配；2026-10-07 用户口径定案）—— 把低阶食物合成为高阶食物，不消耗额外时间点。
- 草稿里的食物不能当烹饪原料（防一物两吃，见文件头 ③）。

| 产物 | 配方（`FoodRecipe.csv` 中 `Enabled=TRUE` 的 5 条） |
|---|---|
| 蜂蜜烤肉（罕见） | 烤蟾蜍 ×2 |
| 月光浓汤（罕见） | 香草炖菜 ×2 |
| 毒蛇杂烩（罕见） | 烤蟾蜍 ×1 + 香草炖菜 ×1 |
| 龙血藤药膳（稀有） | 蜂蜜烤肉 ×1 + 月光浓汤 ×1 |
| 凤凰羽羹（稀有） | 毒蛇杂烩 ×1 + 月光浓汤 ×1 |

- 上表为**食物升级链**（普通 → 罕见 → 稀有）：输入与产物都在 `Food.csv` 里，产物效果见 §三。
- **7 条「材料 → 食物」行**（`RecipeId 1–7`，`Enabled=FALSE`）按 2026-10-07 口径**不属于烹饪**（烹饪只用食物）；去留见[材料分类与道具加工设计案 §四.2](../../../施工文档/2026/2026.10/材料分类与道具加工设计案.md)。
