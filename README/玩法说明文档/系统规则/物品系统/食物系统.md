# 食物系统

## 一、定位与来源

- 食物属于队伍战斗外背包，不占战斗内临时道具栏。
- 食物可由战斗掉落、事件奖励获得，或在休息时使用篝火合成。
- 同一种食物以独立实例保存，各自记录稀有度、饱食度、有效期和附带效果。

## 二、有效期

- 食物以“天”为有效期。
- 每天休息结算后，背包内未使用食物的有效期减 1；到 0 时腐坏并移除。
- 过期食物不能放入篝火；放入篝火的食物在本次休息结束后全部消耗。

## 三、食物清单

| 稀有度 | 食物 | 饱食度 | 有效期 | 篝火效果 |
|---|---|---:|---:|---|
| 普通 | 粗麦饼 | 2 | 3 天 | 无 |
| 普通 | 香草炖菜 | 3 | 2 天 | 下一场战斗开始获得 2 点护盾 |
| 普通 | 烤蟾蜍 | 3 | 2 天 | 下一场战斗第一次受到伤害时，额外获得 1 点护盾 |
| 罕见 | 蜂蜜烤肉 | 4 | 3 天 | 下一场战斗攻击 +1 |
| 罕见 | 月光浓汤 | 4 | 2 天 | 下一场战斗开始清除 1 层普通弱化 |
| 罕见 | 毒蛇杂烩 | 4 | 1 天 | 下一场战斗攻击 +2，但开始时获得 1 层虚弱 |
| 稀有 | 龙血藤药膳 | 5 | 3 天 | 下一场战斗开始获得 5 点护盾并抽 1 张牌 |
| 稀有 | 凤凰羽羹 | 5 | 2 天 | 下一场战斗首次生命降至 0 时回复 20% 最大生命值；本场仅一次 |

## 四、篝火合成

- 每次休息最多合成 2 次食物；合成后可立刻放入本次篝火。
- 合成只消耗材料，不消耗额外时间点。

| 食物 | 配方 |
|---|---|
| 香草炖菜 | 药草 ×2 + 苔藓 ×1 |
| 烤蟾蜍 | 蟾蜍 ×1 + 药草 ×1 |
| 蜂蜜烤肉 | 蟾蜍 ×1 + 鸟类羽毛 ×1 |
| 月光浓汤 | 月光草 ×1 + 药草 ×1 |
| 毒蛇杂烩 | 毒蛇 ×1 + 毒囊 ×1 |
| 龙血藤药膳 | 龙血藤 ×1 + 药草 ×2 |
| 凤凰羽羹 | 凤凰羽毛 ×1 + 月光草 ×1 |
