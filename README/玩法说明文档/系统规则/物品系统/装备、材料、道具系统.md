# 装备、材料、道具系统

> 战斗外的养成产出：战斗获得材料 → **合成**道具 / **锻造**装备 → 强化战斗表现；三类加工（**合成 / 锻造 / 烹饪**）的边界见 §〇。

## 〇、三类加工的边界（2026-10-07 用户口径，定案）

| 系统 | 输入 | 输出 | 产物性质 | 现状落点 |
|------|------|------|----------|----------|
| **合成** | 合成材料（`Material.Category = 合成材料`，101–110） | 道具（`Item.csv` 301–308） | **一次性**消耗品，使用后获得战斗内 / 持续时间的增益 | **未实现**：五设施里没有「合成台」、道具配方表未建 → 落点见 [材料分类与道具加工设计案 §四](../../../施工文档/2026/2026.10/材料分类与道具加工设计案.md) |
| **锻造** | 打造材料（`Category = 打造材料`，201–206） | 装备（武器 / 头盔 / 护甲 / 鞋 / 饰品） | 可佩戴，**持续**提供增益，**槽位有限** | **已落地**：村庄「锻铁铺」（2026-10-05）、商人「锻造炉」（同界面、金币 ×1.5，2026-10-07） |
| **烹饪** | 食物（`Food.csv`） | 更高级食物 | 食物在**餐厅 / 营地**提供饱食度与收益 | **已落地**：营地篝火（食物升级，`FoodRecipe.csv` 的 5 条 `Enabled=TRUE`）；餐厅「现做」（输入口径见下） |

- **三者互相独立**：材料不进烹饪、食物不做道具、装备不由食物打造；三者各有一张配方表（`ItemRecipe.csv`（待建）/ `EquipmentRecipe.csv` / `FoodRecipe.csv`）。
- **餐厅没有合成台**（2026-10-07 用户口径）：餐厅只有「购买 / 烹饪 / 出售」，**道具合成不在餐厅**（候选重列见设计案 §四）。
- **按本表判据得出的两组待拍板冲突**：
  1. `EquipmentRecipe.csv` 有 6 行配方用的是**合成材料**（101 / 102 / 103 / 105 / 107 / 108），与本表「打造材料 → 装备」不符 → A 改文档 / B 改数据，见设计案 §二。
  2. 餐厅「烹饪」页当前吃的是**材料**（`RestaurantUi.CookableRecipes()` 只列「输入全为 `Material`」的 7 条且不看 `Enabled`；`RunSession.Place.cs` 的 `RestaurantRequirements` 亦明写「餐厅只做材料 → 食物，食物合成在营地」），与本表「烹饪 = 食物 → 更高级食物」不符 → 见设计案 §四.2。

## 一、材料

### 1.1 来源

- 各种战斗中获得，种类多样

### 1.2 分类

| 类别 | 用途 |
|------|------|
| 合成材料 | 用于合成各种道具 |
| 打造材料 | 用于制作装备 |

- 部分材料不存在严格的界限：既可以用于合成道具，也可以经过加工后用于打造装备 —— **待拍板**：2026-10-07 用户口径按类别分工（合成材料 → 道具、打造材料 → 装备），而现 `EquipmentRecipe.csv` 有 6 行越界用了合成材料 → 见[材料分类与道具加工设计案 §二](../../../施工文档/2026/2026.10/材料分类与道具加工设计案.md)

## 二、道具

### 2.1 构成

- 各种药剂与新奇的小玩意

### 2.2 特性

- 消耗品
- 使用后获得战斗内或持续时间内的增益

### 2.3 获取：仅可通过合成台制作（**未实现（遗留）**：五设施里没有「合成台」，落点待拍板 → 见 [材料分类与道具加工设计案 §四](../../../施工文档/2026/2026.10/材料分类与道具加工设计案.md)）

- **输入口径**（2026-10-07 用户口径）：合成只吃**合成材料**（101–110），产物是 `Item.csv` 的 **301–308 八件道具**；与锻造（吃打造材料）、烹饪（吃食物）互不串用。
- 村庄拥有合成台 —— **未实现（遗留）**：村庄五设施已定为旅馆 / 民宿 / 锻铁铺 / 餐厅 / 树林（`DataBase/Level/InteractPoint.csv`），**没有「合成台」这个设施**；落点候选（**餐厅已排除**）见设计案 §四。
- 一天结束时，也可直接通过配方消耗对应材料搭建合成台，并消耗时间点进程合成道具（与时间点系统联动） —— **未实现（遗留）**：营地篝火已落「烹饪」（`FoodRecipe.csv` 的 5 条食物升级配方），**道具配方表（合成材料 → 道具）尚未建立**（`Item.csv` 的 301–308 八件道具目前无任何配方引用）

## 三、装备

### 3.1 部位与佩戴限制

| 部位 | 左右手武器/防具 | 头盔 | 护甲 | 鞋 | 饰品 |
|------|------|------|------|-----|------|
| 佩戴限制 | 两个手位；单手各占一槽，双手占满两槽 | 1 件 | 1 件 | 1 件 | 当前最多 3 件，后续数量待定 |

- 仅将原武器槽替换为左右手武器/防具槽；头盔、护甲、鞋和饰品部位保留。
- 双手装备仅排斥其他手位装备，不排斥头盔、护甲、鞋或饰品。手位防具与护甲部位分别记录。
- 手位搭配与战斗换装见 [六边形战场玩法](../战斗系统/六边形战场玩法.md#五装备槽位)。饰品数量保留为配置项，当前沿用最多 3 件。
- 效果：为角色提供持续的增益
- 战斗换装免费。换下的一件或多件装备加入角色所在格的道具/装备堆；单位与物品堆可同格。陷阱、机关彼此及与物品堆互斥，有触发物件时按最近合法接收格随机安置。
- 装备对每回合移动额度的变化立即生效；本回合已用移动次数保留，避免反复换装刷新次数。移动动作基础距离为一格，基础情况下每次动作消耗 1 能量并计一次；后续可由增益提高单次动作距离。
- 地上武器/防具显示在“当前格道具”入口，拾取需要装备到手位；默认不能放入随身道具槽，预留装备能力开放该权限的接口。无武器或双防具仍允许默认相邻单目标攻击。
- 武器默认攻击规格见 [六边形战场玩法](../战斗系统/六边形战场玩法.md#53-武器默认攻击与防御值)：长刀为单手距离 2，长枪为双手距离 3，魔典为双手距离 4 的投掷单体，弓为双手距离 5 的远程直线。投掷直达落点、不受中间单位或障碍阻挡；魔典和弓无防御值，其他近战武器具备防御值。普通攻击默认免费，只有明确声明时才消耗资源。
- 运行时武器表为 `DataBase/Equipment/Weapon.csv`，路径键为 `Data.Equipment.Weapon`。`AttackMode` 使用 `WeaponAttackMode` 枚举：`AdjacentSingle、MeleeLine、Fan、ThrowSingle、RangedLine、Thrust`；`EquipmentType` 使用 `EquipmentType` 枚举（`Melee` / `Ranged` / `Armor`）标识近战武器 / 远程武器 / 防具，缺省时按 `AttackMode` 推导；表中同时配置攻击距离、防御值、伤害修正、移动修正与资源成本。

### 3.2 获取：仅可通过锻造台制造（**已落地**：村庄叫「锻铁铺」、商人叫「锻造炉」）

- 村庄存在锻造台 —— **已落地（2026-10-05）**：村庄内叫**锻铁铺**，配方 `DataBase/Equipment/EquipmentRecipe.csv`（每次打开 2 次、金币 ×1、每次打造 0.1 时间点）
- **输入口径**（2026-10-07 用户口径）：锻造只吃**打造材料**（201–206）；现 `EquipmentRecipe.csv` 有 6 行用的是合成材料 → 待拍板项（见 §〇 末条 / 设计案 §二）
- 商人处可花费金币使用锻造台 —— **已落地（2026-10-07）**：商人界面右下「**锻造炉**」，同一份界面、金币 ×1.5

## 六、战斗中临时道具交互(2026-09-09)

- 临时道具在战斗中显示为卡片式 prefab(道具名 + 效果摘要)。
- “随身道具”3 格为固定槽位(非按钮),空槽显示“空”;当前格道具面板与三随身槽位于界面右侧;左右装备槽等宽等高。
- 无目标道具:拖动跟手;拖出道具栏松开即使用(治疗等)。
- 目标型道具(投掷型):拖出后吸附顶部中央 + 引导线 + 黄/红格预览;放到合法目标格松开即使用/投放。
- 拖到随身槽 → 移动/交换;拖回当前格道具面板 → 放回地面;拖拽经过某槽位时该槽高亮。
- 从当前格拿起时目标槽已满会自动交换;多件道具允许共存于当前格物品堆。
