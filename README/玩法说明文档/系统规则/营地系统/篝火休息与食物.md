# 篝火休息与食物

## 一、日终休息

- 每天的时间点容量为 4。地图行动消耗当天剩余时间点；剩余为 0 时强制进入休息。
- 玩家也可在尚有时间点时主动结束当天并进入休息。此时未消耗时间点按比例转化为休息收益；主动结束后，当天不能再进入地图节点。
- 休息流程为：放入食物 → 篝火合成 → 选择守夜 → 结算生命、食物效果和夜袭 → 开始新的一天。
- 村庄的完全回复独立于篝火休息，不消耗食物，也不触发守夜风险。

## 二、生命回复

每名未守夜角色的基础回复比例为：

```text
10% + 20% ×（进入休息时剩余时间点 ÷ 4）+ 2% × 本次篝火总饱食度
```

- 回复以角色最大生命值计算，超过最大生命值的部分无效。
- 篝火总饱食度的有效上限为 10；因此食物最多提供 20% 最大生命值的回复加成。
- 轮流守夜的角色将自己的最终回复乘以 2/3。
- 单人守夜的角色不回复生命。

## 三、篝火添加食物

- 食物按玩家添加顺序进入篝火。
- 篝火的**效果饱食度上限**为 10。上限以内的食物提供饱食度和食物效果。
- 首次使累计饱食度超过 10 的食物，及其后的食物，仍提供全部饱食度用于生命回复，但不提供食物效果。
- 过期食物不能放入篝火；篝火中的食物在本次休息结束后全部消耗。
- 食物来源、有效期、清单和配方见[食物系统](../物品系统/食物系统.md)。

## 四、守夜

| 方式 | 生命回复 | 夜袭 | 额外结果 |
|---|---|---|---|
| 不守夜 | 全额 | 30% 概率夜袭 | 无 |
| 轮流守夜 | 每名角色为 2/3 | 不会夜袭 | 无 |
| 单人守夜 | 守夜角色为 0；其他角色全额 | 不会夜袭 | 守夜角色获得 1 张“睡眠不佳” |

- 夜袭在生命回复前发生。战胜夜袭后，未守夜角色仍按本次篝火结算回复生命。
- 夜袭的敌方强度按当天最近一次普通敌袭的 50% 生成；具体怪物组合在遭遇表配置。
- 单人守夜可由任意一名当前存活角色承担。

## 五、睡眠不佳

- “睡眠不佳”是一张无法主动打出的状态牌，加入守夜角色下一场战斗的起始手牌。
- 每次该角色回合结束时，若此牌仍在手牌中，随机获得以下一种弱化：1 层虚弱、1 层易伤，或本回合之后的移动动作额外消耗 1 点能量。
- 触发后，此牌进入弃牌堆；未触发前不占状态牌区。
- 该牌不能被常规出牌操作打出，也不能通过保留、免费或代打绕过限制。

## 六、待后续验证的数值

- 每日时间点容量、基础 10%、时间比例 20%、每点饱食度 2%、篝火上限 10、夜袭概率 30% 和每次休息合成上限 2 均为首版平衡值。
- 食物掉率、事件池、夜袭怪物组合、食物效果叠加方式和“移动能量 +1”的持续时长需要随正式关卡与战斗数据校准。
