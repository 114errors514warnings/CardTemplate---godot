# 关键词系统

关键词（KeyWord / Flag）控制**卡牌本身**的额外行为（保留 / 消耗 / 暴击 / 升级）以及**运行时**附加到卡牌上的临时修饰。

## 一、CardKeyWord（卡牌固有关键词）

`CardKeyWord` 是 `[Flags]` 枚举，CSV 的 `CardKeyWord` 列直接写枚举名，多个用 `|` 分隔：

| 枚举名 | 行为 |
|--------|------|
| `None` | 无 |
| `Retain` | 保留：回合结束时不弃置，留在手牌中 |
| `Exhaust` | 消耗：打出后进入消耗牌堆（`ExhaustPile`），不再回循环 |
| `InfiniteUpgrade` | 无限升级：可记录 `TotalUpgradeLevel`，伤害公式用 `base * 1.2^level` |
| `Crit` | 暴击：造成双倍伤害（实现中） |

> CSV 中 `true` 等价于 `Retain`（`LoadCardCsv.ParseCardKeyWord` 兼容）。

## 二、KeywordFlag（运行时关键词生命周期）

`KeywordFlag` 标志控制**运行时通过 `AddKeyword` Effect 临时附加的关键词**何时移除：

| 枚举名 | 行为 |
|--------|------|
| `None` | 不移除（永久，直到该卡离开手牌）|
| `RemoveAfterActivate` | 关键词生效一次后移除 |
| `RemoveAtTurnEnd` | 回合结束时移除 |

## 三、CardConditionType（出牌条件）

CSV 的 `ConditionParams` 列写 `CardConditionType` 枚举名，**出牌前**自动校验全部条件，任一不满足则不能打出：

| 枚举名 | 条件 |
|--------|------|
| `None` | 无条件 |
| `NoBattleCardPlayedThisTurn` | 本回合内该角色**尚未**打出过战斗牌 |

"战斗牌"口径 = `CardCategory.Attack` 或 `CardCategory.Skill`；`State` 牌不计入已出牌数。

## 四、AppliedKeywordEntry（运行时关键词条目）

```csharp
public struct AppliedKeywordEntry
{
    public CardKeyWord Keyword;   // 哪种关键词
    public KeywordFlag Flags;     // 何时移除
}
```

`Card.AppliedKeywords` 是 `List<AppliedKeywordEntry>`，运行时由 `AddKeyword` Effect 追加。

### 用法示例

卡牌「蓄力」`21002009,AddKeyword|AddKeyword`：第一次为指定战斗牌添加"暴击 + RemoveAfterActivate"（打出后移除），第二次添加"Retain + RemoveAtTurnEnd"（回合结束移除）。

## 五、卡牌升级

| 类型 | 字段 | 行为 |
|------|------|------|
| 战斗中升级 | `BattleUpgradeLevel` | 战斗内升级临时 +1，战斗结束重置 |
| 永久升级 | `PermanentUpgradeLevel` | 跨战斗累计，永远保留 |
| 累计等级 | `TotalUpgradeLevel` | 两者之和 |

`InfiniteUpgrade` 卡牌用 `TotalUpgradeLevel` 计算伤害：`baseExtraDamage * 1.2^level`，向下取整（`Math.Floor`）。

## 六、CSV 配置示例

```csv
11002001,盾牌冲撞,Attack,1,ShieldSlam,造成攻击力+护盾值的伤害,2,Retain
```

`CardKeyWord=Retain` → 回合结束不弃置。

```csv
21002010,统一战线,Skill,2,Shield|AddState,防御，额外获得6点格挡，所有友方下张战斗牌免费,1;6;1|5;20;1
```

`EffectType` 中 `AddState` 第二个段 `5;20;1` → 目标 `AllAllies(5)`，附加 `NextBattleCardFree(20)` 1 层。

## 七、六边形战场新增词条与特性（设计，未实施）

| 名称 | 已确认语义 | 尚需细化 |

| 穿透 | 突进、远程攻击不被障碍或其他单位挡下 | 沿途命中策略、突进本体通过及落点、与爆炸组合 |
| 爆炸 | 远程实际命中目标附近单位受伤 | 半径、伤害量、敌我过滤、多个命中对应爆炸次数 |

穿透/爆炸属于攻击修饰，免疫强制位移属于单位特性，不能混入同一概念。以上尚未加入运行时枚举或 CSV，拟实施时同步定义、解析器、展示和测试。既有伤害公式继续使用，碰撞半伤基数与回弹惩罚不在此擅自定值。

完整行为见 [六边形战场玩法](六边形战场玩法.md#35-突进远程穿透与爆炸) 与其突进击退、连锁与回弹章节。

### 7.1 响应（Response，卡牌关键词；2026-10-03 用户口径，**未实施**）

- **语义**：在满足该卡的**触发条件**且**费用足够**时**自动打出**这张牌；**不可手动打出**（手动出牌操作要被拒）。
- **生命周期**：与「保留」相反 —— **回合开始时**弃置（不是回合结束时不弃置）。
- **显示口径**：作为**单独一行**，在「响应」后显示触发条件，例如 `响应：即将受到伤害时`；CSV 的 `CardKeyWord` 列与卡面该行都写这一整串。
- **首张实例**：精灵「敏捷闪躲」= `响应：即将受到伤害时`（[卡牌表格/精灵.csv](../../角色设计/卡牌表格/精灵.csv)）；触发后抵消该次伤害的**任何效果**，多段攻击只抵第一段。
- **落地形态（拟）**：触发时施加一层**屏障**（[状态系统 §2.2](../../../功能说明文档/战斗系统/状态系统.md)）—— 屏障负责「抵挡一次攻击伤害」，「免除该次攻击附带的效果」另需一条豁免通道（待敲定）。
- **现状**：枚举 / 解析 / 自动打出 / 弃置时机**均未实现**；运行时该卡当前只是「1 费获得 1 层屏障」，`CardKeyWord` 列留空（写 `响应` 会解析失败）。完整设计与验收见 [10 月施工文档 §20](../../../施工文档/2026/2026.10/10月施工文档.md) 与[代码需求清单 P2-28](../../../施工文档/2026/2026.09/玩法/代码需求清单.md)。
