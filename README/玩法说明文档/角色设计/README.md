## 角色定位（2026-10-03 用户口径）

| 角色 | 一句话定位 | 卡牌强化方向（用户口径）|
|---|---|---|
| [重剑手](重剑手.md) | 前排承伤：叠盾 + 越挨打越强 | 施加护盾、损失生命获得增益（生命越低越容易被部分攻击锁定为目标）、反击、近战范围攻击 |
| [精灵](精灵.md) | 远程直线穿透 + 手牌 / 生命互换的支援 | 消耗友方的卡牌（**增益的一环**）、移除友方的负面状态、恢复友方生命、召唤物、远程直线穿透攻击 |
| [法师](法师.md) | 团队增益 + 地形压制 | 群体增益、制造 debuff 区域（**火焰 / 寒冰 / 雷电等自然现象**，不使用黑暗向术式）、群体远程投掷攻击、持续伤害 |

机制侧现状（每条方向「已实现 / 半实现 / 未实现」）见各角色页的定位表；本批新增 6 张牌（精灵 / 法师 各 3 张，B / A / S）的等级与效果原文在 [卡牌表格](卡牌表格/README.md)，逐张说明与**按价值等级（[卡牌数值平衡标准](../系统规则/数值平衡/卡牌数值平衡标准.md) §4.4 速查表）重算的数值**在各角色页（精灵 §四 / 法师 §五）。
