## 角色定位（2026-10-03 用户口径）

**一句话**：前排承伤位 —— 用护盾与「越挨打越强」把敌人的攻击吸到自己身上。

| 作战方向 | 语义 | 机制侧现状（2026-10-03 查证）|
|---|---|---|
| 施加护盾 | 叠盾挡伤 | **已实现**：`EffectType.Shield`（「攻守兼备」`1` 自身 / 「大地」`1;0;3` 三次防御 + `MirrorShieldToAllies` 复制给全体友方）；护盾上限与保留见 `StateType.ShieldCapEqualsHP = 14`（阵地）|
| 损失生命获得增益 | 每失去 1 点生命换 1 点攻击 | **已实现**：`StateType.GainAttackOnHpLoss = 11`（燃血）+ `EffectType.HpLoss = 17`（燃血 / 强撑）|
| 生命越低越容易被部分攻击锁定为目标 | 嘲讽 | **部分实现**：`StateType.ForcedTaunt = 15`（城墙）＝「**有护盾时**敌人的**单体**攻击优先选中持有者，多名合法时随机」→ **没有**按 HP 比例加权的嘲讽；用户口径与现役实现不一致，⚠️ 待拍板 |
| 反击 | 回合外受击反打 | **已实现**：`StateType.CounterAttack = 4`（「反攻号角」`AddState 1;4;2`、`GetStateStacks` 按层计数）、`CounterAttackWhenAttacking = 12`（紧咬不放）|
| 近战范围攻击 | 以自身为中心的范围 | **已实现**：空间 `Fan`（两条 120 度边界围出的前方区域，路径上友军同受完整效果）、`WhirlwindSlash = 5`（旋风斩：回合外攻击群攻化）|

> 本页只记定位与机制现状；逐卡见 [六边形战场卡牌设计 §四](六边形战场卡牌设计.md)，流派思路见下。

## 卡组构建思路

- 流派1：叠盾防守，并通过反甲和反击造成伤害  
  - 核心卡：城墙（当你拥有护盾时，敌人的攻击会优先以你为目标）、回合外攻击变群攻、全身撞击（造成等同防御点数的伤害）、护盾翻倍
- 流派2：大费打击，可叠加的超高单点伤害  
  - 核心卡：绝力一击，武装（升级自身和手牌中的一张牌）
- 流派3：卖血力量流派  
  - 通过自己掉血或者受到伤害叠加力量，并通过特定攻击回血
