# 法师

> 2026-10-03 用户口径：按「通过卡牌强化的作战方向」给法师加 3 张专有牌（B / A / S），优先复用现有机制；**场地效果不使用黑暗向术式，以火焰、寒冰、雷电等自然现象为主基调**（本轮补记）。旧三张设计牌（咒术准备 / 法力涌流 / 法术结界）见[卡牌表格/法师.csv](卡牌表格/法师.csv)，新版空间适配见[六边形战场卡牌设计 §五](六边形战场卡牌设计.md)。本页为**文档设计**，2026-10-03 已落 `DataBase/Card/法师Card.csv`（`11004001` 陨星投掷 / `21004002` 法术共鸣 / `21004003` 寒霜之地，另含 `21004001` 法术护盾；空间列已写、**生效受 P2-29 / P2-30 阻塞**，见 §四 末注）；等级与费用按[卡牌数值平衡标准](../系统规则/数值平衡/卡牌数值平衡标准.md) §4.2 / §4.3 / §4.4 定级。

## 一、角色定位

**一句话**：团队增益与地形压制的施法位 —— 用「格上区域」和「持续伤害」把战场慢慢变难走。

| 作战方向（用户口径）| 语义 | 机制侧现状（2026-10-03 查证）|
|---|---|---|
| 群体增益 | 一次给多名友方加状态 | **已实现**：`EffectType.AddState` + 目标 `AllAllies(5)`（「统一战线」`1;6;1|5;20;1`）；同类群体资源用 `AddCost` + `5`（「鼓气」`5;1`、「总攻」`5;2`）|
| 制造 debuff 区域（**火焰 / 寒冰 / 雷电等自然现象**）| 让某一格持续对进入者生效 | **半实现**：格上区域物通道已接入（`SpatialShape=Trap` + `TrapId` → `GroundObjectPlacementService`/`TryPlaceTrap` + `EntryTriggerMode.EveryEntry`），**触发内容未接入**；「停留 / 回合开始对格内结算」没有钩子 |
| 群体远程投掷攻击 | 法典投掷的落点周围一起受伤 | **已实现**：武器几何 `ThrowSingle`（射程 4；途中单位与障碍都不阻挡）；群体形状用 `CardSpatialShape.Burst` + `Radius`（`BattleRangeResolver.ResolveAffectedCells` 已实现爆发）|
| 持续伤害 | 每回合持续掉血 | **未实现**：`StateType.Ignite = 3`（燃烧）在枚举与 `通用State.csv` 里都有（`IsDebuff=TRUE`、`Never/None` 不衰减、不可叠层），但**代码侧只有 4 处引用**（枚举 / 初始状态配置 / 烟测断言 ×2），**没有回合结算 tick** → 当前只是标记 |

- 开局装备法典（双手；`BlocksDefenseShield=true` → 带护盾效果的防御牌会被拒），属性修正攻击 +1 → **当前攻击 3**（`Character.csv` 基础 2 + 法典 `DamageBonus 1`），默认攻击 = 4 格远程投掷（[职业基础配置](职业基础配置.md)）。
- 定位推论：法师同样**吃不到「叠盾」**，输出靠射程与落点，团队价值靠「全体增益 + 元素地形」。

## 二、元素基调（2026-10-03 用户口径）

- **场地效果只走自然现象**：以**火焰、寒冰、雷电**为主基调；其他自然现象（风、沙、雨、雾、藤蔓等）也可用。
- **不使用黑暗向术式**（腐化、诅咒、亡灵、血祭之类）—— 原「腐化之雾」据此换元素、改名「寒霜之地」。

| 元素 | 主基调表现 | 建议挂载状态 | 现状 |
|---|---|---|---|
| 火焰 | 燃烧、爆裂、陨星 | `Ignite` 燃烧（伤害型，`IsDebuff`）| 状态行存在且不衰减；**无回合结算 tick** |
| 寒冰 | 冻结、迟缓、霜地 | `Weak` 虚弱（攻击伤害 −25% = 冻僵）| ✓ 已实现（`OnTurnStart` 每回合 −1 层）|
| 雷电 | 破甲、麻痹、连锁 | `Vulnerable` 易伤（受到伤害 +50% = 破甲）| ✓ 已实现（`OnTurnStart` 每回合 −1 层）|
| 其他自然现象 | 按效果定 | 待定 | — |

> 元素是**表现层基调**，挂载的仍是现成状态，不新增状态枚举；「燃烧」的伤害结算缺口见 §六。

## 三、定级口径（2026-10-03）

口径与[精灵](精灵.md) §二 同一套（固定值计、不按人数乘算、空间与 DoT 列未评定）；攻击类点数按法师当前攻击 **3** 计。

### 4.1 法术共鸣（B，1 费）—— 群体增益

- **设计意图**：法师的「团队底牌」—— 一张牌把全队的攻击力抬一档；因为群体不按人数计值，等级落在 B、费用给 **1 费**（2 费 B 需要 10.1 点，只有靠人数乘算才凑得到，而那是 [数值设计规范](../../AIWorkSpace/AgentOps/数值设计规范.md) §一.4 禁止的口径）。
- **`Params` 草案**：`EffectType = AddState|AddState`，`Params = 1;6;1|5;6;1`（自身 / 增加攻击力 / 1 层；全体友方 / 增加攻击力 / 1 层）—— 与「统一战线」的参数写法同形。
- **定级**：已评定 = 1 层攻击力 **3** vs 1 费 B **4.3** → 偏差 **−1.3 ✓ 平衡**；群体覆盖列未评定（不按人数乘算）。
- **已验证复用**：`StateType.AddAttack = 6`（1 层攻击力 = 每次攻击 +1 伤害），`StateSystem.AddOrUpdateState` 负责叠层；`通用State.csv` 里该状态不衰减（`Never / None`）。
- **口径**：`AllAllies` 不含自身，所以自身那一段单独写 `1;6;1`；范围写「全体友方」而不是「相邻友军」（模板侧有「邻友」，缺的是运行时目标类型）。

### 4.2 寒霜之地（A，1 费）—— 自然元素场地（寒冰）

- **设计意图**：法师的第一张「地形牌」，也是**元素场地的样板**（用户口径：火焰 / 寒冰 / 雷电）。往敌人必经之路上放一格霜地，逼对方绕路或吃 1 层虚弱；原「腐化之雾」的黑暗向命名与效果按元素基调替换。
- **空间字段**：`SpatialShape=Trap`，`SpatialArgs=Range=4`（法典武器距离），`TrapId=frost_field`（新定义名，待登记；替换原 `corruption_mist`）。
- **`Params` 草案**：`EffectType = Damage|AddState`，`Params = 2;0|2;2;1`（选定目标（= 该格上的敌方单位）+ 额外伤害 0；同目标 + `Weak` 1 层）；区域物内的「进入 → 1 层虚弱」由区域物定义给出（同一处缺口）。
- **定级**：已评定 = 攻击 3 + 虚弱 1 层 2 = **5** vs 1 费 A **5.2** → 偏差 **−0.2 ✓ 平衡**；区域物的后续触发（2 点/次 × 次数）列未评定。
- **已验证复用**：落物检查（射程 / 可通行 / 目标格无单位与物品）、`GroundObjectKind.Trap`、`EntryTriggerMode.EveryEntry`（每次进入都触发）、触发回传（`BattleMovementService` 的 `Trigger`）、`AddState(Weak)`。
- **缺口**：
  1. **触发内容**：与精灵「古树哨卫」同一处依赖 —— 需要区域物定义给出 `frost_field` 的触发内容：进入 → `AddState(Weak, 1)`（现成 `EffectType`）。
  2. **停留结算**（可选强化）：设计里只影响进入者；若要做「格内单位回合开始也吃 1 层虚弱」，需要新增地面效果回合钩子，**当前无**。
- **简单版验收**：1 费打出 → 目标格上的敌方单位受一次攻击 + 1 层虚弱；该格出现 `frost_field`；敌人进入该格 → 1 层虚弱；同格可反复触发。

### 4.3 陨星投掷（S，2 费）—— 群体远程投掷 + 持续伤害（火焰）

- **设计意图**：法师的收束技，把三条方向压在一张牌上 —— 投掷落点（法典几何）、半径覆盖（群体）、燃烧（持续伤害）。
- **空间字段**：`SpatialShape=Burst`，`SpatialArgs=Range=4;Radius=1`（4 = 法典武器距离；半径 1 = 目标格及相邻六格）。
- **`Params` 草案**：`EffectType = Damage|AddState`，`Params = 2;6|2;3;1`（选定目标 + 额外伤害 6；同目标 + `Ignite` 1 层），`CardKeyWord = Exhaust`（写法与「淬炼」的 `2;6|…` 同形）。
- **定级**：已评定 = 攻击 3 + 额外伤害 6 = 9，消耗 −1 → **8** vs 2 费 S **14.5** → 偏差 **−6.5**；差额由**半径 1 的群体覆盖**承担（未评定）。两条收口路径（待拍板）：① 先补「空间 / 群体收益评定」（推荐，符合 §六）；② 若要在评定前就落在区间内，把费用降到 **1 费 S**（6.2）→ 偏差 **+1.8 ✓**（代价：1 能量打出半径 1 的火焰爆发，偏廉价）。
- **已验证复用**：`ResolveAffectedCells` 的 `Burst` 分支给出半径内格点，`TryCastCard` 把格上单位收集为受影响目标；`Damage` 走 `AttackEffect`（伤害 = 来源攻击 + 额外值），`AddState` 走 `StateSystem.AddOrUpdateState`（燃烧不可叠层，配几层都按 1 层落地）。
- **待拍板的两处**：
  1. **燃烧没有结算**：`Ignite` 当前只是标记（且 `Never / None` 不衰减 → 将来接 DoT 要先定义「每回合掉多少血、是否永久」）→ 简单版承认「只挂标记」，或改挂「易伤 / 虚弱」作即时压制；完整版需补 DoT 结算（新 `EffectType` 或状态侧回合钩子）。
  2. **半径内敌我过滤**：空间路由把受影响格上的**所有**单位收集为目标（与[六边形战场卡牌设计](六边形战场卡牌设计.md) §二「扇扫」的友军同效口径一致）→ 要「只打敌方」需按 `EffectTargetType.AllEnemies(3)` 过滤，而「空间集合 × 全体敌人」的交集语义**未实测**。

## 五、数值一览（固定值口径）

应有点数取 §4.4 速查表（= §4.2 费用基准 × §4.3 等级系数），判定用 §4.5（`|偏差| ≤ 2` 记平衡）；攻击类已含法师当前攻击 **3**：

| 卡 | 等级 · 费 | 应有点数 | 已评定部分（单目标）| 偏差 | 未评定项 | 结论 |
|---|---|---|---|---|---|---|
| 法术共鸣 | B · 1 | 4.3 | 1 层攻击力 = **3** | **−1.3 ✓** | 群体覆盖 | 平衡 |
| 寒霜之地 | A · 1 | 5.2 | 攻击 3 + 虚弱 1 层 2 = **5** | **−0.2 ✓** | 区域物触发（2 点/次 × 次数）| 平衡 |
| 陨星投掷 | S · 2 | 14.5 | 攻击 3 + 额外 6 − 消耗 1 = **8** | **−6.5**（差额需由半径 1 群体覆盖补齐）| 半径 1 群体、燃烧 DoT、敌我过滤 | **需先补群体评定**（或费用降 1 费 → +1.8 ✓）|

> 与上一版（2026-10-03 早前草案）的差别：不再用「1 层攻击力 × 3 人 = 9 点」的乘算写法（违反[数值设计规范](../../AIWorkSpace/AgentOps/数值设计规范.md) §一.4），改为**单个标准单位**计值 + 未评定项清单；法术共鸣由 2 费改 1 费、寒霜之地（原腐化之雾）由 2 费改 1 费并改为即时攻击 + 虚弱、陨星投掷由 3 费改 2 费并把额外伤害从 3 提到 6（对齐 §4.4 档位）。
