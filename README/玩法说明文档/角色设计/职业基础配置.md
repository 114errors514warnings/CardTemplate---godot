# 职业基础配置

## 当前可运行配置

重剑手（1002）、精灵（1003）和法师（1004）基础属性统一为 HP 30、攻击 2、防御 2。三者初始牌组均为 8 张：攻击 ×5、护盾 ×3。

| 职业 | 开局双手装备 | 属性修正 | 默认攻击 |
|---|---|---|---|
| 重剑手 | 双手剑 | 攻击 +1，防御 +1 | 相邻单体 |
| 精灵 | 弓箭 | 攻击 +2；不能通过防御牌获得护盾 | 5 格远程直线 |
| 法师 | 法典 | 攻击 +1；不能通过防御牌获得护盾 | 4 格远程投掷 |

装备效果由 `DataBase/Equipment/Weapon.csv` 定义。装备时，攻击与防御会实际修正单位属性；因此攻击牌、普通攻击和防御牌均使用修正后的数值。弓箭、法典占用双手，且带有 `BlocksDefenseShield=true`：包含护盾效果的防御牌会被拒绝，不会消耗卡牌或能量。

## 六边形测试与正式关卡的边界

- `DataBase/Battlefield/FoundationMap.json` 是保留的六边形地图测试关，未因本轮职业/怪物配置而改动。
- 正式第一层地图遭遇由 `DataBase/Stage/第一层/*.csv` 配置；首批怪物方案已加入普通敌袭与高危敌袭表。
- 武器属于局外的角色/背包装备状态，不由地图配置或每场战斗临时发放。新建运行局时会把职业初始武器写入角色槽位存档；战斗仅还原该持久状态，战后也会回写。后续局外换装、丢弃 UI 只修改同一装备字段。
