# 卡牌参数配置说明

## 一、CardId 编号规则

所有 CardId 均为 **8 位数字**，由「5 位前缀」+「3 位后缀」组成。

### 1. 通用牌前缀

| 卡牌类型 | CardType | 前缀 |
|----------|----------|------|
| 攻击牌 | Attack | 10000 |
| 技能牌 | Skill | 20000 |
| 状态牌 | State | 30000 |

### 2. 角色专有牌前缀

格式：`类型数字(1位)` + `CharacterID(4位)`

- 攻击专有牌：`1XXXX`（1 + 4位角色ID）
- 技能专有牌：`2XXXX`
- 状态专有牌：`3XXXX`

### 3. 后缀规则（3位）

- 同前缀下，已有 ID 的最大后缀 + 1，补零至 3 位。
- 若该前缀下尚无 ID，后缀从 `001` 开始。
- 示例：前缀 `10000` 下已有 `10000001`、`10000002`，新卡 ID 为 `10000003`。

---

## 二、CSV 排列顺序规则

CSV 文件中的卡牌行必须按 **CardId 从小到大**升序排列。新增卡牌时应插入到对应数值位置，而非追加到文件末尾。

---

## 三、通用 Card.csv 字段说明

CSV 表头：`CardId,CardName,CardType,EnergyCost,EffectType,EffectDesc,Params,CardKeyWord,ConditionParams`

| 字段 | 说明 |
|------|------|
| CardId | 8 位卡牌模板 ID，详见上方编号规则 |
| CardName | 卡牌显示名称 |
| CardType | 卡牌类别：`Attack` / `Skill` / `State` |
| EnergyCost | 出牌消耗的能量点数 |
| EffectType | 效果类型，多效果用 `\|` 分隔，**顺序即执行顺序** |
| EffectDesc | 效果描述（展示用文本） |
| Params | 各效果参数，多效果用 `\|` 分隔，同一效果内各参数用 `;` 分隔 |
| CardKeyWord | 卡牌关键词，多关键词用 `\|` 分隔 |
| ConditionParams | 可选；卡牌出牌条件参数，多条件用 `\|` 分隔，填写 `CardConditionType` 枚举名 |

> **注意**：`EffectType` 与 `Params` 按索引一一对应，第 i 个效果使用第 i 组参数。

### 参数分隔层级

- `|`：分隔多个效果，对应 `EffectType` 中的多个效果项
- `;`：分隔单个效果的各个参数槽位

示例格式：`EffectType: A|B`，`Params: 目标;参数1;参数2|目标;参数1`

---

## 四、Params 参数格式

`Params[i][0]` **固定**为该效果的目标类型（`EffectTargetType`），后续参数为效果自身参数。

### EffectTargetType（目标类型）

| 值 | 枚举名 | 说明 |
|----|--------|------|
| 0 | Auto | 自动（有选中目标则选中，否则自身） |
| 1 | Self | 自身 |
| 2 | SelectedTarget | 选定目标（卡牌将自动标记为需要目标） |
| 3 | AllEnemies | 全体敌人 |
| 4 | AllUnits | 场上所有单位 |

> `NeedTarget` 无需手动配置，系统自动推导：任意效果的目标类型为 `SelectedTarget(2)` 时，该卡牌即为需要指定目标。

### EffectType（效果类型）及其效果参数

| 值 | 枚举名 | 效果参数（`Params[i][1]` 起） | 说明 |
|----|--------|------------------------------|------|
| 1 | Damage | `[1] extraDamage`（可省略），`[最后] hitCount`（可省略，默认1次） | 对目标造成伤害（受易伤等状态修正）；当参数个数大于1时，最后一个参数表示重复命中次数 |
| 2 | Shield | `[1] extraShield`（可省略），`[最后] shieldCount`（可省略，默认1次） | 为目标增加护盾；当参数个数大于1时，最后一个参数表示重复防御次数，前面的参数仍表示额外护盾 |
| 3 | AddState | `[1] stateType`，`[2] stacks`（默认1） | 为目标附加状态 |
| 4 | ClearState | `[1] stateType` | 清除目标指定状态 |
| 5 | Heal | — | 治疗（当前说明文档已预留，具体实现以代码为准） |
| 6 | DrawCard | — | 抽卡（当前说明文档已预留，具体实现以代码为准） |
| 7 | AddCost | `[1] amount` | 增加来源单位能量，受状态修正 |
| 8 | ClearAllStates | — | 清除目标全部状态 |
| 9 | ShieldSlam | `[1] extraDamage`（可省略） | 造成“来源攻击力 + 来源护盾值 + 额外值”的伤害 |
| 10 | ClearFirstNormalDebuff | `[1] count`（默认1） | 清除目标状态栏中的前 count 个普通弱化状态 |
| 11 | UpgradeBattleCard | `[0] cardTargetType`，`[1] count`（默认1），`[2] requireKilledTarget`（可省略） | 升级战斗中的具体卡牌 |
| 12 | UpgradePermanentCard | `[0] cardTargetType`，`[1] count`（默认1），`[2] requireKilledTarget`（可省略） | 升级默认卡组中的具体卡牌 |
| 14 | AddKeyword | `[0] cardTargetType`，`[1] keyword`（CardKeyWord 枚举值），`[2] keywordFlag`（KeywordFlag 枚举值），`[3] count`（默认1） | 为指定卡牌运行时添加关键词；关键词生效后行为由 KeywordFlag 控制 |
| 15 | MirrorShieldToAllies | `[1] extraShield`（可省略） | 将前续 Shield 效果累积的护盾复制到全体友方 |

### CardOperationTargetType（卡牌操作目标类型）

| 值 | 枚举名 | 说明 |
|----|--------|------|
| 0 | None | 无效目标类型 |
| 1 | SelectHandCards | 由玩家手动选择手牌中的指定数量卡牌 |
| 2 | RandomHandCards | 随机选择手牌中的指定数量卡牌 |
| 3 | RandomDefaultDeckCards | 随机选择默认卡组实例中的指定数量卡牌 |

### 卡牌操作效果参数补充说明

- `Params[i][0]`：`CardOperationTargetType`，表示本条卡牌操作效果要作用到哪一类卡牌。
- `Params[i][1]`：目标数量，省略时默认按 1 张处理。
- `Params[i][2]`：`requireKilledTarget`，可省略；当该值大于 0 时，表示这条卡牌操作效果必须在“本次出牌已击杀目标”时才会触发，否则跳过。
- 该第三参数目前用于类似“淬炼”这种“如果击杀目标，则随机永久升级卡组中的一张牌”的效果配置。

示例：

```csv
11002004,淬炼,Attack,2,Damage|UpgradePermanentCard,攻击，造成6点额外伤害，如果击杀目标，随机永久升级卡组中的一张牌，消耗,2;6|3;1;1,Exhaust
```

- 第一段参数 `2;6`：`Damage`，目标类型为 `SelectedTarget(2)`，额外伤害 6。
- 第二段参数 `3;1;1`：`UpgradePermanentCard`，目标类型为 `RandomDefaultDeckCards(3)`，随机升级 1 张，且要求本次先击杀目标才触发。

### CardKeyWord（卡牌关键词）

| 枚举名 | 说明 |
|--------|------|
| Retain | 保留：回合结束时不弃置 |
| Exhaust | 消耗：打出后进入消耗牌堆 |
| InfiniteUpgrade | 无限升级：允许记录并显示累计升级级数 |

### CardConditionType（条件关键词参数）

| 值 | 枚举名 | 说明 |
|----|--------|------|
| 0 | None | 无条件，占位值 |
| 1 | NoBattleCardPlayedThisTurn | 本回合内，该牌所属角色尚未打出过战斗牌 |

- `ConditionParams` 是 `Card` 自身的出牌条件成员；只要该列非空，系统就会在实际出牌前校验全部条件。
- 当前“战斗牌”的口径为：`Attack` 和 `Skill`；`State` 牌不计入该条件的已出牌次数。
- 条件关键词会在实际出牌前校验；任一条件不满足时，该牌本次不能打出。

示例：

```csv
21002004,蓄势待发,Skill,1,Shield,如果本回合尚未打出过战斗牌，则获得护盾,1,,NoBattleCardPlayedThisTurn
```

### StateType（状态类型）

| 值 | 枚举名 | 说明 |
|----|--------|------|
| 0 | None | 无 |
| 1 | Vulnerable | 易伤：受到伤害 +50%（向下取整），可叠层，每回合开始 -1 层 |
| 2 | Weak | 虚弱：造成的攻击伤害 -25%（向下取整），可叠层，每回合开始 -1 层 |
| 3 | Ignite | 点燃（待实现） |
| 4 | CounterAttack | 反击：回合外受到攻击时，对来源进行一次反击（反击不会触发反击），可叠层，每回合开始 -1 层 |
| 5 | WhirlwindSlash | 旋风斩：回合外的攻击会作用于所有敌人，可叠层，每回合开始 -1 层 |

## 六、当前实现补充说明

### 1. 多玩家战斗下的目标解析

- `SelectedTarget`：由出牌时传入的目标决定。
- `Self`：作用于当前出牌角色自身。
- `AllEnemies`：
	- 玩家出牌时，作用于所有存活怪物。
	- 怪物结算时，作用于所有存活玩家。
- `AllUnits`：作用于所有存活单位。

### 2. NeedTarget 推导规则

- 只要任意效果的目标类型为 `SelectedTarget(2)`，该牌会自动被系统视为“需要目标”的卡牌。
- UI 调试出牌时，若卡牌需要目标但未传入目标，出牌会失败。

### 3. 状态牌与状态牌堆

- 状态牌打出后不会进入普通弃牌堆，而是进入其目标单位的状态牌堆。
- 状态结束时，若存在回收回调，则会将对应状态牌移回所属角色的弃牌堆。
- 同一张状态牌当前不支持同时进入多个不同单位的状态牌堆。

---

## 五、多效果执行顺序说明

多效果卡牌按 `EffectType` 字段中的配置顺序**依次执行**。若需要让某一效果受到另一效果的加成（例如先施加易伤再造成伤害），**必须将施加状态的效果放在造成伤害的效果前面**。

**示例**（10000002 压制打击）：

```
EffectType: AddState|Damage
Params:     3;1;2|2
```

- 效果1：`AddState`，目标=`AllEnemies(3)`，`stateType=Vulnerable(1)`，`stacks=2`
- 效果2：`Damage`，目标=`SelectedTarget(2)`，伤害已吃到本次施加的易伤加成

## 七、卡牌 CSV 文件组织规则

### 文件存放位置

所有卡牌 CSV 均放在 `DataBase/Card/` 目录下，按以下结构组织：

```
DataBase/Card/
├── 通用/
│   └── 通用Card.csv        ← 所有角色通用牌
└── 重剑手Card.csv          ← 角色专属牌（与 通用/ 同级）
```

- **通用牌**：放入 `通用/通用Card.csv`，供所有角色使用的基础牌池。
- **角色专属牌**：以 `<角色名>Card.csv` 命名，直接放在 `DataBase/Card/` 下，不放进 `通用/` 子目录。

### 自动加载规则

游戏启动时，`LoadingSystem` 会递归扫描 `DataBase/Card/` 目录（含所有子目录）下的全部 `.csv` 文件，逐一合并加载到卡牌字典中。**新增角色专属卡牌 CSV 无需修改代码或路径注册表**，放入对应目录后下次启动即自动生效。

- 若多个 CSV 中存在相同 `CardId`，先加载的条目保留，后续重复 ID 会打印警告并跳过。
- 路径注册表（`FilePathRegistry.csv`）中的 `Data.Card.Common` 键仅供手动调用 `LoadCardsByKey` 时使用，不影响启动时的自动扫描。
