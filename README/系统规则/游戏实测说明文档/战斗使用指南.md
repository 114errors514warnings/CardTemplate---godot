# 战斗使用指南

> 摘录自 `README/系统规则/使用介绍.md`（2026-08-29 迁移）

## 一、开始战斗前的准备

### 1. 选择角色

- 点击"新增角色"按钮
- 参数格式：`角色ID`
- 每点击一次，会将该角色追加到当前出战列表末尾
- 仅在战斗开始前生效

### 2. 修改已有角色槽位

- 点击"选择角色"按钮
- 参数格式：`角色ID [index]`
- `index` 从 1 开始，不填时默认修改第 1 个角色
- 该按钮用于修改"第几个角色槽位"上的角色，而不是新增角色
- 仅在战斗开始前生效

### 3. 删除最后一个角色

- 点击"删除角色"按钮
- 无需参数
- 默认删除当前出战列表中的最后一个角色
- 仅在战斗开始前生效

### 4. 添加怪物

- 点击"添加怪物"按钮
- 参数格式以对应按钮说明为准
- 可多次添加怪物，组成敌方阵容

### 5. 开始游戏

- 点击"开始游戏"按钮
- 系统会根据当前 `BattleSetupData` 中记录的角色和怪物初始化战斗

## 二、对局信息查看

### 1. 局内页签

- 显示所有存活角色与怪物的基础信息
- 角色信息包括：
  - 角色ID
  - 名称
  - UniqueInGameID
  - 当前/最大生命
  - 攻击、防御、能量、护盾
  - 当前状态
  - 当前手牌

### 2. 抽牌堆详细页签

- 按角色分别显示各自抽牌堆
- 每个角色单独一段，包含牌名、CardId、卡牌 UniqueInGameId

### 3. 弃牌堆详细页签

- 按角色分别显示各自弃牌堆
- 格式与抽牌堆相同

## 三、玩家回合如何出牌

### 1. 回合规则

- 玩家回合开始时，所有存活角色会**同时**开始回合
- 所有角色都会各自抽牌并重置能量
- 玩家回合内可自由切换操控不同角色出牌

示例：

- 角色A出牌
- 角色B出牌
- 角色A再次出牌

### 2. 出牌按钮参数格式

- 新格式：`[操作者玩家UniqueInGameId] 手牌顺序 [目标UniqueInGameId]`
- 若省略操作者玩家ID，则默认使用当前第一个可用角色
- 若卡牌不需要目标，则目标参数可省略

示例：

- 正确示例：`0000001 1 1000001`
  - `0000001`：操作者玩家UniqueInGameId
  - `1`：该角色手牌中的第1张牌
  - `1000001`：目标单位UniqueInGameId

> **注意**：手牌顺序是当前手牌列表中的位置，不是卡牌模板 ID。

## 四、结束回合

- 点击"结束回合"按钮
- 所有角色会**同时**结束玩家回合
- 所有非保留手牌会进入各自弃牌堆
- 随后进入怪物回合

## 五、修改属性类按钮

以下按钮现已支持多角色：

- 设置生命
- 设置攻击
- 设置防御
- 设置能量上限
- 增加能量

### 参数规则

- 通用格式：`[玩家UniqueInGameId] 数值...`
- 若省略玩家UniqueInGameId，则默认使用当前第一个可用角色

示例：

- 设置生命：`[玩家UniqueInGameId] 当前生命值 最大生命值`
- 设置攻击：`[玩家UniqueInGameId] 攻击值`
- 设置防御：`[玩家UniqueInGameId] 防御值`
- 设置能量上限：`[玩家UniqueInGameId] 能量上限`
- 增加能量：`[玩家UniqueInGameId] 增加能量值`

## 六、关于 UniqueInGameId

- 角色、怪物、卡牌在战斗中都有各自的 `UniqueInGameId`
- 多玩家模式下，涉及"指定操作者""指定目标"的 UI 操作，优先使用该 ID
- 对局信息面板中可以查看当前角色和怪物的 `UniqueInGameId`
- 详见 [实体与标识/UniqueInGameId](../实体与标识/UniqueInGameId.md)

## 七、当前限制

- 选择角色按钮当前用于"加入角色"，重复点击会继续往出战列表追加角色
- 状态牌当前不支持同一张牌同时进入多个不同单位的状态牌堆
- 怪物攻击目标当前从所有存活玩家中选取有效目标（**2026-08 增强**：拥有 `ForcedTaunt` 且 `Shield > 0` 的玩家优先）
