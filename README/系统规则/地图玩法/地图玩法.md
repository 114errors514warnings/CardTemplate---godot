# 地图玩法

> 战斗之外的关卡流程玩法：地图选路 + 时间点 / 昼夜循环。地图几何示意见同目录「地图示意图.png」。

## 一、定位与总览

- 类杀戮尖塔的构筑式玩法：在地图上选择关卡或遇到其他类型的节点，通过完善自己的卡组来变强
- 目标：战胜三层地图的三个 Boss

## 二、地图结构

- 地图为一个大正六边形，由等比缩放的小型正六边形节点铺成
- 每个节点连接附近 3 个节点
- 连接线方向与两相邻节点中心的连线平行，长度与节点边长相同
- 大六边形每条边包含的节点数为奇数，以保证地图中心存在节点
- 几何细节以「地图示意图.png」为准

## 三、起点与终点

- 起点：地图最左侧节点，玩家从此开始游戏
- 推进：只能通过前往相邻节点进行探索，需要规划路线
- 终点：最右侧 Boss 节点，进入条件见 §四钥匙

## 四、节点类型

### 4.1 特殊节点（固定位置）

| 节点 | 固定位置 | 效果 |
|------|----------|------|
| 村庄 | 地图中心 | 完全回复生命值，并进行各类强化补给 |
| 精英怪 | 地图右上角 | 击败掉落 1 把钥匙 + 强化奖励 |
| 精英怪 | 地图右下角 | 同上 |
| 精英怪 | 中心和右侧节点的中点 | 同上 |
| Boss | 地图最右侧 | 持有 ≥2 把钥匙才能进入（钥匙可通过商人购买）|

> 钥匙数量（精英怪掉落 1 把 / 进入 Boss 需 ≥2 把）为草案值。

### 4.2 常规节点

| 类型 | 占比 | 说明 |
|------|------|------|
| 空白 | 10% | 比较少见 |
| 普通敌袭 | ~40% | 常规战斗，战胜后获得金币 |
| 高危敌袭 | ~12% | 难度高于普通敌袭，掉落更丰富的奖励，较稀有 |
| 普通事件 | | 有概率产生增益、减益或进行交易的事件，不会进入战斗；也可能刷新成商人。所有普通事件中至少包含一个商人，最多两个 |
| 危险事件 | | 选择后必定进入特殊战斗，会产生区别于普通敌袭的效果 |
| 商人 | | 使用战胜敌袭后获得的金币进行交易；地图上仅会刷新 1 个节点（不包含普通事件中出现的）|

> 各类型占比为草案值（空白 10% / 普通敌袭 ~40% / 高危敌袭 ~12%）；普通事件、危险事件占比暂未确定。

## 五、时间点系统

时间点用于计量游戏进程。

### 5.1 时间点的获得

| 来源 | 规则 |
|------|------|
| 战斗 | 每经过 10 个战斗中的回合，获得 1 个时间点（草案值）|
| 移动 | 移动到相邻节点，额外增加时间点进程 3 回合（草案值）|

### 5.2 天

- 每 3 个时间点表示 1 天（草案值）

### 5.3 夜晚休息

- 触发：在战斗、事件结束后，若至少拥有 2 个时间点（草案值），则强制进入夜晚休息阶段
- 可选操作：
  - **回复生命**：按「4 − 时间点进程（回合数）/ 10 − 已拥有时间点」（草案值）的数值等比回复生命值。即每天的时间点进程越低，回复血量越多
  - **其他操作**：消耗剩余的时间点进程进行其他操作

### 5.4 每日 Debuff

- 每天结束都会获得 1 个 Debuff，不存在特例；Debuff 可叠加
- Debuff 在「位于不同格点」时收到，效果与所在格点类型绑定，作用于该类格点的遭遇
- 示例：位于普通敌袭格点收到的 Debuff = 普通敌袭敌人的血量增加（仅针对普通敌袭）
- 覆盖范围随时间推进扩大：
  - 前期：仅覆盖除村庄、精英怪、Boss 之外的格点（普通敌袭、高危敌袭、普通事件、危险事件等）
  - 进行到特定天数后：精英怪、Boss 也进入覆盖范围

## 六、数值说明

- 正文中的节点占比、钥匙数量、时间点换算（战斗 10 回合 = 1 时间点、移动 +3 回合进程、3 时间点 = 1 天）、夜晚回复公式、每日 Debuff 加成等数值均为玩法草案，后续可能调整，以实际实现为准
- 尚未明确的玩法内容（非数值）：普通事件 / 危险事件的占比、夜晚休息可消耗时间点进程进行的「其他操作」具体内容
