# 六边形战场玩法

## 一、适用范围

战斗发生在由正六边形格点紧密排布的战场上。单位位置、攻击距离、攻击影响范围、战场物件和关卡目标共同参与战斗结算。

本玩法更迭保留现有状态系统、Effect 系统、伤害计算、能量、费用、牌堆和卡牌生命周期。空间规则负责确定单位能否成为效果目标，以及移动、物件与关卡目标何时触发；进入既有伤害或状态结算后，继续使用原有规则。

## 二、战场与坐标

### 2.1 格点

- 战场由紧密排布的正六边形格点组成。
- 每个单位具有唯一的当前位置坐标。
- 单位的距离、相邻关系、移动路径与攻击范围均以六边形格点计算。
- 坐标实现推荐使用轴向坐标 `(q, r)`；两点距离统一换算为六边形最短格数。
- 每个格点只能被一个单位占据。
- 除障碍格外，其他格点均为普通格。机关、陷阱与道具均为格上物件，不构成独立格点类型；格点可同时承载单位、物件与地形状态。
- 先由 JSON 塑造基础地形，再按随机生成规则布置道具与障碍物。基础配置指定范围、固定内容与生成限制，随机结果以本场种子复现。
- 随机生成内容的表现资源、外观变体与装饰选择暂只记录需求，本期不实施表现生成。
- 障碍允许形成封闭区域，但任何单位（含玩家、怪物、保护目标与增援）不能生成在其中。生成算法必须排除封闭区域内的单位出生点。
- 格点交互高亮只属于表现层，不改变格点本身的规则。
- 单位不能穿过玩家、怪物、保护目标或其他单位占据的格点。
- 格点分别维护单位占位与物件内容。单位最多一个；多件道具和装备可组成同格物品堆。陷阱、机关各最多一个，彼此互斥，且与物品堆互斥。单位可与物品堆或单个触发物件共存。
- 进入有单位的格点前，必须先通过击退等效果使原单位离开且目的格合法，不能让两个单位同时占用该格。
- 战场尺寸、边界形状与障碍格规则尚未确定，见“待决策项”。

### 2.2 初始部署

- 玩家小队固定为三个出战槽位。
- 战斗开始时，三个玩家单位部署在战场正中心附近三个彼此相邻的格点上。
- 三个初始格点两两相邻，呈三角形排列。例如轴向坐标 `(0,0)`、`(1,0)`、`(0,1)`，三组两点距离均为 1；不得使用连续三格直线排列。
- 三个槽位与三个初始格点应建立稳定映射，避免读档或重新进入战斗后交换位置。
- 怪物在允许部署的格点中随机排布。
- 怪物不得占用玩家初始格点；其他部署间距和安全距离尚未确定。

### 2.3 格点改变与地形状态

- 效果可以对格点造成不自动到期的永久改变，例如摧毁障碍，或摧毁地面形成无法经过的坑洞。“永久”不预设跨战斗保存。
- 单位所在格形成坑洞时，单位立即坠落死亡，不产生掉落物；预留按单位特性判定的例外接口，例如未来飞鸟可以免于坠落，当前不直接实现飞行机制。
- 坠落属于机制杀，非爪牙计入通关击败价值；不产生地面掉落，也不视为“淬炼”的攻击斩杀，不触发其永久升级。
- 地形状态是在持续期限或移除条件满足前，对格点属性产生的改变。例如灼烧地形：位于其上的角色在回合结束时受到伤害。
- 格点上的状态与单位自身状态分别记录；具体触发时序、衰减、叠加、移除、通行判断和配置格式后续详述。
- **攀登项**：未来可能增加格子自然属性，例如高地、草地、森林，与角色属性或卡牌联动；本期仅记录，不引入该属性的实现或数值。

### 2.4 单位位置

- 玩家、普通怪物、爪牙和保护目标等战斗单位均具有位置坐标。
- 单位移动后立即更新坐标。
- 单位死亡立即释放单位占位。部分怪物死后生成阻挡障碍作为后续扩展，先预留死亡后地形改变接口。
- 位置是目标筛选、范围判定、敌方索敌、离场判定、陷阱和机关触发的共同数据来源。

## 三、攻击距离与影响范围

### 3.1 单位攻击距离

- 单位默认攻击只能选取自身相邻格的一个单位，即距离 1 的单格单目标；并非同时攻击六个邻格。
- 攻击距离与影响范围仅由武器和卡牌规则决定，取消独立可成长的单位基础射程设定。未获得武器或卡牌范围改变时使用默认相邻单目标。
- 玩家与怪物使用同一距离计算口径。
- 无武器、双手均为防具或持双手防具时仍允许攻击，使用默认攻击规则及所用卡牌的范围规则。

### 3.2 攻击牌影响范围

- 部分攻击牌具有特殊攻击影响范围。
- 影响范围可以不同于单位基础攻击距离，例如单格、相邻扩散、直线、扇形、环形或指定区域。
- 只有符合空间规则的敌方单位才进入现有伤害、状态和 Effect 结算。
- 范围内存在多个目标时，各目标仍分别使用现有伤害计算和状态处理。
- 卡牌覆盖范围挂钩所选武器的攻击距离，不继承或叠加武器自身的攻击范围形状；具体距离到范围尺寸的映射由卡牌定义。没有武器时用默认距离 1。
- 新版逐卡空间适配见 [六边形战场卡牌设计](../../角色设计/六边形战场卡牌设计.md)。攻击距离与攻击范围分别作为数值衡量指标，空间价值未评定前不得按旧点数直接判定整卡平衡。

### 3.3 敌方攻击意图

- 敌方攻击意图新增攻击距离或攻击影响范围信息。
- 怪物只能攻击符合其当前意图空间条件的目标。
- 怪物意图可以“先移动后攻击”，也可以“先攻击后移动”。
- “先攻击后移动”只有在攻击结算时目标已经位于怪物攻击范围内才会执行；目标不合法时，该意图不能绕过射程直接攻击。
- “先移动后攻击”的寻路、移动后的范围复核，以及攻击目标失效后的处理后续决定。
- 现有易伤、虚弱、反击、嘲讽、护盾和伤害结算规则保持不变；仅在执行前增加空间合法性检查。

### 3.4 丢失目标与离场

- 玩家与怪物距离过远时，怪物可能丢失目标并离开战场。
- 离场的怪物不等同于被击败，不计入击败价值点数。
- 丢失目标规则可以由不同怪物的特性分别配置；距离阈值、持续回合数、寻路尝试和离场方向后续决定。

### 3.5 突进、远程、穿透与爆炸

- 障碍和其他单位可以挡下突进与远程攻击；攻击沿路径检查拦截，不能默认命中遮挡后的选定目标。
- “穿透”词条使上述攻击不被障碍或其他单位挡下。穿透不等于摧毁障碍，也不自动赋予碰撞目标强制位移免疫的突破能力。
- “爆炸”词条使远程攻击实际命中目标附近的单位也受到伤害，爆炸中心跟随实际命中目标，不取被挡住的原定目标坐标。
- 爆炸半径、伤害量、敌我过滤，以及穿透沿途是否逐个命中、穿透与爆炸共同生效时的爆炸次数，仍待定。
- 突进的攻击路径与攻击者本体位置分别处理。穿透攻击不被挡下已经确定，但攻击者是否穿越中间占用格、最终落点在哪里仍需明确，任何结果不能让两个单位同时占格。

### 3.6 突进击退、连锁与回弹

- 突进会击退被命中单位。用 A 表示原攻击者，B 表示被击退单位，C 表示 B 准备进入的格点上的另一单位，方向 d 为攻击推进方向。
- C 可被强制位移：B 继续击退 C，并对 C 造成 B 所受伤害的一半。若继续撞到可位移单位，采用相同连锁规则逐层传播；半伤取值阶段和取整方式待确认。
- C 具有“免疫强制位移”，或前方为障碍：不推动 C/障碍，B 沿攻击反方向回弹至前一格。前一格有此前推动 B 的单位时，B 将其向后击退腾出位置。
- 回弹惩罚施加给 B，表现为弱化或额外伤害，具体效果后续配置；原攻击者 A 不承受此次碰撞/回弹附带的伤害或弱化。回弹造成的位置后移与伤害惩罚分别记录。
- “免疫强制位移”是单位特性，障碍按此类不可推动阻挡处理；不能把碰到任何单位都当撞墙。
- 示例（从左向右攻击）：`A → B → C`。C 可移动时继续向右推 C，C 受半伤；C 不可移动时 B 向左回弹，必要时向左推 A，A 不吃回弹惩罚。
- 连锁中每次实际进入均触发陷阱/机关并处理坑洞；死亡释放格后需重查后续位置。回弹方向再次被堵、原攻击者移动免疫，以及原攻击者被推入有害地形时如何满足“不受任何负面影响”，列入待决策，不能擅自叠放或传送到任意空格。

## 四、移动

- 玩家和部分怪物可以在六边形格点间移动。
- 部分敌方攻击意图会附带移动。
- 单位占据的格点视为路径阻挡，其他单位不能穿过或停留在该格点。
- 移动经过或到达战场物件所在格点时，按物件规则触发。
- 玩家移动消耗能量，并受每回合允许移动次数限制。人物新增“每回合允许移动次数”属性，实际额度同时受装备影响。
- 普通移动在自身回合内串行执行，不新增敌人插入行动、机会攻击或常规移动打断机制。目标位置不可前往时不执行移动，提交前需校验路径、能量和剩余次数。
- 进入陷阱/机关、地面形成坑洞等效果仍正常结算；单位死亡后不能继续移动。这是已确认的死亡与触发规则，不另设通用打断玩法。
- 普通移动一次一格，消耗 1 点能量并计一次移动；只允许选择合法相邻格。
- 装备对每回合移动额度的改变立即生效，已使用次数不因换装重置。剩余次数为 `max(0, 当前有效额度 - 本回合已移动格数)`；换装降低额度到已用次数以下时剩余为 0，不撤销已经完成的移动。
- 普通移动、击退、拉拽、传送均触发进入格点的陷阱和机关。逐格位移按实际进入的格触发；传送触发落点，不虚构中间途经格。

## 五、装备槽位

### 5.1 槽位结构

- 原武器槽替换为左右手两个武器/防具槽位；头盔、护甲、鞋、饰品部位不变。饰品当前最多 3 件，后续数量可能调整。
- 武器与新增的防具共用这两个槽位。
- 单手武器和单手防具各占一个槽位。
- 双手武器和双手防具占用两个槽位，因此只能单独装备一件。

### 5.2 合法组合

| 装备组合 | 是否允许 |
|----------|----------|
| 两件单手武器 | 允许 |
| 两件单手防具 | 允许 |
| 一件单手武器 + 一件单手防具 | 允许 |
| 一件双手武器 | 允许，占满两槽 |
| 一件双手防具 | 允许，占满两槽 |
| 双手装备 + 其他手位装备 | 不允许 |
| 双手装备 + 头盔、护甲、鞋或饰品 | 允许，按各部位原有限制 |

装备提供的攻击距离、防御、卡牌或其他效果仍通过现有属性、状态与 Effect 系统生效。

- 战斗中允许更换装备，换装不消耗能量或移动次数。
- 发动需要武器的攻击时，玩家需要选定使用左手位或右手位的武器。
- 轮流使用左右手的单手武器可以获得增益；增益内容、判定窗口和重置条件后续决定。
- 双手装备同时占据左右手位，使用时不需要选择左右手。
- 换下的装备作为丢弃物优先加入角色所在格的物品堆；已有道具或装备不再构成冲突。存在陷阱/机关等不能接收物品堆的情况时按最近合法接收格安置，见 6.3。
- 地上装备显示在“当前格道具”槽，拾取后必须直接装备到对应武器/防具手位；默认不能收入随身道具槽。预留由装备效果开放“武器放入道具栏”的许可接口，暂不默认启用。
- 重复类型装备效果叠加顺序后续决定。其他装备部位保留原有佩戴规则。

## 六、战场物件

### 6.1 临时道具

- 战场中可以生成仅限本场战斗使用的道具。
- 单位到达道具所在格点后，道具显示在“当前格道具”槽，不自动拾取。
- 当前格道具槽是当前位置内容的展示入口，不是第四个随身槽。离开格点后槽内显示消失，道具仍留在原格；再次返回时，若道具未被拾取、使用或销毁，则重新显示。
- 玩家可从当前格槽直接使用道具，或主动拖入空闲随身槽后携带。使用按道具目标类型选择单位或格点。
- 拾取后的道具归拾取角色单独持有，进入该角色的战斗内临时持有区，可由该角色主动使用。
- 临时道具不能带出战斗，战斗结束后清除。
- 每个角色具有三个临时道具栏位。
- 切换角色时，当前格入口按新位置刷新物品堆，三个随身道具槽按该角色持有物刷新。当前格入口可展开多件道具/装备供逐件操作，随身仍只有三个槽。
- 道具来源包括开局随机生成、角色丢弃或扔出、怪物掉落。多件道具和装备允许混放在同一物品堆，保留各自独立实例，不自动合成或丢弃重复项。
- 使用是否消耗行动以及怪物能否拾取尚未确定。

### 6.2 陷阱与机关

- 陷阱与机关同为格点上的触发物件，均与指定坐标关联，不另设机关格。
- 单位到达对应格点后产生正面或负面效果。
- 具体效果继续通过现有 Effect 与状态系统结算。
- 两者均支持一次性和永久两种触发模式：一次性首次触发后销毁并释放物件占位；永久模式每次进入该格都触发，触发后继续占用物件位置。
- 连续移动经过该格也属于进入；持续站立不会仅因停留而反复触发。回合末地形状态独立结算。
- 陷阱投放基础范围为自身周围一圈，不含自身格；范围可受装备或其他增益改变。只能投放到没有单位、道具、装备、陷阱、机关的合法格点。
- 陷阱投放失败不按掉落规则自动改到附近格点；玩家应选择合法目标。已有陷阱同样占物件位置，不能叠放。
- 机关仅能在战斗开始时生成，战斗过程中不能投放或通过其他方式新增机关。

### 6.3 占位与物件落点

| 内容组合 | 是否允许 |
|----------|----------|
| 单位 + 另一单位 | 不允许；原单位被击退等离开后才能进入 |
| 单位 + 多件道具/装备 | 允许；有符合要求的持有槽位时可以逐件拾取 |
| 单位 + 一个陷阱或机关 | 允许进入并触发效果；一次性销毁，永久保留 |
| 多件道具、装备混放 | 允许，组成物品堆 |
| 陷阱 + 机关、多个陷阱或多个机关 | 不允许 |
| 物品堆 + 陷阱或机关 | 不允许 |
| 向已存在单位的格点投放陷阱 | 不允许，即使物件位置为空 |

- 本次授权确定的共存方案：陷阱/机关为排他的触发物件，物品堆可多件但不与触发物件共存；不设多道具相互挤走的规则。
- 开局生成、丢弃、扔出、怪物掉落和换装卸下的道具/装备，只要目标格可接收物品堆，就直接放入，包括已有道具/装备或单位的格点。
- 目标格有陷阱/机关时，按距离 1、2、3……寻找最近可接收物品堆的格，在同距离候选中随机选择。候选可已有道具或装备，不要求空堆；不得覆盖触发物件。
- 一次性陷阱/机关触发后销毁，原格即可接收物品堆；永久触发物件保留时该格仍不能接收物品堆。投放陷阱依然要求无单位、空物品堆、无陷阱/机关，失败不自动转投。
- 地形状态不参与物件互斥，仍可与单位和合法物件内容共存。障碍/坑洞能否接收物品堆，以及整张图无合法接收格时的处理仍待定。

## 七、关卡目标与结算

### 7.1 歼灭关卡

- 击败所有必须击败的敌人后胜利。
- 标记为“爪牙”的敌人不属于必须击败目标。
- 当所有必杀非爪牙敌人均已被击败或离场时，即使仍有爪牙存活，也满足通关条件；离场敌人仍不计为击败，按比例减少奖励。

### 7.2 生存关卡

- 玩家需要存活到指定回合。
- 期间持续生成新的敌人。
- 完成第 N 回合后，玩家仍满足存活条件时结束战斗并全额获奖；不在第 N 回合开始时提前结束。
- 某回合满足以下彻底清场条件时提前胜利。
- 提前胜利要求彻底清场：当前场上没有任何敌人（包含爪牙），并且没有尚未生成的后续增援。
- 敌人生成时点、生成位置和波次配置尚未确定。

### 7.3 保护目标关卡

- 通关需要同时满足：全部必须击败的敌人已被击败或离场、保护目标单位存活；离场影响奖励比例。
- 保护目标死亡时，本场判定失败。
- 该失败不直接结束整局游戏；本关不获得通关奖励，并在后续流程中产生负面影响。
- 负面影响大概率表现为后续村庄或事件中的可选项变差；具体内容后续决定。

### 7.4 敌人离场与战利品折损

- 怪物因距离过远、丢失目标而离场时，不视为被击败。
- 生存关卡通关后总是获得全额战利品，不进行击败价值比例折损。
- 其他关卡的战利品根据本场实际击败的非爪牙敌人价值点数决定。
- 概念阈值：实际击败价值点数不超过本场敌人总价值点数的 70% 时，卡牌奖励减少一张；低于 50% 时再减少一张。
- 正常卡牌奖励为每个角色一张，共三张。
- 奖励减少时，随机取消一名角色的一张卡牌奖励；需要减少两张时随机取消两个不同角色的奖励。
- 70%、50% 与卡牌损失数量均为待定数值，不作为最终平衡标准。
- 获奖比例不包含爪牙。因距离过远、丢失目标而离场的非爪牙敌人属于未击败部分：计入本场应击败的总价值，但不计入实际击败价值，因此会降低获奖比例。

### 7.5 爪牙

- 敌人可具有“爪牙”标记。
- 爪牙参与普通行动、受击、状态和伤害结算。
- 爪牙不属于默认通关必杀目标。
- 爪牙不计入非生存关卡的战利品价值比例。
- 生存关卡想要提前胜利时，仍存活的爪牙会阻止“彻底清场”成立。
- 爪牙是否随首领死亡离场尚未确定。

## 八、与现有系统的关系

| 现有系统 | 更迭后的职责 |
|----------|--------------|
| 状态系统 | 保持生命周期和触发机制；空间相关状态可通过新增配置扩展 |
| Effect 系统 | 保持效果执行；执行前接收经过空间规则筛选后的目标集合 |
| 伤害计算 | 保持攻击、防御、护盾、易伤、虚弱、暴击等公式 |
| 卡牌系统 | 保持费用、牌堆、关键词和升级；攻击牌增加空间范围数据 |
| 怪物意图 | 保留效果序列；新增射程、范围、移动和目标丢失信息 |
| 关卡结算 | 从固定“全灭敌人”改为按关卡目标判定，并支持价值点数影响奖励 |

## 九、待决策项

1. 战场使用有限六边形、矩形裁切的六边形区域，还是其他边界形状；各关卡的尺寸如何配置。
2. 各人物每回合移动次数的具体基础值及装备修正值；每格 1 能量、计一次、额度立即生效已确定。
3. 卡牌范围尺寸如何由武器攻击距离计算；不引用武器攻击范围。突进/远程默认被单位和障碍挡下，穿透例外已确定。
4. 范围模板的方向如何确定；是否允许旋转；边界格如何截断。
5. “先移动后攻击”的寻路、移动后目标复核和目标失效处理。
6. 各类怪物丢失目标的距离阈值、持续回合数、重新索敌与离场规则。
7. 保护目标死亡后的后续负面选项、持续范围和返回地图流程。
8. 70% 与 50% 奖励边界最终数值以及使用 `<` 还是 `≤`。
9. 战斗内临时道具的使用成本，以及怪物能否拾取或破坏道具。
10. 双持效果叠加，以及轮流使用左右手武器的增益内容和重置条件。
11. 整图没有合法物品堆接收格时的安置方案、障碍/坑洞接收规则；多件道具装备同格已允许。
12. 穿透突进本体落点、沿途命中与穿透爆炸组合；爆炸半径、伤害和敌我过滤。
13. 连锁击退半伤的取值/取整、回弹惩罚、后方再次阻挡和免疫冲突；原攻击者后移遇陷阱/坑洞时的保护优先级。
