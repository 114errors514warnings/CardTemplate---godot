# 六边形战场玩法

## 一、适用范围

战斗发生在由正六边形格点紧密排布的战场上。单位位置、攻击距离、攻击影响范围、战场物件和关卡目标共同参与战斗结算。

本玩法更迭保留现有状态系统、Effect 系统、伤害计算、能量、费用、牌堆和卡牌生命周期。空间规则负责确定单位能否成为效果目标，以及移动、物件与关卡目标何时触发；进入既有伤害或状态结算后，继续使用原有规则。

## 二、战场与坐标

### 2.1 格点

- 战场由紧密排布的正六边形格点组成。
- 每个单位具有唯一的当前位置坐标。
- 单位的距离、相邻关系、移动路径与攻击范围均以六边形格点计算。
- 坐标实现推荐使用轴向坐标 `(q, r)`；两点距离统一换算为六边形最短格数。
- 每个格点只能被一个单位占据。
- 单位不能穿过玩家、怪物、保护目标或其他单位占据的格点。
- 战场尺寸、边界形状与障碍格规则尚未确定，见“待决策项”。

### 2.2 初始部署

- 玩家小队固定为三个出战槽位。
- 战斗开始时，三个玩家单位部署在战场正中心附近三个彼此相邻的格点上。
- 三个槽位与三个初始格点应建立稳定映射，避免读档或重新进入战斗后交换位置。
- 怪物在允许部署的格点中随机排布。
- 怪物不得占用玩家初始格点；其他部署间距和安全距离尚未确定。

### 2.3 单位位置

- 玩家、普通怪物、爪牙和保护目标等战斗单位均具有位置坐标。
- 单位移动后立即更新坐标。
- 位置是目标筛选、范围判定、敌方索敌、离场判定、陷阱和机关触发的共同数据来源。

## 三、攻击距离与影响范围

### 3.1 单位攻击距离

- 所有单位都具有基础攻击距离。
- 基础攻击距离表示单位能够直接选取敌方目标的最远六边形格数。
- 玩家与怪物使用同一距离计算口径。
- 装备、状态和战场物件是否能修改攻击距离，尚未确定。

### 3.2 攻击牌影响范围

- 部分攻击牌具有特殊攻击影响范围。
- 影响范围可以不同于单位基础攻击距离，例如单格、相邻扩散、直线、扇形、环形或指定区域。
- 只有符合空间规则的敌方单位才进入现有伤害、状态和 Effect 结算。
- 范围内存在多个目标时，各目标仍分别使用现有伤害计算和状态处理。
- 卡牌攻击范围会受益于单位基础攻击距离；具体叠加或扩展算法后续决定。

### 3.3 敌方攻击意图

- 敌方攻击意图新增攻击距离或攻击影响范围信息。
- 怪物只能攻击符合其当前意图空间条件的目标。
- 怪物意图可以“先移动后攻击”，也可以“先攻击后移动”。
- “先攻击后移动”只有在攻击结算时目标已经位于怪物攻击范围内才会执行；目标不合法时，该意图不能绕过射程直接攻击。
- “先移动后攻击”的寻路、移动后的范围复核，以及攻击目标失效后的处理后续决定。
- 现有易伤、虚弱、反击、嘲讽、护盾和伤害结算规则保持不变；仅在执行前增加空间合法性检查。

### 3.4 丢失目标与离场

- 玩家与怪物距离过远时，怪物可能丢失目标并离开战场。
- 离场的怪物不等同于被击败，不计入击败价值点数。
- 丢失目标规则可以由不同怪物的特性分别配置；距离阈值、持续回合数、寻路尝试和离场方向后续决定。

## 四、移动

- 玩家和部分怪物可以在六边形格点间移动。
- 部分敌方攻击意图会附带移动。
- 单位占据的格点视为路径阻挡，其他单位不能穿过或停留在该格点。
- 移动经过或到达战场物件所在格点时，按物件规则触发。
- 每回合移动次数、移动距离，以及移动是否消耗能量或独立行动资源尚未确定。

## 五、装备槽位

### 5.1 槽位结构

- 每个角色具有两个通用装备槽位。
- 武器与新增的防具共用这两个槽位。
- 单手武器和单手防具各占一个槽位。
- 双手武器和双手防具占用两个槽位，因此只能单独装备一件。

### 5.2 合法组合

| 装备组合 | 是否允许 |
|----------|----------|
| 两件单手武器 | 允许 |
| 两件单手防具 | 允许 |
| 一件单手武器 + 一件单手防具 | 允许 |
| 一件双手武器 | 允许，占满两槽 |
| 一件双手防具 | 允许，占满两槽 |
| 双手装备 + 任意其他装备 | 不允许 |

装备提供的攻击距离、防御、卡牌或其他效果仍通过现有属性、状态与 Effect 系统生效。

- 战斗中允许更换装备。
- 发动需要武器的攻击时，玩家需要选定使用左手位或右手位的武器。
- 轮流使用左右手的单手武器可以获得增益；增益内容、判定窗口和重置条件后续决定。
- 双手装备同时占据左右手位，使用时不需要选择左右手。
- 重复类型装备的效果叠加顺序以及被替换装备的去向后续决定。

## 六、战场物件

### 6.1 临时道具

- 战场中可以生成仅限本场战斗使用的道具。
- 单位到达道具所在格点后拾取。
- 拾取后的道具归拾取角色单独持有，进入该角色的战斗内临时持有区，可由该角色主动使用。
- 临时道具不能带出战斗，战斗结束后清除。
- 每个角色具有三个临时道具栏位。
- 使用是否消耗行动以及怪物能否拾取尚未确定。

### 6.2 陷阱与机关

- 陷阱或机关占据指定格点。
- 单位到达对应格点后产生正面或负面效果。
- 具体效果继续通过现有 Effect 与状态系统结算。
- 物件是否一次性触发、是否可重复触发、触发后是否消失以及敌我是否都能触发，由物件配置决定；配置结构尚未确定。

## 七、关卡目标与结算

### 7.1 歼灭关卡

- 击败所有必须击败的敌人后胜利。
- 标记为“爪牙”的敌人不属于必须击败目标。
- 当所有非爪牙敌人均被击败时，即使仍有爪牙存活，也满足通关条件。

### 7.2 生存关卡

- 玩家需要存活到指定回合。
- 期间持续生成新的敌人。
- 达到规定回合且玩家仍存活时胜利。
- 若某一回合提前击败全部当前敌人，也立即胜利。
- 提前胜利要求彻底清场：当前场上没有任何敌人（包含爪牙），并且没有尚未生成的后续增援。
- 敌人生成时点、生成位置和波次配置尚未确定。

### 7.3 保护目标关卡

- 通关需要同时满足：击败全部必须击败的敌人、保护目标单位存活。
- 保护目标死亡时，本场判定失败。
- 该失败不直接结束整局游戏；本关不获得通关奖励，并在后续流程中产生负面影响。
- 负面影响大概率表现为后续村庄或事件中的可选项变差；具体内容后续决定。

### 7.4 敌人离场与战利品折损

- 怪物因距离过远、丢失目标而离场时，不视为被击败。
- 生存关卡通关后总是获得全额战利品，不进行击败价值比例折损。
- 其他关卡的战利品根据本场实际击败的非爪牙敌人价值点数决定。
- 概念阈值：实际击败价值点数不超过本场敌人总价值点数的 70% 时，卡牌奖励减少一张；低于 50% 时再减少一张。
- 正常卡牌奖励为每个角色一张，共三张。
- 奖励减少时，随机取消一名角色的一张卡牌奖励；需要减少两张时随机取消两个不同角色的奖励。
- 70%、50% 与卡牌损失数量均为待定数值，不作为最终平衡标准。
- 获奖比例不包含爪牙。因距离过远、丢失目标而离场的非爪牙敌人属于未击败部分：计入本场应击败的总价值，但不计入实际击败价值，因此会降低获奖比例。

### 7.5 爪牙

- 敌人可具有“爪牙”标记。
- 爪牙参与普通行动、受击、状态和伤害结算。
- 爪牙不属于默认通关必杀目标。
- 爪牙不计入非生存关卡的战利品价值比例。
- 生存关卡想要提前胜利时，仍存活的爪牙会阻止“彻底清场”成立。
- 爪牙是否随首领死亡离场尚未确定。

## 八、与现有系统的关系

| 现有系统 | 更迭后的职责 |
|----------|--------------|
| 状态系统 | 保持生命周期和触发机制；空间相关状态可通过新增配置扩展 |
| Effect 系统 | 保持效果执行；执行前接收经过空间规则筛选后的目标集合 |
| 伤害计算 | 保持攻击、防御、护盾、易伤、虚弱、暴击等公式 |
| 卡牌系统 | 保持费用、牌堆、关键词和升级；攻击牌增加空间范围数据 |
| 怪物意图 | 保留效果序列；新增射程、范围、移动和目标丢失信息 |
| 关卡结算 | 从固定“全灭敌人”改为按关卡目标判定，并支持价值点数影响奖励 |

## 九、待决策项

1. 战场使用有限六边形、矩形裁切的六边形区域，还是其他边界形状；各关卡的尺寸如何配置。
2. 玩家移动采用独立移动点、消耗能量、打出移动牌，还是每回合固定移动次数。
3. 卡牌攻击范围如何从单位基础攻击距离获得增益。
4. 范围模板的方向如何确定；是否允许旋转；边界格如何截断。
5. “先移动后攻击”的寻路、移动后目标复核和目标失效处理。
6. 各类怪物丢失目标的距离阈值、持续回合数、重新索敌与离场规则。
7. 保护目标死亡后的后续负面选项、持续范围和返回地图流程。
8. 70% 与 50% 奖励边界最终数值以及使用 `<` 还是 `≤`。
9. 战斗内临时道具的使用成本，以及怪物能否拾取或破坏道具。
10. 被替换装备的去向、双持效果叠加，以及轮流使用左右手武器的增益内容和重置条件。
