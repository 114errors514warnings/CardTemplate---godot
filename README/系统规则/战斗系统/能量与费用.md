# 能量与费用

每个玩家角色拥有独立的当前能量（`costs`）和能量上限（`Max_costs`），能量是出牌的经济门槛。

## 一、字段

| 字段 | 含义 |
|------|------|
| `costs` | 当前剩余能量（int）|
| `Max_costs` | 能量上限（int，默认 3）|

## 二、回合内变化

| 时机 | 行为 | 代码位置 |
|------|------|----------|
| 玩家回合开始 | `costs = Max_costs` | `BattleSytem.cs:1255` |
| 出牌 | `costs -= actualEnergyCost` | `CardPlayController.cs:217` |
| AddCost 效果 | `costs += amount`（受状态修正）| `EffectSystem.ApplyAddCost` |

## 三、实际费用计算（`actualEnergyCost`）

`CardPlayController.PlayHandCard` 入口（line 165-172）：

```csharp
int actualEnergyCost = card.GetCurrentEnergyCost(sourcePlayer);

// 优先级 1：NextBattleCardFree 状态
if (IsBattleCard(card) && StateSystem.TryGetStateStacks(sourcePlayer, StateType.NextBattleCardFree, out int freeStacks) && freeStacks > 0)
{
    actualEnergyCost = 0;
    StateSystem.RemoveState(sourcePlayer, StateType.NextBattleCardFree);
}

// 优先级 2：玩家 costs < actualEnergyCost → 出牌失败
if (sourcePlayer.costs < actualEnergyCost) return false;
```

### 3.1 `Card.GetCurrentEnergyCost(player)` 三段优先级

```csharp
public int GetCurrentEnergyCost(IUnitInstance currentPlayer = null)
{
    // 1. 实例级 EnergyCostOverride
    if (EnergyCostOverride != null && currentPlayer != null)
        return EnergyCostOverride.Invoke(currentPlayer);
    // 2. 按 CardId 注册的静态工厂
    if (currentPlayer != null && CostOverrideFactories.TryGetValue(CardId, out var factory))
        return factory.Invoke(currentPlayer);
    // 3. 回退 EnergyCost
    return EnergyCost;
}
```

#### 死亡之舞示例

`Card.RegisterCostOverrideFactory(11002010, p => Math.Max(0, 3 - loseHpTimes))` 注册死亡之舞工厂，实时算"3 - 本局失去生命次数"。

**新增 2026-08**：通用动态费用机制，原先只支持固定 `EnergyCost`。

## 四、能量上限调整

- 默认 `Max_costs = 3`（角色初始化时）
- 可通过 `SetPlayerMaxEnergy` 指令修改
- `AddCost` 效果只加 `costs`（当前能量），不超 `Max_costs`

## 五、UI 显示

- 战斗场景手牌区左侧显示当前操控角色的能量：`当前/上限`（如 `1/3`）
- 切换操控角色或打出卡牌后，能量显示同步刷新
- `CardBattleScene` 中 `EnergyLabel.Text = "{player.costs}/{player.Max_costs}"`
