# 战斗循环

战斗采用「玩家回合 / 怪物回合」交替循环，直到胜负判定。

## 一、回合结构总览

```
┌── 玩家回合 ──┐    ┌── 怪物回合 ──┐
│              │    │              │
│ 1. 所有存活   │    │ 1. 所有存活   │
│    玩家同时   │    │    怪物依次   │
│    开始       │    │    开始       │
│ 2. 状态结算   │    │ 2. 状态结算   │
│ 3. 护盾清零   │    │ 3. 护盾清零   │
│ 4. 抽牌       │    │ 4. 执行已选   │
│ 5. 能量重置   │    │    意图       │
│ 6. 出牌(共享  │ ── │ 5. 重新选意图 │
│    行动窗口)  │    │              │
│ 7. 结束回合   │    │              │
│ 8. 弃非保留牌 │    │              │
└──────────────┘    └──────────────┘
        ▲                   │
        └───────────────────┘
```

## 二、玩家回合开始

按顺序对每个存活玩家：

1. **状态结算** — `StateSystem.OnTurnStart(player)`
   - 衰减每个状态的 stacks（`TurnStartDecayAmount`）
   - 处理 `TurnStartEffect`（给能量 / 护盾）
   - 处理 `ShieldGuard`（给护盾）
   - 处理 `ShieldCapEqualsHP`（cap 护盾到 HP；**新：拥有此状态时不清零**，由 `BattleSytem.cs:1247` 判定）
2. **护盾清零** — 默认行为（`BattleSytem.cs:1247`），但有 `ShieldCapEqualsHP` 状态时**保留护盾并 cap 到 currentHP**
3. **抽牌** — `drawCardNum` 张（默认 5）
4. **能量重置** — `costs = Max_costs`（默认 3）

## 三、玩家回合进行中

- **共享行动窗口** — 不区分"角色A回合""角色B回合"
- 可在同回合内自由切换角色出牌：A 出牌 → B 出牌 → A 再出牌
- 仍处玩家回合且角色满足费用、目标等条件时，可继续出牌
- 状态卡可在回合外（怪物回合）触发（如反击）

## 四、玩家回合结束

按顺序对每个存活玩家：

1. **弃置** — 不带 `Retain` 关键词的手牌进入各自弃牌堆
2. **保留** — 带 `Retain` 的手牌留在手中（如盾牌冲撞）

## 五、怪物回合

按顺序对每个存活怪物：

1. **状态结算** — `StateSystem.OnTurnStart(monster)`（同玩家）
2. **护盾清零** — 同玩家规则（带 `ShieldCapEqualsHP` 状态时保留）
3. **执行已选意图** — `MonsterIntentionService.ExecuteMonsterIntention(monster)` 依次执行 `SelectedIntention` 中的 Effect

若怪物没有已选意图（`SelectedIntention.Length == 0`），先 `SelectIntentionForMonster` 随机选一条。

## 六、回合切换

- 怪物回合结束后，为所有存活怪物重新选择下一轮意图
- 检查胜负判定
- 重新进入玩家回合

## 七、胜负判定

`BattleSytem.CheckBattleEndAndHandle`：

- 所有怪物死亡 → **战斗胜利**
- 所有玩家死亡 → **战斗失败**
- 单个玩家死亡不会立刻结束战斗，只要有至少 1 名玩家存活，战斗继续

## 八、状态衰减时机

**回合开始**处理衰减（`StateSystem.OnTurnStart`），不是回合结束。

衰减规则详见 [状态系统](状态系统.md) §1.1。
