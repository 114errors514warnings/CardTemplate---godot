# 目标规则

战斗中的所有"对谁"问题由 `EffectTargetType` + 怪物意图的目标模式共同解决。

## 一、EffectTargetType（卡牌出牌）

`Params[i][0]` 固定为目标类型，详见 [Effect 系统](Effect系统.md) §2。简表：

| 值 | 枚举名 | 行为 |
|----|--------|------|
| 0 | Auto | 有选中目标用选中目标，否则自身 |
| 1 | Self | 自身 |
| 2 | SelectedTarget | 玩家选定的目标（卡牌标记 `NeedTarget=true`）|
| 3 | AllEnemies | 全体敌人（玩家出牌=所有怪物；怪物出牌=所有玩家）|
| 4 | AllUnits | 场上所有单位 |
| 5 | AllAllies | 全体友方（不含自身）|

### 1.1 `NeedTarget` 自动推导

无需手动配置：
- 任意效果的目标类型为 `SelectedTarget(2)` 时，该卡牌自动被系统视为"需要目标"
- UI 调试出牌时若卡牌需要目标但未传入目标，出牌失败

### 1.2 `AllEnemies` 方向

- 玩家作为来源 → 目标是**所有存活怪物**
- 怪物作为来源 → 目标是**所有存活玩家**

## 二、怪物攻击目标

> 以下 `MonsterIntentionService` 的随机目标规则仅适用于旧版战斗场景。六边形战场改由 `EnemyIntent.csv` 的 `TargetPolicy` 和空间攻击规格决定目标；测试关已覆盖最近、同线最近、低生命和最密集落点策略。

六边形战场的智能索敌、保护目标优先级、投掷范围密集目标选择、投掷单体最低生命选择及突刺同线最近目标选择，见 [六边形战场玩法](六边形战场玩法.md#341-智能索敌优先级)。旧版随机目标模式仅适用于未迁移的旧战斗场景。

`MonsterIntentionService.ResolveRandomAlivePlayerTarget` 解析顺序：

```
1. 拥有 ForcedTaunt 状态 且 Shield > 0 的玩家 → 随机选一个
2. 否则 → 所有存活玩家中随机选
```

> **城墙**（`ForcedTaunt`）要求持有者 `Shield > 0` 才生效（`MonsterIntentionService.cs:478`）。
> 多人同时拥有时**随机**选一个（与"单高优先级目标"一致）。

### 2.1 怪物 Damage 目标模式

详见 [Effect 系统](Effect系统.md) §4.1。`MonsterDamageTargetMode`：

| 模式 | 含义 |
|------|------|
| `RandomPerHit=1` | 每次 Damage 各自随机选目标 |
| `RandomSameTargetWithinIntention=2` | 同条意图内多次 Damage 共享同一随机目标 |

### 2.2 怪物 AddState 目标

格式 `3;EffectTargetType;stateType;stacks`（见 [Effect 系统](Effect系统.md) §4.2）。其中 `SelectedTarget` 解析为"本次意图中最近一次 Damage 命中的目标"。

## 三、城墙（ForcedTaunt）目标重定向

玩家打出「到我身后」`21002012,RearrangeMonsterTargets` 时：

1. 遍历所有存活怪物
2. 仅处理 `SelectedIntention` 含 Damage 段的怪物（单攻类）
3. 把这些怪物的 `SelectedIntentionTargetUniqueInGameId` 设为**施法者**
4. **仅在改目标时**计数：原本目标不是施法者的怪物才算"改"
5. 防御 N 次（N = 被改目标的怪物数）

`Card.ApplyRearrangeMonsterTargetsEffect` 实现位于 `Card.cs:861`（**新增 2026-08**）。

## 五、六边形道具目标选择(2026-09-09)

- 目标型道具按空间形状选择格点：单体(落点格)、远程直线(6 方向射线)、扇形、环形(含菱形近似)。
- 石头等远程直线道具的候选格只取 6 条方向直线上的格子，到第一个单位/障碍即停；不再把整圈射程六边形作为可选范围。
- 对“空格/无敌人”也能使用：目标格只需在射程内即可成功“打出”。远程直线只命中方向上的第一个单位或障碍（穿透例外）；近战直线和突刺的不同停止规则见 [六边形战场玩法](六边形战场玩法.md#直线攻击拦截规则)。
- 从当前格道具面板或随身槽拖出道具即可进入使用流程;拖到随身槽则移动/交换,拖回当前格道具面板则放回地面。
