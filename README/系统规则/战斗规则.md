## 数值取整规则

- 游戏中所有涉及数字计算后出现小数的情况，统一向下取整。
- 如果计算过程中出现负数小数，则先对其绝对值进行向下取整，再恢复原符号。

示例：

- `4.9 -> 4`
- `7.5 -> 7`
- `-1.2 -> -1`
- `-2.8 -> -2`

## 回合流程

当前战斗采用“玩家回合 / 怪物回合”交替循环。

### 1. 玩家回合开始

- 所有存活玩家同时开始回合。
- 对每个存活玩家依次执行：
	- 触发回合开始状态结算。
	- 当前护盾清零。
	- 按各自 `drawCardNum` 抽牌。
	- 当前能量重置为各自的 `Max_costs`。

### 2. 玩家回合进行中

- 玩家回合是共享行动窗口，不区分“角色A回合”“角色B回合”。
- 可在同一个玩家回合内自由切换操控角色出牌。
- 允许出现如下顺序：角色A出牌 -> 角色B出牌 -> 角色A再次出牌。
- 只要仍处于玩家回合，且对应角色满足费用、目标等条件，就可以继续出牌。

### 3. 玩家回合结束

- 点击结束回合后，所有存活玩家同时结束本回合。
- 对每个存活玩家：
	- 弃置所有不带“保留”关键词的手牌。
	- 带“保留”关键词的手牌留在手中。

### 4. 怪物回合

- 所有存活怪物依次开始回合。
- 对每个存活怪物依次执行：
	- 触发回合开始状态结算。
	- 当前护盾清零。
	- 执行其已选定的意图。
- 当前实现下，怪物若需要攻击目标，会从所有存活玩家中选择一名有效目标。

### 5. 回合切换

- 怪物回合结束后，会重新为所有存活怪物选择下一轮意图。
- 随后重新进入玩家回合。

## 胜负判定

- 所有怪物死亡：战斗胜利。
- 所有玩家死亡：战斗失败。
- 单个玩家死亡不会立刻结束战斗，只要仍有至少一名玩家存活，战斗继续。

## 目标规则

- 玩家打牌时，目标由卡牌参数中的 `EffectTargetType` 决定。
- 怪物攻击时，目标从当前所有存活玩家中选取。
- `AllEnemies` 在玩家作为来源时，目标是所有存活怪物；在怪物作为来源时，目标是所有存活玩家。
- `AllUnits` 的目标是场上所有存活单位。

## 状态与回合外判定

- 状态衰减在回合开始时处理，而不是回合结束时处理。
- `CounterAttack`、`WhirlwindSlash` 等“回合外”相关效果，以当前是否处于玩家回合来判断：
	- 玩家在怪物回合中行动，视为回合外。
	- 怪物在玩家回合中行动，视为回合外。

## 手牌、抽牌堆、弃牌堆规则

- 每个玩家拥有各自独立的手牌、抽牌堆、弃牌堆、状态牌堆与能量。
- 抽牌堆为空时，会将该玩家自己的弃牌堆洗回抽牌堆。
- 对局信息中的抽牌堆与弃牌堆详情，按角色分别显示。

## 能量（费用）机制

- 每个玩家角色拥有独立的当前能量（`costs`）和能量上限（`Max_costs`）。
- 能量上限默认为 3，可通过 `SetPlayerMaxEnergy` 指令修改。
- 玩家回合开始时，当前能量自动重置为能量上限。
- 打出手牌时，消耗等于该卡牌 `EnergyCost` 的费用；费用不足则无法打出。
- 战斗场景手牌区左侧显示当前操控角色的能量值，格式为"当前费用/上限"（例如 `1/3`）。
- 切换操控角色或打出卡牌后，能量显示同步刷新。
