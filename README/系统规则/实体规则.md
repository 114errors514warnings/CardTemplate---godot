# 实体唯一标识规则

## 1. 适用范围
- 人物实例（CharacterInstance）
- 怪物实例（MonsterInstance）
- 卡牌实例（Card）

## 2. UniqueID 格式
- 统一使用 7 位数字字符串/数字。
- 第 1 位为类型前缀，后 6 位为流水号（000001-999999）。

## 3. 前缀约定
- 人物实例：`0xxxxxx`
- 怪物实例：`1xxxxxx`
- 卡牌实例：`3xxxxxx`

## 4. 生成规则
- 通过 `UniqueIdGenerator` 统一生成：
	- `NextCharacterId()` 生成人物实例ID。
	- `NextMonsterId()` 生成怪物实例ID。
	- `NextCardId()` 生成卡牌实例ID。
- 当流水号超过 999999 时，按 1 重新循环。

## 5. 代码落点
- `IUnitInstance` 包含 `UniqueId` 字段。
- `CharacterInstance` 在构造时自动赋值 `UniqueId`。
- `MonsterInstance` 在构造时自动赋值 `UniqueId`。
- `BattleSytem.AddCardToPlayer` 创建卡牌实例时写入 7 位卡牌ID。
