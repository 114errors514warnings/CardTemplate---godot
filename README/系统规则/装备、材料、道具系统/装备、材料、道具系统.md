# 装备、材料、道具系统

> 战斗外的养成产出：战斗获得材料 → 合成道具 / 打造装备 → 强化战斗表现。

## 一、材料

### 1.1 来源

- 各种战斗中获得，种类多样

### 1.2 分类

| 类别 | 用途 |
|------|------|
| 合成材料 | 用于合成各种道具 |
| 打造材料 | 用于制作装备 |

- 部分材料不存在严格的界限：既可以用于合成道具，也可以经过加工后用于打造装备

## 二、道具

### 2.1 构成

- 各种药剂与新奇的小玩意

### 2.2 特性

- 消耗品
- 使用后获得战斗内或持续时间内的增益

### 2.3 获取：仅可通过合成台制作

- 村庄拥有合成台
- 一天结束时，也可直接通过配方消耗对应材料搭建合成台，并消耗时间点进程合成道具（与时间点系统联动）

## 三、装备

### 3.1 部位（5 种）

| 部位 | 武器 | 头盔 | 护甲 | 鞋 | 饰品 |
|------|------|------|------|-----|------|
| 佩戴限制 | 1 件 | 1 件 | 1 件 | 1 件 | 最多 3 件 |

- 每个角色最多佩戴 3 件饰品，其余部位仅允许佩戴 1 件
- 效果：为角色提供持续的增益

### 3.2 获取：仅可通过锻造台制造

- 村庄存在锻造台
- 商人处可花费金币使用锻造台

## 四、与其他系统的联动

| 系统 | 联动点 |
|------|--------|
| 战斗 | 各种战斗产出材料 |
| 地图玩法 · 村庄（中心节点）| 拥有合成台与锻造台 |
| 地图玩法 · 商人 | 可花费金币使用锻造台 |
| 时间点系统 · 夜晚休息 | 一天结束时可用配方搭建合成台，消耗时间点进程合成道具 |

## 五、后续补充（非数值玩法缺口）

- 材料的具体种类与产出途径
- 道具清单、配方、增益效果
- 装备属性、稀有度 / 品质、锻造配方
- 材料「加工」的具体流程
