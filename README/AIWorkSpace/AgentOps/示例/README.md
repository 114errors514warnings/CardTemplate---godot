# 示例 — 规范文档的参考样板

> 本目录存放按 [文档编写规则.md](../文档编写规则.md) 写出的**完整文档示例**。新写文档前先看本目录里的样板，结构 / 风格 / 内容密度对齐。
>
> `AIWorkSpace/` 整体**仅**含 AI 规范 + 示例，**不**含任何具体执行案。本目录下的示例用于**对照规范**——具体执行案应放在 `README/施工文档/<年>/<年.月>/` 下。

## 目录

| 文件 | 用途 |
|------|------|
| [8月施工文档.md](8月施工文档.md) | 月度施工文档的标准模板：3 大部分结构（需求 / 执行 / 测试）+ 后续建议，无自言自语、无估时。`README/施工文档/2026/2026.08/8月施工文档.md` 的完整副本，作为样板。 |

## 使用方式

- **新写月度施工文档**前 → 复制本目录的 `8月施工文档.md`，按当月实际情况替换 1.x / 2.x / 3.x 内容
- **改施工文档**前 → 对照本目录样板，确保符合 4 大规则（不自言自语 / 不估时 / 3 大部分结构 / 严格按需求文档）
- **新写扩展方向打磨说明**前 → 参考 [战斗系统打磨说明.md](../../../../施工文档/2026/2026.08/战斗系统打磨说明.md) 的 P0/P1/P2 优先级 + 工作量估时（这是扩展方向文档，不是施工文档，估时保留）
