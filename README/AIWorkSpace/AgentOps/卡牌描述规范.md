# 卡牌描述规范

> 来源：用户 2026-08-30 明确指示（重剑手卡牌描述审查时确立：发现 30 张卡牌中 19 张 DataBase 描述与 `README/角色设计/卡牌表格/` 不一致）

## 核心规则

**所有卡牌的效果描述（`DataBase/Card/**/*.csv` 的 EffectDescription 列、卡牌 UI 文本、状态牌区显示）以对应角色在 `README/角色设计/卡牌表格/` 下各角色 `.csv` 文件的"效果"列原文为准，不允许擅自修改。**

## 权威源

| 用途 | 权威源 |
|------|--------|
| 卡牌描述（玩家面向文案）| `README/角色设计/卡牌表格/角色.csv` 的"效果"列 |
| 卡牌类型 / 费用 / 关键词 / 等级 | 同上"类型/费用/关键词/等级"列 |
| 状态名 / 状态描述（chip / tooltip）| `Scripts/System/StateMetadata.cs`（21 case 编译期静态，详见 §状态名 / 状态描述）|
| 状态牌区描述 | 角色 csv 描述列（即本规范权威源）|

## DataBase 与卡牌表格的对应关系

| 角色 | DataBase 卡牌 csv | 卡牌表格 |
|------|-------------------|----------|
| 重剑手 | `DataBase/Card/重剑手Card.csv` | `README/角色设计/卡牌表格/重剑手.csv` |
| 法师 | `DataBase/Card/法师Card.csv`（如存在）| `README/角色设计/卡牌表格/法师.csv` |
| 精灵 | `DataBase/Card/精灵Card.csv`（如存在）| `README/角色设计/卡牌表格/精灵.csv` |
| 通用 | `DataBase/Card/通用/通用Card.csv` | `README/角色设计/卡牌表格/通用卡牌.csv` |

**CardName 字段**（`DataBase/Card/*.csv` 第 2 列）必须**与**卡牌表格"卡牌名"列**完全一致**（包括标点、字间距），用于校验对照。

## 同步流程

1. **新建/修改卡牌描述时**：
   - 先在 `README/角色设计/卡牌表格/角色.csv` 写一行原文（含"效果"列）
   - 再在 `DataBase/Card/角色Card.csv` 添加/修改 EffectDescription（**照搬**卡牌表格原文）
   - **绝不**在 DataBase 直接写描述而不更新卡牌表格

2. **审查时发现 DataBase 与卡牌表格不一致**：
   - 列出所有不一致项（按严重程度分组：语义不同 vs 标点/语气不同）
   - 报告给用户
   - **修复方向**：以卡牌表格"效果"列原文**覆盖** DataBase EffectDescription（卡牌表格是权威源，DataBase 是镜像）
   - **修复前必须**获得用户明确授权

3. **翻译文件**（`.en.translation` / `.效果.translation` 等）：按源 csv 同步，不在源 csv 添加原文不存在的内容

## 状态名 / 状态描述（不依赖卡牌表格）

状态 chip 和 tooltip 的中文名/描述**不**走卡牌表格，而是走 `Scripts/System/StateMetadata.cs` 静态类（21 case 编译期固定，0 缓存）。详见：

| 显示位置 | 数据来源 |
|----------|----------|
| 状态 chip 名字 | `StateMetadata.Name(StateType)` |
| 状态 chip tooltip 描述 | `StateMetadata.Description(StateType)` |
| 状态牌区描述（卡牌 UI）| 卡牌表格"效果"列（即状态牌卡牌的描述）|

**重要区分**：
- 状态名 / 描述 = C# 枚举层（`StateMetadata`），**不**依赖 `DataBase/State/通用State.csv` 的 Name / EffectDescription 字段
- 状态牌描述 = 角色 csv "效果"列（如重剑手.csv line 27 "旋风斩"卡牌描述"你回合外的攻击会作用于所有敌人"）

## 允许的操作

| 操作 | 是否允许 | 说明 |
|------|----------|------|
| 照搬卡牌表格"效果"列原文到 DataBase EffectDescription | ✅ | 标准流程 |
| 在卡牌表格"备注"列写补充说明 | ✅ | 不影响 DataBase |
| 推断卡牌描述（无卡牌表格原文时）| ❌ | 必须先在卡牌表格加原文 |
| 自创卡牌效果描述 | ❌ | 必须先在卡牌表格加原文 |
| 修改卡牌表格"效果"列 | ⚠️ | 仅用户明确指示时 |

## 已纠正的反模式

- ❌ 在 DataBase EffectDescription 写"攻击，攻击前解除自身的一个普通弱化**状态**"（卡牌表格原文是"效果"）—— 标点/用词差异
- ❌ 在 DataBase EffectDescription 写"对目标施加反击触发"（卡牌表格原文是"对敌人施加状态，当其对你造成战斗伤害时，进行反击"）—— 语义简化
- ❌ 在 DataBase EffectDescription 自行合并"效果 + 关键词 + 备注"（如绝力一击的"+10攻击"来自备注列，不是"效果"列）
- ❌ 在 DataBase EffectDescription 自行添加卡牌表格"效果"列没有的语义（如城墙描述多加"回合开始时护盾不清零，cap=HP"）
- ❌ 简化卡牌表格原文（如统一战线"所有友方下张战斗牌免费" → 卡牌表格"所有友方单位本回合的下一张战斗牌可免费打出"）

## 修复示例（重剑手，2026-08-30 审查发现 19/30 张不一致）

| 修复方向 | 说明 |
|----------|------|
| 11002001 盾牌冲撞 | DataBase "造成攻击力+护盾值的伤害" → 卡牌表格原文"额外造成你护盾点数的伤害" |
| 11002009 紧咬不放 | DataBase "对目标施加反击触发" → 卡牌表格原文"对敌人施加状态，当其对你造成战斗伤害时，进行反击" |
| 31002007 城墙 | DataBase 删去"回合开始时护盾不清零，cap=HP"（卡牌表格无此内容），还原为"当你拥有护盾时，敌人的单体攻击仅会以你为目标（若多人拥有该状态，则目标为其中的随机一人）" |
| ... | （其他 16 项同上方向）|

**修复前必须逐条由用户审核**——尤其当卡牌表格的"效果"列为空时（如绝力一击），需用户明确指定如何处理。
