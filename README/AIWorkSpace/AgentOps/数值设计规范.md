# 数值设计规范

> 卡牌数值评定的统一规则（怎么做）。具体数值标准见「数值平衡标准」
> （README/系统规则/数值平衡/数值平衡标准.md）。

## 一、核心原则

1. **锚点**：1 点伤害 = 1 点数。
2. **价值必须是固定的数字**：禁止 `2×费用`、`3/人`、`×N` 等依赖未知 / 可变数量的表述。
3. **只由本卡效果决定**：卡牌价值由本卡效果 + 显式环境假设决定，与被作用的未来对象（下一张牌、友军数量）无关。
4. **群体效果取固定值**：全体友军 / 全体敌人效果 = 单个标准单位的价值（固定数字），不随受益人数缩放。
5. **延迟效果按折扣计算**：下回合才生效的效果按折扣计算，折扣规则见「数值平衡标准」§三。
6. **未评定行为不估值**：依赖未知信息、无法给出明确逻辑的行为 → 列入「数值平衡标准」§五未评定行为清单，不得估值。

## 二、卡牌价值与费用、等级的关系

- 公式：**卡牌应有点数 = 费用点数基准 × 等级系数**
- 费用基准 / 等级系数 / 应有点数速查表 / 校验规则 → 见「数值平衡标准」§四
