# 数值设计规范

> 数值平衡评定的统一规则（怎么做）。具体数值标准见 README/系统规则/数值平衡/
> （卡牌数值平衡标准.md、单位数值平衡标准.md）。

## 一、核心原则

1. **锚点**：1 点伤害 = 1 点数。
2. **价值必须是固定的数字**：禁止 `2×费用`、`3/人`、`×N` 等依赖未知 / 可变数量的表述。
3. **只由本卡效果决定**：卡牌价值由本卡效果 + 显式环境假设决定，与被作用的未来对象（下一张牌、友军数量）无关。
4. **群体效果取固定值**：基础伤害、护盾等按单个标准单位计值，不随受益人数缩放。六边形战场的射程与范围收益独立评定，不按实际人数或最大覆盖格数重复乘算；未评定不代表收益为零。
5. **延迟效果按折扣计算**：下回合才生效的效果按折扣计算，折扣规则见「卡牌数值平衡标准」§三。
6. **未评定行为不估值**：依赖未知信息、无法给出明确逻辑的行为 → 列入「卡牌数值平衡标准」§五未评定行为清单，不得估值。
7. **空间指标必填**：新版卡牌记录攻击距离规则、范围形状与尺寸、起点与方向、目标类型及空间限制。无空间作用填写“不适用”；未定规则填写“待定”，不能留空。
8. **部分评定不作整卡结论**：含未评定射程、范围或地形收益的卡牌，只展示已评定部分与缺项，不得直接宣布平衡。定值须先明确移动成本、基准射程和典型敌人密度等环境假设。

## 二、卡牌价值与费用、等级的关系

- 公式：**卡牌应有点数 = 费用点数基准 × 等级系数**
- 费用基准 / 等级系数 / 应有点数速查表 / 校验规则 → 见「卡牌数值平衡标准」§四
