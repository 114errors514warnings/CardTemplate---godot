# 内容创作规范

> AI Agent 后续构思游戏内容（角色 / 卡牌 / 怪物 / 材料 / 道具 / 装备 / 事件 / 文本等）时必须遵守的世界观约束。

## 一、背景风格

- 游戏背景为「西欧中世纪风魔法幻想世界」
- 创作的内容应当严格遵守该风格
- 避免出现明显脱离该风格的设定、用语或意象

## 二、地区划分

- 游戏有三大主要地区：符文之地、森林、王城
- 创作内容尽可能划清其所属的地区，并结合该地区特色
- 涉及地区的设定需明确归属地区，不混淆
