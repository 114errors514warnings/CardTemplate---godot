# 内容创作规范

> AI Agent 后续构思游戏内容（角色 / 卡牌 / 怪物 / 材料 / 道具 / 装备 / 事件 / 文本等）时必须遵守的世界观约束。

## 一、背景风格

- 游戏背景为「西欧中世纪风魔法幻想世界」
- 创作的内容应当严格遵守该风格
- 避免出现明显脱离该风格的设定、用语或意象

## 二、地区划分

- 游戏有三大主要地区：符文之地、森林、王城
- 创作内容尽可能划清其所属的地区，并结合该地区特色
- 涉及地区的设定需明确归属地区，不混淆

## 三、创作阶段与配置阶段（2026-10-01 规范）

- **构思 / 设计阶段只出说明文档，不生成配置文件**（关卡、怪物、地图、掉落、意图同理）。数值可以写、但按草案标注「需实配时校准」。
- **只有用户明确要求「配表 / 落地 / 写进配置」时才动 `DataBase/**`**。
- 完整规则（含判据与禁止清单）见 [工作守则.md](工作守则.md) §十；关卡设计侧的口径见 [关卡设计 README](../../玩法说明文档/关卡设计/README.md)「两阶段工作流」。
