| [问题分析与解决规范.md](问题分析与解决规范.md) | 查证 / 修复 / 记录引用规范；改文件前建回滚点、改后抽查 diff |

## 适用

- 任何 AI Agent 维护本项目代码 / 配置 / 文档前
- 包括但不限于：施工文档、C# 代码、`.tscn` 场景、CSV 配置、xUnit 测试、Godot 工程

## 不适用

- 项目内普通开发者（非 AI 协作）的贡献流程
- CI / 自动化脚本（但里面的硬安全策略仍然生效）
