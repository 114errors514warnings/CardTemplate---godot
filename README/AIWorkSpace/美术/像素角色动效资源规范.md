# 重剑手像素角色动效包（首版）

## 目标

测试场景以同一张角色动作表作为人物母版。剑、盾、弓与法器使用独立装备贴图；当前动作表的双手剑已画入原图。正式生产目标是 `48×64 px` 逻辑尺寸与逐帧手部锚点，当前生成图集尚未达到该交付规格。

## 已接入的测试资源

- `Resources/Images/Characters/Pixel/swordmaster_pixel_action_sheet.png`：双手剑模式的人物与动作母版；从左到右为待机 A、待机 B、行走接触、行走经过、双手蓄力、双手挥击、受击/倒地。
- `Resources/Images/Characters/Pixel/swordmaster_pixel_action_equipment_sheet.png`：从同一母版去除原剑后的装备组合版本；保留其余人物像素，用于空手、单手剑、盾、剑盾、双剑、弓、法器。
- `Resources/Images/Characters/Pixel/equipment_*.png`：独立装备图。测试场景已从旧根目录 `Images/` 改为 `Resources/Images/` 加载。
- `Scenes/Debug/AnimationMaterialTestScene.tscn`：可从主菜单“动画素材测试”进入。

## 动画状态机

| 状态 | 目标帧 | 时长/循环 | 触发 |
|---|---|---|---|
| Idle | 0, 1 | 1.5 fps 循环 | 无输入、动作结束、装备切换 |
| Move | 2, 3 | 8 fps 循环 | 格间移动 |
| Attack | 4, 5, 0 | 9 fps，不循环 | 攻击结算 |
| Hurt | 6, 0 | 8 fps，不循环 | 受击 |
| Death | 6 | 停留；人物下沉约 7 像素 | HP 归零 |

攻击只播放 4、5、0 帧，不旋转整个人物节点。每次装备切换从待机第 0 帧重新开始；所有装备状态均循环播放 0、1 帧。

## 装备层和锚点

当前测试实现使用独立 `Sprite2D` 挂载装备，并根据攻击帧调整贴图位置。尚未制作真正的骨骼与前后手臂分层。正式导出中，以下资源应独立于身体帧：`arm_front`、`arm_back`、`weapon_*`、`shield_*`、`cape`。

每帧 `attachments.json` 至少记录：

```json
{
  "frame": "attack_01",
  "hand_left": [17, 31],
  "hand_right": [27, 27],
  "weapon_layer": "front"
}
```

单手剑、盾、剑盾、双剑使用左右手独立锚点。大剑、战斧、长枪、双手锤共享同一套 `two_hand_idle / two_hand_attack` 双臂帧，只替换武器图和锚点偏移；弓箭、法典分别允许独立姿势。
