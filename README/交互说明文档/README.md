# 交互说明文档

记录玩家如何点击、拖拽、悬停、取消和确认操作，以及界面在各输入状态下的反馈。

> 只收录**已实现**的交互，并随开发实时更新；尚未实现的设计案放在 `README/施工文档/2026/<年.月>/交互/`。
> **已实现的交互案随实现迁入本区**：去掉文件名里的「案」、改用说明语气；本区已有同类文档时**合并进既有文档**，不另开重复文件。施工文档侧只保留完成情况与迁出对照表（见[施工文档索引](../施工文档/README.md)「已迁出」表），规则见[文档编写规则 §九](../AIWorkSpace/AgentOps/文档编写规则.md)。
