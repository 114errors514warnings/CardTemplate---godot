# 篝火休息交互概念案

> 本文为营地休息的概念交互案。饱食度、回复、守夜和夜袭规则以[篝火休息与食物](../../玩法说明文档/系统规则/营地系统/篝火休息与食物.md)为准。

## 营地基础画面

- 画面表现为三名角色围绕火堆。
- 不显示全屏或底部 UI 底板。
- 仅常驻四个独立按钮：添加食物、烹饪、守夜、休息。
- 营地期间地图、战斗和原背包界面不接受输入。

## 添加食物

点击后进入食物分配状态：

```text
左侧
├─ 上：本次篝火的饱食度进度条
└─ 下：已添加食物的格状列表

右侧
└─ 当前局背包中的食物格状列表
```

- 左右两侧格中的食物可自由拖动。
- 从背包拖到篝火列表时，预览本次休息的饱食度与食物效果。
- 从篝火列表拖回背包时，撤销对应预览。
- 点击“休息”前，食物只存在于本次营地草稿，不正式消耗。
- 点击“休息”后，篝火列表中的食物统一消耗并按玩法规则结算。

## 烹饪

- 当前仅保留入口和交互状态，不定义配方界面。
- 点击后显示烹饪入口；食材、配方、产物、火堆占用和时间消耗后续另行定义。
- 烹饪完成后的食物应进入右侧背包或左侧篝火草稿，具体归属后续确认。

## 守夜

- 当前仅保留守夜方式选择入口。
- 后续选择不守夜、轮流守夜或单人守夜，并在 UI 中显示对应生命回复、夜袭和睡眠不佳影响。
- 守夜选择在点击“休息”前可修改，不立即结算。

## 休息

点击后按顺序：

1. 锁定已添加食物和守夜选择。
2. 消耗篝火食物。
3. 应用饱食、回复、烹饪和守夜结果。
4. 处理夜袭或睡眠不佳。
5. 推进到新一天并刷新当天时间点。
6. 返回六边形局内地图。
