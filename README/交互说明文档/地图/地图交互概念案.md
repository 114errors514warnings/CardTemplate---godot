# 地图交互概念案

> 本文为节点、事件与村庄的概念交互案，不替代地图玩法和时间规则。

## 六边形局内地图

- 所有节点类型共用六边形局内地图的位置、可达性和当天时间点。
- 玩家左键点击可达格点前往该位置；不可达格不响应前往操作。
- 到达格点后，根据节点类型进入对应交互，地图坐标与当天剩余时间点保持为当前局状态。
- 若剩余时间不足以支付下一步移动或节点交互时间，禁止继续前往并触发营地转场。

## 事件节点

- 不切换地图场景。
- 保留当前地图画面，在其上覆盖事件 UI 并锁定地图输入。
- 事件 UI 显示标题、描述、选项、代价和结果摘要；选择完成后关闭覆盖层并恢复地图输入。
- 事件结果可改变物品、角色状态、时间点和节点访问状态；具体事件内容后续配置。

## 村庄节点

- 进入村庄时切换到独立村庄地图场景。
- 角色左键点击村庄内可达格点前往对应位置；到达后在该格点处进行建筑或功能交互。
- 第一版预留商人、铁匠、治疗和离开入口；具体功能后续分批接入。
- 离开村庄后返回六边形局内地图，并保留当前局的角色、背包、时间和地图位置。

## 营地转场

1. 地图淡出。
2. 切换到三名角色围绕火堆的营地画面。
3. 营地淡入并显示休息交互。
4. 休息结算后淡出营地，返回地图并开始新一天。

营地规则见[篝火休息与食物](../../玩法说明文档/系统规则/营地系统/篝火休息与食物.md)，具体 UI 见[篝火休息交互概念案](../营地/篝火休息交互概念案.md)。
