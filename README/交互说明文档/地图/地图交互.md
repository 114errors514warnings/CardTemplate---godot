# 地图交互

## 当前可用流程（2026-09-21）

### 运行局内的地图

- 地图是运行局根场景常驻的独立覆盖层（`RunFlowScene/WorldMapLayer`，`CanvasLayer.Layer = 30`），不再作为独立场景往返切换；战斗、事件、结算在它下层的内容宿主中切换。
- 地图只显示六边形地图本体、节点、路径和当前节点高亮；不显示金币、钥匙、时间、角色信息、按钮、说明文字或其他 HUD。节点悬停详情尚未实现。
- 内容进行中打开＝只读：允许查看与平移，不允许点击节点、改变位置或启动内容。内容完成、运行局回到选点状态后才是可选：左键点击可达节点进入对应内容，不可达节点不响应。
- 只读态点击节点的提示尚未实现（嵌入模式下地图不创建状态条）。
- 地图独立 UI 视觉参考：[world-map-ui-reference.png](../../../Images/UI/Map/world-map-ui-reference.png)。

### 运行局顶部按钮栏

- 全局按钮由运行局根场景常驻持有（`GlobalButtonLayer`，`CanvasLayer.Layer = 50`）；内容自带的同名按钮不再显示，行为由常驻栏接管。
- 右上分两行：**通用行**（上，右对齐）`地图`、`定位当前角色`、`调试`、`暂停`；**剧情专属行**（正下方同一条带）左侧 `Log`、`隐藏`、`Auto: 关闭`，右侧 `跳过`（仅剧情可跳过时）。
- 通用行随当前内容形态变化：战斗中与结算未确认显示 `定位当前角色` `地图` `调试` `暂停`；剧情事件不显示 `定位当前角色`；没有任何内容时只显示 `地图` 与 `调试`。
- 剧情专属行只属于剧情 UI：排在通用行正下方（左 `Log` / `隐藏` / `Auto`，右 `跳过`），**世界地图打开时整行隐藏**，关闭地图后按剧情状态（含 Log / Auto 状态）原样恢复。
- `跳过` 只在剧情仍在推进时显示：事件允许跳过且还没走到选项 / 结束面板；进入选项或结束面板后隐藏（此时没有可跳的内容，与浮层内置跳过按钮规则一致）。开始事件配了自动播放到底，所以只会在结束面板停留、看不到 `跳过`；普通事件推进过程中始终可见。
- `暂停` 打开暂停界面：它挂在最高的 `CanvasLayer.Layer = 60`（`RunUiLayers.Pause`），压过世界地图、调试窗与顶部按钮栏，界面上的“继续”始终可点。
- `地图` 按钮恒可用（不因内容操作未完成而灰显）：地图已打开且存在内容时文本为 `返回`，否则为 `地图`；内容未完成时打开得到只读地图。
- 内容完成后进入“地图叠加在内容之上”的状态，按钮栏仍按**当前内容形态**显示——与局内按 `地图` 的表现完全一致。

### 主菜单与组队

- 无存档时可选择“纯净模式”或“剧情模式”。剧情模式跳过组队，直接以三人队建立运行局并进入开始事件；纯净模式仍进入三槽位组队界面（可重复选择重剑手、伊瑟拉、维吉尼亚），组队完成后进入旧独立地图场景，尚未并入运行局根场景。
- 有存档时显示“继续游戏”和“放弃当前进度”。继续游戏按存档的待处理内容进入事件、战斗或结算，地图模式随内容状态恢复。

### 开始事件与地图入口

- 新局建立后直接进入开始事件。开始事件自动结算，不展示多分支选项，只显示“前往地图”。
- 点击“前往地图”＝完成当前内容：不清空内容、不切换场景，地图以“已打开”的覆盖层叠到内容之上；只有此时地图节点可选。
- 地图打开期间顶部栏 `地图` 按钮持续显示；点击它关闭地图回到原内容（事件 UI 或结算界面原样恢复），再次点击重新打开并继续选择下一个节点。

### 地图节点

- 左键点击可达节点；已访问节点可经过但不重复触发。
- 普通战斗按 `NormalCombatRule.csv` 计算难度，再由 `LevelPool.csv` 随机选关卡；高危战斗由关卡池选取。
- 普通事件、危险事件、商人节点由 `EventPool.csv` 选取事件；当前 `ConditionId` 仅为预留空字段，尚不筛选条件。
- 村庄、三处精英和 Boss 属于固定位置节点，由 `FixedNode.csv` 配置；Boss 可在同一固定 Boss 键下按权重随机选择多个关卡。
- 找不到或无法加载对应关卡/事件配置时，停留在地图并显示错误原因。

### 地图调试

- 嵌入模式下地图自身不显示任何按钮；`调试` 入口在运行局顶部按钮栏的右组。
- 调试面板由运行局根场景统一持有（唯一实例）；面板打开时地图输入遮罩不会吃掉面板上的点击。
- 调试面板的“通用”分类支持输入 `LevelId` 跳转关卡、输入 `EventId` 跳转事件；跳转走运行局内容宿主与正常存档路径。

> 本文为节点、事件与村庄的概念交互案，不替代地图玩法和时间规则。

## 六边形局内地图

- 所有节点类型共用六边形局内地图的位置、可达性和当天时间点。
- 玩家左键点击可达格点前往该位置；不可达格不响应前往操作。
- 到达格点后，根据节点类型进入对应交互，地图坐标与当天剩余时间点保持为当前局状态。
- 若剩余时间不足以支付下一步移动或节点交互时间，禁止继续前往并触发营地转场。玩家也可主动选择“结束当天”，在尚有时间点时进入营地；界面预览剩余时间点比例对应的生命回复收益。

## 事件节点

- 不切换地图场景。
- 保留当前地图画面，在其上覆盖事件 UI 并锁定地图输入。
- 事件进行中除战场本身外不显示任何战斗 UI（关卡目标、手牌、装备、结束回合等全部隐藏），且事件内容存活期间不再恢复；地图打开时剧情 UI 整体让位，关闭地图后原样恢复。
- 事件 UI 显示标题、描述、选项、代价和结果摘要；选择完成后不销毁覆盖层，而是锁定原选项并显示唯一“前往地图”按钮，由玩家点击后让位给地图。
- 事件结果可改变物品、角色状态、时间点和节点访问状态。非战斗事件的选项结算后显示“前往地图”，由玩家点击后再让位给地图；不自动恢复地图输入。
- 事件选项尚未结算时允许打开地图 UI 查看节点信息，但所有节点选择操作禁用；关闭地图 UI 后返回原事件选项状态。

## 村庄节点（未实现）

- 进入村庄时切换到独立村庄地图场景。
- 角色左键点击村庄内可达格点前往对应位置；到达后在该格点处进行建筑或功能交互。
- 第一版预留商人、铁匠、治疗和离开入口；具体功能后续分批接入。
- 离开村庄后返回六边形局内地图，并保留当前局的角色、背包、时间和地图位置。
