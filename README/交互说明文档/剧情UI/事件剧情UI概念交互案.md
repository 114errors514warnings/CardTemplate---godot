# 事件剧情 UI 概念交互案

> 本文定义事件系统覆盖在当前战斗或地图场景上的对话交互。剧本、人物立绘、剧情梗概、选项结果和场景跳转均由后续配置提供。

## 一、场景覆盖与输入状态

- 事件开始时，在当前场景顶层添加全屏剧情覆盖层。
- 覆盖层隐藏战斗手牌区；其他底层 HUD 可按事件配置隐藏或弱化。
- 覆盖层的根节点必须拦截鼠标与触摸射线，底层地图、战斗单位、手牌、装备、道具和移动输入全部不可响应。
- 事件结束后恢复事件前的 UI 可见状态与输入状态；不得统一假设所有场景都存在战斗手牌区。
- 事件覆盖层包含背景图、左右立绘、对话气泡、对话控制按钮、选项容器和确认弹窗。层级从低到高：背景 → 立绘 → 气泡/选项 → 控制按钮 → Log/跳过确认弹窗。

## 二、剧本基础数据

每条对话至少配置：

| 字段 | 说明 |
|---|---|
| `SpeakerId` | 说话人物 ID |
| `SpeakerName` | 气泡左上角显示名称 |
| `PortraitId` | 人物立绘资源 ID |
| `Text` | 对话内容 |
| `Side` | 左、右或自动分配 |
| `BubbleStyle` | 普通、左侧说话、右侧说话 |
| `AutoDelay` | 当前句完整显示后的自动等待时间 |

事件还可配置背景图、剧情梗概、是否允许跳过、选项列表和结束后的场景目标。选项至少配置 `Text`、面向玩家的 `EffectDescription` 与实际结果回调/结果数据；`EffectDescription` 是已经公开的结果，直接显示在选项文本后的全角括号中。

## 三、左右人物立绘

### 3.1 初始显示

- 对话开始时，左侧优先显示第一个说话人物。
- 右侧优先显示第二个与左侧不同的说话人物。
- 如果前两句由同一人物说话，另一侧保持空位或使用剧本指定的默认陪衬立绘，不伪造第二个说话人物。
- 立绘显示人物名、立绘资源和当前说话状态；当前说话人物较亮，另一侧降低亮度。

### 3.2 后续替换规则

1. 当前说话人物已存在于左或右立绘，则不替换立绘，仅切换高亮与气泡尖角方向。
2. 当前说话人物不在任一侧时，优先替换“上一句说话人物所在的另一侧”。
3. 若剧本明确配置 `Side`，以配置侧为准；该侧原人物被替换。
4. 若未配置 `Side`，使用以下自动规则：
   - 左侧人物说完后，下一位新人物优先替换右侧；
   - 右侧人物说完后，下一位新人物优先替换左侧；
   - 无上一句或两侧均为空时，填入空侧。
5. 替换使用短淡入淡出或横向滑入，避免立绘瞬间跳变。

此规则保证两人对话稳定；三人以上对话时，总是保留当前说话人物，并轮换另一侧立绘。

## 四、对话气泡

### 4.1 固定结构

气泡固定包含：

```text
左上：人物名称
中部：从左上开始排版的说话内容
```

- 人物名称固定在内容框左上区域。
- 正文从名称下方左侧开始，整体在气泡可用区域内垂直居中；多行文本保持左对齐，不居中逐行排版。
- 文本使用逐字显示；点击时若未显示完，先立即显示完整当前句，不直接进入下一句。

### 4.2 三种气泡样式

| 样式 | 用途 | 尖角 |
|---|---|---|
| 普通气泡 | 旁白、系统、无立绘角色 | 无尖角的圆角矩形 |
| 左侧气泡 | 左侧人物说话 | 圆角矩形 + 左下角朝左下的尖角 |
| 右侧气泡 | 右侧人物说话 | 圆角矩形 + 右下角朝右下的尖角 |

- 气泡尖角只表示本句说话来源，不决定人物立绘是否替换。
- 旁白使用普通气泡，两个立绘均降低亮度。
- 气泡位置保持稳定，不因左右说话而整体跳到屏幕另一侧。

## 五、对话推进

### 5.1 手动推进

1. 当前句逐字显示中：左键或确认键补全当前句。
2. 当前句完整显示：左键或确认键进入下一句。
3. 剧本进入选项：停止对话推进，显示选项容器。
4. Log、跳过确认、隐藏 UI、选项出现或场景淡入淡出期间，不接受普通推进输入。

右键、Esc 或取消键优先关闭当前最高层弹窗；没有弹窗时不退出事件，避免误触跳过剧情。

### 5.2 自动播放

`auto` 按钮循环状态：

```text
关闭 → 1 倍速 → 2 倍速 → 4 倍速 → 关闭
```

- 自动播放影响逐字速度和句末等待时间。
- 一句显示完毕后，按 `AutoDelay / 倍速` 等待，再自动进入下一句。
- 出现选项、Log、跳过确认或隐藏 UI 时自动播放暂停；选项不会被自动选择。
- 用户手动推进不关闭自动播放，但当前句会立即补全。

## 六、对话控制按钮

### 6.1 Log

- 打开对话记录弹窗，按时间顺序显示已完整出现的对话。
- 每条记录显示人物名称、立绘或侧别标记、正文和旁白类型。
- Log 打开时冻结自动播放和普通推进；关闭后恢复此前的自动播放状态。
- 记录只读，不能从 Log 回退剧情状态。

### 6.2 隐藏

- 隐藏气泡、控制按钮、选项容器和非必要 HUD，仅保留背景图和人物立绘。
- 隐藏后左键只恢复 UI，不推进对话；再次点击隐藏按钮也可恢复。
- 隐藏状态下仍拦截地图输入，不能通过空白区域点击底层格点。

### 6.3 Auto

- 显示当前状态：关闭、1×、2×、4×。
- 每次点击切换至下一状态；关闭时停止后续自动推进。
- 按钮不改变已显示文本内容或已记录的对话。

### 6.4 跳过

- 位于右上角。
- 点击后打开确认弹窗，不直接跳过。
- 弹窗必须显示剧本配置的剧情梗概与“确认跳过 / 返回剧情”按钮。
- 确认跳过只跳过逐句演出，不默认结算任何选项结果：切换为跳过剧情版，在选项上方显示完整缩略剧情，下面显示与完整剧情版相同的选项和公开影响；玩家仍须选择一项。
- 未配置跳过权限的事件禁用跳过按钮，或显示“本事件不可跳过”。

## 七、事件选项

- 对话到达选项节点时，隐藏或冻结气泡推进，显示选项按钮；完整剧情版不额外显示剧情梗概。
- 在跳过确认后，选项容器上方先显示“剧情梗概”和完整缩略版剧情，再显示同一批选项；这就是跳过剧情版。
- 选项位于以屏幕正中心为中心的 Container 内。
- 使用单列 GridContainer 或等距 VBoxContainer，自上而下均匀排列；选项数量变化时保持整体相对屏幕中心对齐。
- 已公开结果的每项显示为“选项文本（影响）”，例如“就地休息（恢复当前角色 4 点生命）”；未知结果则不填写影响文本，不提前泄露。
- 不可选选项保持可见但禁用，并显示原因。
- 点击合法选项后立即锁定所有选项，应用剧本结果，再进入后续对话或结束转场。

## 八、场景演出与过渡

### 8.1 基础淡入淡出

1. 锁定事件所有输入。
2. 当前覆盖层淡出；需要切换场景时，当前场景一并淡出。
3. 完成事件结果写入与存档。
4. 加载目标场景或恢复原场景地图。
5. 目标背景、立绘和必要 UI 淡入。
6. 恢复目标场景允许的输入。

### 8.2 结果类型

| 结果 | 过渡 |
|---|---|
| 继续地图 | 关闭事件覆盖层，恢复地图输入 |
| 进入战斗 | 淡出后切换战斗场景 |
| 进入村庄 | 淡出后切换村庄场景 |
| 时间不足 | 淡出后进入营地场景 |
| 结束本局 | 淡出后进入结算或主菜单 |

任何转场都必须等待淡出完成后再切换场景，避免事件 UI、手牌区或地图输入残留到新场景。
