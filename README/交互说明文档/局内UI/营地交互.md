## 转场步骤

1. 地图淡出。
2. 切换到三名角色围绕火堆的营地画面。
3. 营地淡入并显示休息交互。
4. 休息结算后淡出营地，返回地图并开始新一天。

## 营地基础画面

- 画面表现为三名角色围绕火堆。
- 不显示全屏或底部 UI 底板。
- 仅常驻四个独立按钮：添加食物、烹饪、守夜、休息。
- 营地期间地图、战斗和原背包界面不接受输入。

## 添加食物

> **已实现（2026-10-02，批 C）**：按钮已开闸。落点 `Scripts/Run/CampScene.cs` 的 `BuildFoodPanel` / `RefreshFoodPanel` + `RunFoodSystem.CampFirePlan`（纯逻辑）+ `RunSession.ApplyRest(plan)`。**拖拽未做**：本期用「添加」「取回」按钮表达同一份草稿语义（草稿本身在 `plan`，点「休息」前不消耗背包）。口径与烟测见 [10 月施工文档 §9](../../施工文档/2026/2026.10/10月施工文档.md)。

点击后进入食物分配状态：

```text
左侧
├─ 上：本次篝火的饱食度进度条
└─ 下：已添加食物的格状列表

右侧
└─ 当前局背包中的食物格状列表
```

- 左右两侧格中的食物可自由拖动。
- 从背包拖到篝火列表时，预览本次休息的饱食度与食物效果。
- 篝火列表明确区分“仍提供效果”和“只提供饱食度”的食物；首次使效果饱食度超过上限的食物及其后的食物，显示为无效果状态。
- 从篝火列表拖回背包时，撤销对应预览。
- 点击“休息”前，食物只存在于本次营地草稿，不正式消耗。
- 点击“休息”后，篝火列表中的食物统一消耗并按玩法规则结算。

## 烹饪

> **已实现（2026-10-02，批 C）**：按钮已开闸。落点 `Scripts/Run/CampScene.cs` 的 `BuildCookPanel` / `RefreshCookPanel` + `RunFoodSystem.CanCook / TryCook` + `RunSession.TryCook`。**成菜入背包**（本节待确认项的默认口径），可立刻「添加」进篝火草稿；材料通道的 7 条旧配方 `Enabled = FALSE`（材料暂不参与烹饪）；**草稿里的食物不能被当原料**（`reservedInstanceIds`，否则会吃到已不存在的食物）。

- 点击后显示已放行配方（`输入 → 产出`）；食物本身的有效期 / 饱食度 / 篝火效果在「添加食物」面板的背包行与篝火行上标注。
- 每次休息最多合成 2 次；**2026-10-02 起合成只消耗食物**（材料暂不参与烹饪），不消耗额外时间点。
- 合成完成后的食物**进入背包**（2026-10-02 定稿，本节待确认项按此口径实现），可立刻「添加」进篝火草稿；无论哪种方式，都必须在点击“休息”前允许玩家撤销本次营地草稿。

## 守夜

> **本期已实现（2026-10-01）**：三选 + 承担者 + 回复实时预览 + 结算折算；仅**夜袭**与**「睡眠不佳」**未结算（见「完成情况」遗留）。

- 守夜选择包括不守夜、轮流守夜和单人守夜，并在 UI 中实时显示生命回复、夜袭和睡眠不佳影响。
- 不守夜为全额回复且有夜袭概率；轮流守夜使每名角色回复降为 2/3；单人守夜使守夜角色不回复，并在下一场战斗获得“睡眠不佳”。
- 守夜选择在点击“休息”前可修改，不立即结算。

## 休息

点击后按顺序：

1. 锁定已添加食物和守夜选择。
2. 消耗篝火食物。
3. 应用饱食、回复、烹饪和守夜结果。
4. 处理夜袭或睡眠不佳。
5. 推进到新一天并刷新当天时间点。
6. 返回六边形局内地图。
